# 1. 삭제된 FAT 파일 복구
## 1.1 복구 가능 조건
### 1.1.1 삭제 파일 식별
- **FAT 파일 삭제** 동작 원리는 [[13주차 파일 시스템 이해 2]]에서 다룬다.
- 포렌식 도구에서는 `E5` 값을 기준으로 삭제된 파일을 식별한다.
- **FAT 엔트리**가 초기화되었더라도 파일이 **연속된 클러스터**에 저장되어 있었다면 **시작 클러스터**와 **파일 크기** 정보로 복구할 수 있다.

## 1.2 복구 시나리오
### 1.2.1 메타데이터가 모두 있는 경우
| 단계 | 작업 | 결과 |
| --- | --- | --- |
| 1 | **Directory Entry**에서 `E5` 삭제 엔트리 탐색 | 삭제 파일 후보 식별 |
| 2 | 파일 **시작 클러스터**, **파일 크기**, 속성, 시간 정보 확인 | 복구에 필요한 **메타데이터** 확보 |
| 3 | **Data Area**에서 **시작 클러스터**부터 **파일 크기**만큼 읽기 | 원본 파일 데이터 획득 |
| 4 | 읽은 데이터를 파일로 저장 | 빠르고 정확한 복구 가능 |

### 1.2.2 메타데이터가 없는 경우
| 조건 | 복구 방식 | 한계 |
| --- | --- | --- |
| **Directory Entry** 정보 없음 | **Data Area**의 클러스터 조각 분석 | 복구 시간 증가 |
| FAT 정보 없음 | **파일 시그니처** 기반으로 다음 클러스터 추정 | 정확도 저하 |
| 파일이 조각남 | 퍼즐 맞추기 방식의 재구성 필요 | 복구 난이도 급상승 |

### 1.2.3 연속 클러스터 여부
| 저장 상태 | 복구 난이도 | 이유 |
| --- | --- | --- |
| **연속 저장** | 낮음 | **시작 클러스터**와 크기 정보만으로 복구 가능 |
| **조각난 저장** | 높음 | 다음 클러스터 추정과 결과 검증이 필요 |

### 1.2.4 삭제 후 덮어쓰기 발생 시
- 삭제된 클러스터 영역인 **Data Area**에 새로운 파일이 기록될 수 있다.
- 새로운 파일이 기록되면 기존 데이터가 덮어써진다.
- 원본 데이터가 소실되면 복구가 불가능하다.
