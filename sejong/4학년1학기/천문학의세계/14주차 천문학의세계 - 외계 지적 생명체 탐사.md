# 1. 우주 속 지구와 생명 탐사의 문제의식
## 1.1 우주의 규모
- 우주의 나이: 약 `138억 년`
- 관측 가능한 우주 반경: 약 `465억 광년`
- 핵심 질문: 외계 생명체가 있는가, 그리고 그 흔적을 관측할 수 있는가?
## 1.2 창백한 푸른 점
- Voyager 1이 지구에서 약 `40.5 AU` 떨어진 위치에서 지구 촬영
- 사진 이름: Pale Blue Dot, 창백한 푸른 점
## 1.3 외계행성 발견 현황
- 2026년 5월 현재 발견 외계행성: 약 `6400개`
- 후보 행성: `10,000개` 이상
- 탐사 범위: 주로 지구에서 약 `1 kpc`, 약 `3000광년` 이내
# 2. 페르미 역설
## 2.1 핵심 질문
> 우리은하에는 별과 행성이 이렇게 많은데, 왜 우리는 아직 외계 문명의 흔적을 발견하지 못했는가?
- 별/행성은 매우 많음
- 생명체/지적 문명 가능성도 있어 보임
- 하지만 확실한 외계 지적 문명 신호는 아직 없음
## 2.2 가능한 설명
| 설명 | 핵심 |
|---|---|
| 지적 문명은 드물다 | 생명체가 있어도 기술 문명까지 드묾 |
| 문명은 오래 지속되지 못한다 | 스스로 파괴되거나 신호를 오래 못 냄 |
| 우주가 너무 넓다 | 거리/시간 규모가 너무 큼 |
| 탐색 방식이 틀렸을 수 있다 | 신호 형태, 주파수, 기술 가정 문제 |
| 일부러 접촉하지 않을 수 있다 | 신호를 안 보내거나 접촉 회피 |
| 지구가 드문 사례일 수 있다 | 생명/문명 조건이 특수 |
## 2.3 Water hole 주파수
- 외계 문명이 통신에 사용할 것이라 예상되는 `1420 MHz-1662 MHz` 대역
- 배경 잡음이 적은 마이크로파 구간
- 먼 거리에서도 신호 도달에 유리
# 3. SETI의 기본 개념
## 3.1 SETI의 의미
- SETI = Search for Extra-Terrestrial Intelligence
- 외계 지적 생명체/기술 문명의 흔적 탐사
| 구분 | 탐색 대상 |
|---|---|
| 생물학적 생명현상 | 대기 조성, 생명 가능 환경, 생체 활동 흔적 |
| 기술 문명적 생명현상 | 인공 전파, 레이더, 의도적 메시지, 기술 흔적 |
## 3.2 관측의 세 축
| 축 | 의미 |
|---|---|
| 관측 영역 | 어느 방향, 얼마나 넓은 영역 |
| 관측 주파수 | 어떤 전자기파 대역 |
| 관측 감도 | 얼마나 약한 신호까지 검출 |
- 좋은 SETI 관측 = 넓은 영역 + 적절한 주파수 + 높은 감도
- 실제 관측은 망원경 시간/장비/데이터 처리 능력 사이 균형 필요
# 4. 주요 SETI 관측과 신호
## 4.1 초기 SETI 프로그램
| 프로그램 | 시기/대상 | 핵심 |
|---|---|---|
| Project Ozma-I | 1960년, Tau Ceti와 Epsilon Eridani | `1420 MHz`, 약 4개월, 가까운 별 2개 전파 탐사 |
| Project Phoenix | 1995-2003년, 약 1000개 별 | Parkes 64m, Arecibo 305m 사용 |
| Project SERENDIP-I - VI | 1979년 이후 | Arecibo 305m 활용 SETI 탐색 |
## 4.2 1420 MHz의 의미
- 중성수소 21 cm 선과 관련
- 수소 = 우주에서 가장 흔한 원소
- 외계 문명이 보편적으로 알아볼 수 있는 주파수 후보
## 4.3 Wow! Signal
- 1977년 8월 15일 기록된 강한 전파 신호
- 외계 지적 생명체 신호 후보로 유명
- 반복 관측으로 확인 X
- SETI 핵심: 반복 가능하고 검증 가능한 신호
# 5. 전파망원경과 SKA
## 5.1 SKA의 의미와 구성
- SKA = Square Kilometre Array
- `1 km x 1 km` 수준 집광 면적 목표의 대형 전파망원경

| 구분 | 위치 | 주파수 범위 | 구성/특징 |
|---|---|---|---|
| SKA-Mid | 남아프리카 | 약 `350 MHz-15.4 GHz` | 접시형 안테나, MeerKAT 포함 |
| SKA-Low | 호주 | 약 `50 MHz-350 MHz` | 저주파 안테나 배열 |
## 5.2 SKA 프리커서
- SKA 완성 전 단계 관측 시설
- 예시: MeerKAT/HERA, ASKAP/MWA
- 현존 최신 중/저주파수 전파망원경
- 최종 SKA 집광력의 약 `1%` 수준
# 6. Breakthrough Initiatives

| Breakthrough Listen | 전파망원경으로 외계 지적 생명체 신호 탐색 |

| Breakthrough Watch | 20광년 이내 외계행성 대기 분석, 생명체 거주 가능성 탐색 |
| Breakthrough Message | 지구 문명 메시지 설계, 외계 송신 타당성 검토 |
## 6.2 Breakthrough Listen
- 역대 최대 규모 SETI 프로젝트
- MeerKAT 전파망원경 이용

| 항목 | 규모/내용 |
|---|---|
| 인근 별 | 약 `100만 개`, 거리 `< 200 pc` |
| 외부 은하 | 약 `100개` |
| 기존 대비 감도 | 약 `50배` 향상 |
| 기존 대비 속도 | 약 `100배` 향상 |
| 탐지 수준 | 항공기 레이더급 신호를 인근 약 `1000개` 별 거리에서 포착 가능 |
## 6.3 천문 관측과 SETI 병행
- MeerKAT 대규모 천문 관측 데이터를 공유받아 SETI 탐색 병행

| 프로젝트 | 주요 관측 대상 |
|---|---|
| LADUMA | 먼 우주의 중성수소 가스 |
| MeerTIME / TRAPUM | 펄서, 전파 transient |
| MIGHTEE / Fornax / MHONGOOSE / MALS | 은하, 은하단 |
- 핵심: 일반 천문 관측 데이터로 인공 전파 신호도 함께 탐색
# 7. SKA를 이용한 외계 지적 생명체 탐사
## 7.1 탐색 가능한 인공 신호
| 신호 유형 | 특징 |
|---|---|
| 행성간 레이더 | 매우 강한 인공 전파 신호 |
| 장거리 항공기 레이더 | 강한 방향성 전파 신호 |
| 고출력 TV/라디오 | 상대적으로 약하지만 지속 가능 |
## 7.2 SKA1과 SKA2의 SETI 계획
| 단계 | 관측 계획 |
|---|---|
| SKA1 | 5년 관측, 200광년 이내 약 `10,000개` 별의 공항 레이더 신호 탐색 |
| SKA2 | 10년 관측, 200광년 이내 모든 별의 공항 레이더 신호 탐색 |
- SKA는 전파 감도와 탐색 범위를 크게 늘린다.
- 검출 조건: 주파수, 방향, 시간, 세기 조건이 맞아야 함
