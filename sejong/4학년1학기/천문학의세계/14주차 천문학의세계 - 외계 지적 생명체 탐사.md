# 1. 우주 속 지구와 생명 탐사의 문제의식
## 1.1 우주의 규모
- 우주의 나이는 약 `138억 년`이다.
- 관측 가능한 우주의 반경은 약 `465억 광년` 규모로 제시된다.
- 우주의 거대한 규모는 외계 생명체 탐사의 출발점이 된다.
- 질문은 단순히 “외계 생명체가 있는가?”가 아니라, **우리가 그 흔적을 관측할 수 있는가**로 이어진다.
## 1.2 창백한 푸른 점
- Voyager 1은 지구에서 약 `40.5 AU` 떨어진 위치에서 지구를 촬영했다.
- 이 사진은 **Pale Blue Dot**, 즉 창백한 푸른 점으로 알려져 있다.
## 1.3 외계행성 발견 현황
- 2026년 5월 현재 발견된 외계행성은 약 `6400개`로 제시된다.
- 후보 행성은 `10,000개` 이상이다.
- 현재까지의 외계행성 탐사는 주로 지구로부터 약 `1 kpc`, 즉 약 `3000광년` 이내의 제한된 시공간에서 이루어졌다.
# 2. 페르미 역설
## 2.1 핵심 질문
> 우리 은하에는 별과 행성이 이렇게 많은데, 왜 우리는 아직 외계 문명의 흔적을 발견하지 못했는가?
- 우주에는 별과 행성이 매우 많다.
- 그렇다면 생명체나 지적 문명도 어딘가에 존재할 가능성이 있어 보인다.
- 그러나 현재까지 확실한 외계 지적 문명의 신호는 발견되지 않았다.
## 2.2 가능한 설명
| 설명 | 핵심 내용 |
|---|---|
| 지적 문명은 드물다 | 생명체는 가능해도 기술 문명까지 가는 경우가 매우 적을 수 있음 |
| 문명은 오래 지속되지 못한다 | 문명이 스스로 파괴되거나 장기간 신호를 내지 못할 수 있음 |
| 우주가 너무 넓다 | 거리와 시간 규모가 너무 커서 서로 만나거나 통신하기 어려움 |
| 탐색 방식이 틀렸을 수 있다 | 우리가 찾는 신호 형태, 주파수, 기술 가정이 맞지 않을 수 있음 |
| 일부러 접촉하지 않을 수 있다 | 외계 문명이 의도적으로 신호를 보내지 않거나 접촉을 피할 수 있음 |
| 지구가 드문 사례일 수 있다 | 생명체와 문명이 생기기 위한 조건이 매우 특수할 수 있음 |
## 2.3 Water hole 주파수
- 외계 문명이 우주 통신에 사용할 것이라 예상되는 **1420 MHz ~ 1662 MHz (메가헤르츠)** 대역입니다
- 우주의 배경 잡음이 가장 적은 마이크로파 구간에 해당하여 **먼 거리에서도 신호가 잘 도달**
# 3. SETI(Search for Extra-Terrestrial Intelligence)의 기본 개념
## 3.1 SETI의 의미
- 외계 지적 생명체 또는 기술 문명의 흔적을 찾는 탐사이다.
- 생물학적 생명현상뿐 아니라, 기술 문명적 생명현상을 탐색한다.

| 구분          | 탐색 대상                             |
| ----------- | --------------------------------- |
| 생물학적 생명현상   | 대기 조성, 생명 가능 환경, 생체 활동의 흔적        |
| 기술 문명적 생명현상 | 인공 전파 신호, 레이더 신호, 의도적 메시지, 기술적 흔적 |
## 3.2 관측 영역, 주파수, 감도
- SETI 관측은 세 가지 축으로 생각할 수 있다.

| 축      | 의미                        |
| ------ | ------------------------- |
| 관측 영역  | 하늘의 어느 방향, 얼마나 넓은 영역을 보는가 |
| 관측 주파수 | 어떤 전자기파 주파수 대역에서 신호를 찾는가  |
| 관측 감도  | 얼마나 약한 신호까지 검출할 수 있는가     |
- 좋은 SETI 관측은 넓은 영역, 적절한 주파수 범위, 높은 감도를 동시에 확보해야 한다.
- 그러나 실제 관측에서는 망원경 시간, 장비 성능, 데이터 처리 능력 때문에 세 요소 사이의 균형이 필요하다.
# 4. 주요 SETI 관측과 신호
## 4.1 초기 SETI 프로그램
| 프로그램                    | 시기/대상                            | 핵심 내용                                |
| ----------------------- | -------------------------------- | ------------------------------------ |
| Project Ozma-I          | 1960년, Tau Ceti와 Epsilon Eridani | `1420 MHz`에서 약 4개월 동안 가까운 별 2개 전파 탐사 |
| Project Phoenix         | 1995-2003년, 약 1000개 별            | Parkes 64m, Arecibo 305m 전파망원경 사용    |
| Project SERENDIP-I - VI | 1979년 이후                         | Arecibo 305m 전파망원경을 활용한 SETI 탐색      |
## 4.2 1420 MHz의 의미
- Project Ozma-I는 `1420 MHz` 부근에서 관측했다.
- 이 주파수는 중성수소의 21 cm 선과 관련된 대표적인 천문학적 전파 주파수이다.
- 수소는 우주에서 가장 흔한 원소이므로, 외계 문명이 보편적으로 알아볼 수 있는 주파수 대역으로 여겨질 수 있다.
## 4.3 Wow! Signal
- Wow! Signal은 1977년 8월 15일에 기록된 강한 전파 신호이다.
- 외계 지적 생명체 신호 후보로 유명하지만, 반복 관측으로 확인되지 않았다.
- SETI에서 중요한 점은 단발성 신호보다 **반복 가능하고 검증 가능한 신호**가 필요하다는 것이다.
# 5. 전파망원경과 SKA
## 5.1 SKA의 의미
- SKA는 **Square Kilometre Array**의 약자이다.
- 이름 그대로 `1 km x 1 km` 수준의 집광 면적을 목표로 하는 대형 전파망원경 계획이다.
- 지구에서 가장 큰 전파망원경 프로젝트 중 하나로 제시된다.
## 5.2 SKA 구성
| 구분      | 위치    | 주파수 범위               | 구성/특징               |
| ------- | ----- | -------------------- | ------------------- |
| SKA-Mid | 남아프리카 | 약 `350 MHz-15.4 GHz` | 접시형 안테나, MeerKAT 포함 |
| SKA-Low | 호주    | 약 `50 MHz-350 MHz`   | 저주파 안테나 배열          |
## 5.3 SKA 프리커서
- SKA 프리커서 전파망원경은 SKA 완성 전 단계의 관측 시설이다. ex) MeerKAT/HERA, ASKAP/MWA
- 이들은 현존하는 최신 중/저주파수 대역 전파망원경에 해당한다.
- 최종 SKA 전파망원경 집광력의 약 `1%` 수준으로 설명된다.
# 6. Breakthrough Initiatives
## 6.1 전체 구성
| 프로젝트                  | 핵심 목표                                        |
| --------------------- | -------------------------------------------- |
| Breakthrough Listen   | 전파망원경으로 외계 지적 생명체의 신호를 탐색하는 SETI 관측 프로젝트     |
| Breakthrough Starshot | 광자 돛과 지상 레이저로 초소형 우주선을 가속해 알파 센타우리로 보내는 프로젝트 |
| Breakthrough Watch    | 20광년 이내 외계행성의 대기 성분을 분석해 생명체 거주 가능성을 탐색      |
| Breakthrough Message  | 지구 문명을 담은 메시지를 설계하고, 외계로 신호를 보내는 행위의 타당성을 검토 |
## 6.2 Breakthrough Listen
- Breakthrough Listen은 역대 최대 규모의 외계 지적 생명체 탐사 프로젝트로 소개된다.
- MeerKAT 전파망원경을 이용한다.

| 관측 대상 | 규모 |
|---|---|
| 인근 별 | 약 `100만 개`, 거리 `< 200 pc` |
| 외부 은하 | 약 `100개` |
- 기존 대비 감도는 약 `50배`, 속도는 약 `100배` 향상된 관측으로 설명된다.
- 항공기 레이더 수준의 전파 신호를 인근 약 `1000개` 별 거리에서 포착할 수 있는 수준으로 제시된다.
## 6.3 천문 관측과 SETI의 병행
- Breakthrough Listen은 MeerKAT의 대규모 천문 관측 프로젝트 데이터를 공유받아 SETI 탐색을 병행한다.

| 프로젝트 | 주요 관측 대상 |
|---|---|
| LADUMA | 먼 우주의 중성수소 가스 |
| MeerTIME / TRAPUM | 펄서 및 전파 transient |
| MIGHTEE / Fornax / MHONGOOSE / MALS | 은하, 은하단 |
- 일반 천문 관측을 수행하면서 동시에 수십만-백만 개 별을 모니터링할 수 있다.
- 핵심은 기존 관측 데이터를 활용해 인공 전파 신호 탐색을 병행한다는 점이다.
# 7. SKA를 이용한 외계 지적 생명체 탐사
## 7.1 탐색 가능한 인공 신호
- SKA를 이용하면 지구 문명에서 사용하는 수준의 강한 전파 신호를 외계에서 탐색하는 시나리오를 생각할 수 있다.
- 예시로 공항 레이더, 장거리 항공기 레이더, 고출력 TV/라디오 신호 같은 인공 전파 방출이 제시된다.

| 신호 유형 | 특징 |
|---|---|
| 행성간 레이더 | 매우 강한 인공 전파 신호 |
| 장거리 항공기 레이더 | 강한 방향성 전파 신호 |
| 고출력 TV/라디오 | 상대적으로 약하지만 지속적일 수 있는 인공 전파 신호 |
## 7.2 SKA1과 SKA2의 SETI 계획
| 단계   | 관측 계획                                           |
| ---- | ----------------------------------------------- |
| SKA1 | 5년 관측으로 200광년 이내 약 `10,000개` 별의 공항 레이더 전파 신호 탐색 |
| SKA2 | 10년 관측으로 200광년 이내 모든 별의 공항 레이더 전파 신호 탐색         |
- SKA는 전파 감도와 탐색 범위를 크게 늘려 외계 기술 문명의 신호 탐색 가능성을 높인다.
- 다만 신호가 존재하더라도 주파수, 방향, 시간, 세기 조건이 맞아야 검출될 수 있다.
