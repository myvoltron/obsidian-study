# 1. 외부 은하의 발견
## 1.1 외부 은하의 의미
- 외부 은하 = 우리은하 밖에 존재하는 은하
- 핵심 질문
  - 우리은하 밖에도 은하가 존재하는가?
  - 은하들은 어떤 기준으로 분류되는가?
  - 은하 중심부 초대질량 블랙홀 활동은 무엇을 만드는가?
## 1.2 섬 우주론과 M31
- 과거 논쟁: 나선 성운이 우리은하 내부 천체인가, 외부 은하인가?
- 섬 우주론 = 우리은하 밖에도 독립된 별들의 집단이 존재한다는 생각
- 핵심: 우리은하가 우주의 전부인가?

| 항목 | 내용 |
|---|---|
| 관측자 | 에드윈 허블 |
| 장비 | 윌슨산 천문대 100인치 망원경 |
| 대상 | M31, 안드로메다 은하의 세페이드 변광성 |
| 방법 | 세페이드 주기-광도 관계로 거리 측정 |
| 결론 | M31은 우리은하 밖에 위치 => 외부 은하 |
- 외부 은하는 멀어서 개별 별이 쉽게 분해되지 않고 성운처럼 보임
## 1.3 우리은하의 위성 은하
- 위성 은하 = 우리은하 중력에 묶여 함께 움직이는 작은 은하
- 우리은하에 가장 가까운 외부 은하 예시

| 위성 은하 종류 | 예시 | 특징 |
|---|---|---|
| 불규칙 위성 은하 | 대마젤란 은하, 소마젤란 은하 | 가스/젊은 별 많음, 별생성 가능 |
| 왜소 구형/타원 위성 은하 | 궁수자리 왜소은하, Fornax, Sculptor 등 | 작고 어두움, 늙은 별 많음 |
- 위성 은하는 우리은하 암흑 물질 헤일로 안에서 궤도 운동을 한다.
- 우리은하와의 중력 상호작용으로 tidal stream이 형성될 수 있다.
- 의미: 우리은하 질량 분포/암흑 물질 헤일로 추정 단서
# 2. 은하의 분류
## 2.1 허블 분류법
- 기준: 은하의 모양
- 표현: 소리굽쇠 다이어그램

| 은하 종류 | 영어 이름 | 핵심 형태 | 별/가스 특징 |
|---|---|---|---|
| 타원은하 | Elliptical galaxies | 원형-타원형, 매끄러운 별 분포 | 늙고 붉은 별 많음, 가스/먼지 적음 |
| 렌즈형 은하 | Lenticular galaxies | 타원은하와 나선은하 중간 | 원반은 있으나 나선팔 약함 |
| 나선은하 | Spiral galaxies | 원반, 팽대부, 나선팔 | 가스/먼지 많음, 별생성 활발, 푸른색 |
| 불규칙 은하 | Irregular galaxies | 대칭 구조 약함 | 푸른색, 중심핵 약함 |
## 2.2 타원은하
- 세부 분류: `E0`-`E7`
- 은하 중심에서 외곽으로 갈수록 밝기 감소
- 대부분 늙은 별로 이루어져 전체적으로 붉게 보인다.
- (우리은하에 비해) 최대 5배 크고 최대 50배 무거울 수 있음 => 거대 타원은하
## 2.3 나선은하
- 우리은하와 비슷하거나 더 큰 크기/질량 가능
- 구조: 원반부 + 나선팔 + 중심 팽대부
- 나선팔: 젊고 푸른 별
- 중심 팽대부: 늙고 붉은 별

| 세부 분류 | 특징 |
|---|---|
| `Sa` | 나선팔 조밀 |
| `Sc` | 나선팔 느슨 |
| `SBa`, `SBb`, `SBc` | 막대 나선은하, barred spiral galaxy |
- 중심부 막대 모양 별 분포 => Sb
- 표면 온도 순서: O -> B -> A -> F -> G -> K -> M -> L
  - O/B: 약 `30000K`
  - G: 태양과 비슷, 약 `6800K`
  - M/L: 약 `3000K`
## 2.4 불규칙 은하
- 중심핵 뚜렷하지 않음
- 비대칭 구조
- 보통 나선은하보다 더 푸름
- 보통 우리은하보다 약 25% 작음
- 예시: 대마젤란 은하, 소마젤란 은하
# 3. 은하의 암흑 물질과 집단 구조
## 3.1 암흑 물질 헤일로
- 모든 외부 은하: 암흑 물질 헤일로에 둘러싸임
- 암흑 물질: 은하 전체 질량의 90% 이상
## 3.2 은하 그룹과 은하단
| 구조 | 규모 | 특징 |
|---|---|---|
| 은하 그룹 | 수십 개 은하 | 비교적 작은 은하 집단 |
| 은하단 | 수천 개 은하 | 중심부에 거대 타원은하 흔함 |
| 초은하단 | 여러 은하단/그룹 | 더 큰 규모의 우주 구조 |
## 3.3 지역 은하 그룹과 처녀자리 초은하단
- 우리은하: 약 50여 개 은하로 이루어진 지역 은하 그룹에 속함
- 주요 구성원: 우리은하, 안드로메다 은하
- 처녀자리 초은하단: 약 100여 개 은하단/은하 그룹
- 처녀자리 은하단: 약 2000개 은하
- 지역 은하 그룹: 처녀자리 초은하단 가장자리 쪽
# 4. 은하의 충돌과 병합
## 4.1 충돌 빈도
| 시기 | 은하 충돌 빈도 | 이유 |
|---|---|---|
| 우주 초기 | 높음 | 우주가 작고 밀도 높음, 은하 사이 거리 가까움 |
| 우주 중후반 | 낮아짐 | 팽창으로 평균 밀도 감소, 은하 사이 거리 증가 |
- 작은 은하들의 충돌과 병합을 통해 큰 은하가 성장한다.
- 은하군/은하단처럼 중력으로 묶인 환경에서는 현재도 충돌 가능
## 4.2 은하 충돌의 특징
- 별끼리 직접 충돌 가능성은 매우 작음
- 이유: 별 사이 거리 매우 큼
- 실제 영향: 중력 상호작용이 별/가스 분포를 바꿈
- 결과: 꼬리 모양 중력적 잔해물, 별생성 증가 가능
## 4.3 충돌과 별생성
- 은하 충돌은 가스를 압축해 새로운 별 형성을 촉진할 수 있다.
- 예시: 안테나 은하
- 붉은 영역: 새로운 별이 왕성하게 형성되는 곳
## 4.4 우리은하와 안드로메다 은하의 충돌
- 약 40억 년 뒤 충돌 예측
- 약 20억 년 정도의 충돌 과정을 거쳐 타원은하로 진화할 가능성이 있다.
- 태양계는 지금보다 은하 외곽으로 밀려날 가능성
# 5. 활동성 은하핵(AGN)
## 5.1 정의와 특징
- AGN = 중심 영역에서 매우 격렬한 활동을 보이는 은하핵
- 원인: 은하 중심 초대질량 블랙홀

| 관측 특징 | 내용 |
|---|---|
| 제트/전파 버블 | 은하핵에서 방출, 은하보다 클 수 있음 |
| 강한 방출 | X선, 자외선, 전파 |
| 큰 광도 | 은하핵이 매우 밝음 |
| 밝기 변화 | 시간에 따라 급격히 변할 수 있음 |
-> WHY? 초대질량 블랙홀
## 5.2 AGN 엔진
| 구성 | 핵심 |
|---|---|
| 초대질량 블랙홀 | 주변 물질을 끌어들임 |
| 강착원반 | 별/가스/먼지가 빨려 들어가며 형성 |
| 자기장 | 왜곡/뒤틀림에 의해 제트 생성 |
| 제트 | 빛의 속도에 가까운 고온 가스 방출 |
| 로브 | 제트 속도가 줄어드는 지점에서 형성 |
- 예시: 전파 은하 Centaurus A
## 5.3 AGN 통합 모형
- 같은 물리 구조도 관측 방향에 따라 다르게 보임

| 관측 형태 | 특징 |
|---|---|
| 블레이자 | 활동핵 가장 밝음, 급격한 밝기 변화 |
| 퀘이사 | 활동핵 밝음, 전파 제트 보임 |
| 전파 은하 | 활동핵은 잘 안 보이나 강한 전파 제트 |
## 5.4 은하와 초대질량 블랙홀의 관계
- 모든 은하 중심부에는 초대질량 블랙홀이 있는 것으로 설명
- 블랙홀 질량과 은하 질량은 비례 경향
- 은하 병합 과정에서 물질이 중심부로 유입되며 블랙홀이 성장한다.
- SMBM - Host galaxy, co-evolution
## 5.5 퀘이사와 AGN 단계
- 퀘이사 = 은하 진화 중 중심부 블랙홀이 강하게 에너지 방출하는 단계
- 은하 병합으로 초대질량 블랙홀에 물질이 유입되면 AGN 모드가 가능하다.
- 같은 AGN도 방향에 따라 블레이자/퀘이사/전파은하
- 우리은하도 과거 AGN 단계 가능성
- 우리은하 근처 퀘이사 적음, 먼 우주에서 주로 발견 <- 우주 초기
## 5.6 우리은하의 페르미 버블
- 감마선 우주 망원경으로 발견
- 우리은하 중심 위아래의 거대한 고에너지 버블
- 과거 우리은하의 AGN 모드 흔적일 가능성
