# 천문학의세계 노트 정리 방식

## 기본 원칙

- PDF 해시값, evidence/source log, case summary 같은 포렌식식 기록은 작성하지 않는다.
- 기존 YAML 메타데이터가 있으면 지우지 말고 유지한다.
- 전체 요약, 압축 요약, 예상 문제, 시험 대비 포인트, 별도 개념도 등 사용자가 요청하지 않은 보조 섹션은 추가하지 않는다.
- 문서는 별도 제목이나 개요 없이 바로 본론으로 시작한다. 첫 줄은 `# 1. ...` 형태의 첫 대제목이어야 한다.
- PDF 페이지 순서를 기계적으로 따라가지 말고, 강의 내용을 파악해 자연스러운 개념 흐름으로 재구성한다.
- 페이지 번호, `근거: p.xx`, 슬라이드 번호 표기는 남기지 않는다.

## 제목 구조

- 대제목/중제목/소제목을 균형 있게 사용한다.
  - 큰 장: `# 1. ...`
  - 하위 주제: `## 1.1 ...`
  - 세부 구분이 있으면: `### 1.1.1 ...`
- 모든 항목을 대제목으로 만들지 않는다.
- 소제목을 아예 생략하지도 않는다. 조건/과정/비교/관측 근거처럼 내용이 갈라지는 부분에는 `###`를 적극적으로 사용한다.

## 내용 선별

- 원본에 있는 개념, 수치, 조건, 단계, 반응식은 최대한 빠짐없이 반영한다.
- 반복되거나 장식적인 내용은 줄이되, 개념 이해에 필요한 맥락은 짧게 보강한다.
- 사용자가 “핵심만” 또는 “쓸데없는 텍스트 제거”를 원하면 핵심 개념, 정의, 수치, 관계식, 단계만 남기고 서술형 부연은 줄인다.
- 노트는 최대한 simple하게 유지한다. 문장형 설명을 길게 늘리기보다 짧은 bullet, 표, 관계식 중심으로 정리한다.
- 원본/사용자 필기의 메모체 표현(`=>`, `->`, `<-`, `ps.` 등)은 의미가 살아 있으면 유지한다.
- `=>`, `->`를 모든 줄에 문체처럼 적용하지 않는다. 과정, 인과, 필기 흐름이 분명한 곳에만 제한적으로 사용한다.
- 이미지 중심 슬라이드는 보이는 대상을 그대로 나열하기보다, 강의 흐름에서 어떤 개념을 설명하는지 중심으로 정리한다.

## 표 사용

- 표가 더 명확한 내용은 문장 나열보다 표로 정리한다.
- 시간 순서, 관측값, 구성 비율, 개념 비교, 수식 기호 정의, 단계별 변화는 표 사용을 우선 고려한다.
- 다만 사용자가 요청하지 않은 “별도 비교표 섹션”을 문서 끝에 덧붙이지 않는다. 표는 관련 본문 섹션 안에 배치한다.

## 용어 통일

- `우리 은하`가 아니라 `우리은하`로 쓴다.
- 은하 중심의 거대 블랙홀은 `초대질량 블랙홀`로 쓴다.
- 우주의 종말 시나리오는 `Big Rip` 표기를 사용한다.

## 파일명

- 파일명은 `천문학의세계 - 주제명.md`처럼 사람이 바로 알아볼 수 있는 이름으로 작성한다.
