# 1. 우리은하의 기본 성질
## 1.1 우리은하의 의미
- 우리은하, Milky Way Galaxy = 태양계가 속한 은하
- 은하수 = 우리가 원반부 안에서 은하 원반을 바라본 모습
- 구성: 별 + 성간 기체 + 성간 먼지 + 암흑물질
## 1.2 주요 수치
| 항목 | 값/내용 |
|---|---|
| 은하 형태 | 막대나선은하 |
| 원반부 직경 | 약 `10만 광년` |
| 원반부 두께 | 약 `1000광년` |
| 전체 질량 | 약 `10^12 M_sun` |
| 별의 수 | 약 `10^11개` |
| 태양의 은하 중심 거리 | 약 `28,000-30,000광년` |
| 태양의 은하 공전 속도 | 약 `220 km/s` |
| 별 생성률 | 약 `1 M_sun/year` |
- `M_sun` = 태양 질량
- 전체 질량 대부분 = 암흑물질
# 2. 성간물질과 성간 소광
## 2.1 성간물질(Interstellar Matter)

| 성간물질  | 구성/역할                  |
| ----- | ---------------------- |
| 성간 기체 | 수소 원자, 수소 분자, 헬륨, 중금속  |
| 성간 먼지 | 작은 고체 입자, **별빛 흡수/산란** |
- 별 사이 공간의 희박한 물질
- 천문학의 중금속 = 수소/헬륨보다 무거운 모든 원소
## 2.2 성간 소광(Interstellar Extinction)
- 성간 먼지가 별빛을 흡수/산란
- 파장 짧을수록 강함

| 파장 영역 | 성간 먼지 영향    |
| ----- | ----------- |
| 가시광선  | 크게 가려짐      |
| 적외선   | 가시광선보다 잘 통과 |
| 전파    | 거의 영향 없음    |
- 우리은하 중심부 관측: 가시광선보다 적외선/전파 사용
# 3. 우리은하의 구성 성분
## 3.1 일반 물질과 암흑물질
| 구성 성분 | 전체 질량 대비 비율 | 대략적 질량          |
| ----- | ----------: | --------------- |
| 별     |       약 10% | 약 `10^11 M_sun` |
| 가스    |        약 1% | 약 `10^10 M_sun` |
| 먼지    |     약 0.01% | 약 `10^8 M_sun`  |
| 암흑물질  |       약 90% | 전체 질량 대부분       |
- 보이는 물질만으로는 우리은하 질량 설명 어려움
- 나머지 질량은 빛으로 보이지 않지만 중력을 만드는 암흑물질로 설명된다.
# 4. 우리은하의 구조
## 4.1 전체 구조
| 구조  | 형태/위치           | 주요 특징                 | 운동             |
| --- | --------------- | --------------------- | -------------- |
| 원반부 | 납작한 원반          | 젊은 별, 가스, 먼지, 별생성     | 같은 방향의 규칙적 회전  |
| 팽대부 | 은하 중심부          | 늙은 별, 높은 별 밀도, 중심 블랙홀 | 방향 다양          |
| 헤일로 | 원반/팽대부 주변 구형 영역 | 늙은 별, 구상성단, 암흑물질      | 무작위적, 타원 궤도 많음 |
## 4.2 원반부와 나선팔
- 우리은하 = 중심부 막대 구조가 있는 막대나선은하
- 원반부: 은하 중심 기준 회전, 젊은 별/성간물질 많음
- 막대에서 여러 나선팔이 뻗어 나옴
- 태양계 위치: 오리온 가지, Orion Spur
## 4.3 팽대부, 헤일로, 구상성단
- 팽대부: 중심부, 별 밀도 높음, 늙은 별 많음
- 헤일로: 원반/팽대부를 둘러싼 구형 영역, 암흑물질 많음
- 구상성단, globular cluster: 수십만-수백만 개 별이 둥글게 모인 집단
- 구상성단 위치: 주로 헤일로
- 의미: 우리은하 초기 형성과 진화 연구 단서
# 5. 우리은하의 질량 측정
## 5.1 밝기를 이용한 질량 추정
```text
M = (M/L) x L
```

| 기호    | 의미     |
| ----- | ------ |
| `M`   | 질량     |
| `L`   | 광도     |
| `M/L` | 질량-광도비 |
- 장점: 빛을 내는 물질 질량 추정
- 한계: 암흑물질 질량 직접 측정 어려움
## 5.2 운동을 이용한 질량 추정
```text
mv^2 / r = GM(r)m / r^2
M(r) = rv^2 / G
```

| 기호     | 의미                           |
| ------ | ---------------------------- |
| `M(r)` | 반지름 `r` 안쪽 질량, enclosed mass |
| `r`    | 별과 은하 중심 사이 거리               |
| `v`    | 별의 공전 속도                     |
| `G`    | 중력상수                         |
## 5.3 태양 궤도로 본 질량
| 항목           | 값               |
| ------------ | --------------- |
| 태양 공전 속도     | 약 `220 km/s`    |
| 태양의 은하 중심 거리 | 약 `28,000광년`    |
| 태양 궤도 안쪽 질량  | 약 `10^11 M_sun` |
- 운동으로 추정한 질량 > 밝기로 추정한 질량
- 이 차이는 암흑물질의 존재를 시사한다.
# 6. 우리은하의 회전곡선과 암흑물질
## 6.1 회전곡선(Galaxy Rotation Curve)
- 은하 중심 거리와 별 공전 속도 관계

| 구분  | 예상/관측                                          | 의미                 |
| --- | ---------------------------------------------- | ------------------ |
| 예상  | 중심에서 멀수록 `v = sqrt(GM/r)` 감소                   | 보이는 물질이 중심에 모여 있다면 |
| 실제  | 외곽에서도 약 `220 km/s`로 거의 일정                      | 편평한 회전곡선           |
| 결론  | `M(r) = rv^2/G`, `v`가 일정하면 `M(r)`은 `r`에 비례해 증가 | 외곽에 보이지 않는 질량 필요   |
- 편평한 회전곡선 = 우리은하 암흑물질의 대표 증거
## 6.2 암흑물질
- 암흑물질 = 전자기파 방출/흡수 X, 중력 O
- 우리은하 회전곡선과 전체 질량 분포 설명에 필요

| 종류        | 의미/예시                     | 한계/특징                  |
| --------- | ------------------------- | ---------------------- |
| 바리온 암흑물질  | 어두운 천체, 백색왜성, 중성자별, 블랙홀 등 | MACHO만으로 필요량 설명 어려움    |
| 비바리온 암흑물질 | 일반 물질이 아닌 새로운 물질          | 관측상 대부분의 암흑물질 후보       |
| CDM       | 차가운 암흑물질                  | 현재 대규모 구조 형성 설명에 가장 유리 |
| WDM       | 따뜻한 암흑물질                  |                        |
| HDM       | 뜨거운 암흑물질                  |                        |
# 7. 우리은하의 중심
## 7.1 은하 중심부 관측
- 중심 방향에는 성간 먼지가 많아 가시광선 관측이 어렵다.

| 파장  | 관측 의미                  |
| --- | ---------------------- |
| 전파  | 먼지 영향 적음, 은하 중심 전파원 관측 |
| 적외선 | 먼지를 통과해 중심부 별/구조 관측    |
| X선  | 고에너지 현상 관측             |
## 7.2 궁수자리 A별과 초대질량 블랙홀
- 궁수자리 A별, `Sgr A*` = 우리은하 중심의 강한 전파원
- `Sgr A*`는 중심 초대질량 블랙홀과 관련
- 주변 관측: 초신성 잔해, 전파 필라멘트, 강한 자기장, 고온 가스, X선 방출원

| 증거 | 의미 |
|---|---|
| 중심 근처 별들의 빠른 궤도 운동 | 작은 영역에 큰 질량 집중 |
| 질량 | 태양 질량 약 `400만 배` |
| 해석 | 초대질량 블랙홀 |
| EHT 관측 | `Sgr A*` 주변 고리 모양 구조 |
- 펜로즈, 겐첼, 게즈: 관련 연구로 2020년 노벨물리학상

# 9. 우리은하의 형성
## 9.1 계층적 병합
- 우리은하 = 작은 은하들이 반복적으로 합쳐지며 성장
- 계층적 병합, hierarchical merging 모형
## 9.2 형성 과정
| 순서  | 과정                 |
| --- | ------------------ |
| 1   | 암흑물질 헤일로 먼저 형성     |
| 2   | 암흑물질 중력으로 가스 모임    |
| 3   | 가스 냉각/수축           |
| 4   | 회전하는 가스가 납작한 원반 형성 |
| 5   | 가스에서 새 별 형성        |
| 6   | 작은 은하들과 반복 병합      |
| 7   | 병합 과정에서 팽대부/헤일로 성장 |
| 8   | 원반/나선팔 구조 발달       |
## 9.3 은하 병합의 흔적
- 왜소은하가 병합되면 **별흐름**(Stellar Stream)이 형성될 수 있다.
- 대표 예: 궁수자리 별흐름, Sagittarius stream
- SDSS 같은 대규모 관측에서 우리은하 주변의 별흐름이 발견되었다.
- 별흐름 = 과거 왜소은하 병합 증거, 계층적 병합 지지
