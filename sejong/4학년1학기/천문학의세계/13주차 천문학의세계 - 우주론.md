# 1. 우주의 시작과 올버스 역설
## 1.1 올버스 역설
- 질문: 왜 밤하늘은 어두운가?
- 정적인 무한 우주라면 별빛이 모든 방향에서 오므로 밤하늘은 밝아야 한다.
- 실제 밤하늘은 어두움
- 결론: 우주는 무한히 오래된 정적 우주가 아닐 가능성
## 1.2 밝기와 별 개수의 보상
| 요소             | 거리 증가에 따른 변화    | 의미                    |
| -------------- | --------------- | --------------------- |
| 별 하나의 밝기       | 거리의 제곱에 반비례해 감소 | 멀수록 희미                |
| 같은 거리 껍질의 별 개수 | 거리의 제곱에 비례해 증가  | 멀수록 별 수 증가            |
| 결과             | 감소와 증가가 보상      | 정적 무한 우주라면 밤하늘은 밝아야 함 |
## 1.3 팽창 우주와 연결
- 올버스 역설은 우주의 나이가 유한할 가능성을 암시한다.
- 허블의 우주 팽창 관측과 연결
- 과거 우주: 더 작고, 밀도/온도 높음
# 2. 팽창하는 우주
## 2.1 허블-르메트르 법칙
- 모든 은하는 우리은하로부터 멀어지고 있다.
- 더 먼 은하일수록 더 큰 **적색이동**과 후퇴속도를 보인다.
	- 안드로메다 은하는 예외: 중력의 작용이 적색이동보다 큼
- 외부 은하 거리와 적색이동 관계 = **허블-르메트르 법칙**
## 2.2 우주론적 원리
- 모든 방향에서 은하가 멀어진다고 해서 우리은하가 중심이라는 뜻은 아니다.
- 우주 팽창은 어디서나 거의 비슷하게 관측
- 우주론적 원리: **큰 규모에서 특별한 중심/방향 없음**
## 2.3 적색이동과 관측 가능한 우주
- 시공간이 팽창하면 광자 파장도 함께 길어진다.
- 파장 증가 = 적색이동

| 구분                  | 값/내용                  |
| ------------------- | --------------------- |
| 우주의 나이              | 약 138억 년              |
| 팽창 없다고 가정한 관측 가능 거리 | 약 138억 광년             |
| 시공간 팽창 고려한 관측 가능 반경 | 약 480억 광년             |
| 이유                  | 빛이 오는 동안 우주 공간 자체가 팽창 |
# 3. 빅뱅과 초기 우주
## 3.1 빅뱅의 의미
- 과거로 갈수록 우주 부피 감소, 밀도/온도 증가
- 빅뱅 = 매우 작고 밀도 큰 초기 상태에서 시작했다는 설명
- 공간 안의 폭발 X, **공간 자체의 팽창**
- 특정 위치 사건 X, **모든 곳에서 동시에 일어난 사건**
- 빅뱅 모델은 빅뱅 순간보다 이후 우주 진화를 설명
## 3.2 초기 우주의 시간 순서
| 시기         | 핵심 상태/사건                       |
| ---------- | ------------------------------ |
| `10^-47 s` | 양성자보다 수천억 배 작음, 온도 약 `10^32 K` |
| 빅뱅 직후      | 주로 에너지 형태                      |
| `10^-6 s`  | 쿼크, 전자, 뉴트리노, 반입자 등 형성         |
| `10^-2 s`  | 쿼크 -> 양성자/중성자                  |
| 이후         | 팽창/냉각 -> 원자핵, 원자 구조            |
- 입자와 반입자가 반응하면 빛으로 변환된다.
- 빛이 다시 입자-반입자로 바뀌는 과정도 이어져 혼돈 상태가 지속되었다.
## 3.3 우주론적 핵융합
- 온도가 **수백억 도** 수준으로 떨어지면 **양성자/중성자 사이에 강력**이 작용한다.
- 양성자와 중성자가 원자핵을 만드는 과정이 **우주론적 핵융합**이다.
- 우주 나이 **약 3분**에는 거의 모든 **중성자가 원자핵으로 묶였다.**

| 성분           | 비율/특징           |
| ------------ | --------------- |
| 수소           | 보통 물질 질량의 약 75% |
| 헬륨           | 보통 물질 질량의 약 25% |
| 중수소, 리튬, 베릴륨 | 아주 적은 양         |
## 3.4 원자의 형성과 우주 배경 복사
| 시기/조건         | 사건                                   |
| ------------- | ------------------------------------ |
| 초기 우주         | 원자핵, 전자, 광자가 섞인 **플라즈마**             |
| 빅뱅 이후 약 30만 년 | 전자 + 원자핵 -> 안정적 원자                   |
| 온도 약 `3000 K` | 광자가 자유롭게 진행 가능                       |
| 현재            | 당시 빛이 팽창으로 길어져 마이크로파로 관측 -> 우주 배경 복사 |
# 4. 우주 배경 복사와 밀도 요동
## 4.1 우주 배경 복사
| 관측     |   시기 | 의미                |
| ------ | ---: | ----------------- |
| COBE   | 1989 | 우주 배경 복사 성질 관측    |
| WMAP   | 2001 | 우주 배경 복사 요동 정밀 관측 |
| Planck | 2009 | 더 정밀한 우주 배경 복사 지도 |
- 평균 온도: 약 `2.725 K`
- 초기 뜨겁고 밀도 높던 우주의 흔적
- 붉은 영역 = 상대적으로 온도 높음, 푸른 영역 = 상대적으로 온도 낮음
## 4.2 온도 요동과 밀도 요동
- 우주 배경 복사: 거의 균일하지만 작은 **온도 요동 존재**
- 각크기: 약 0.0001도
- 온도 요동은 **물질 밀도 요동**으로 이어진다.
- 밀도 요동은 이후 은하와 거대 구조의 씨앗이 된다.
## 4.3 양자 요동과 인플레이션
- 초기 온도/밀도 요동의 기원 = 빅뱅 직후 **양자 요동**
- 약 `10^-43 s`-`10^-34 s`: 인플레이션, 급격한 팽창
- 양자 요동은 인플레이션을 통해 우주적 규모로 확대되어 밀도 요동이 된다.
- 인플레이션은 **상전이**(phase transition)로 발생했을 가능성
  - 상전이 = 물질/장의 상태가 특정 조건에서 갑자기 **다른 상태로 바뀌는 현상**
  - 예시: 물이 얼음이 되거나 수증기가 되는 변화
  - 초기 우주에서는 상전이 과정에서 방출된 에너지가 급격한 팽창을 일으켰을 가능성
# 5. 암흑기와 우주의 거대 구조
## 5.1 우주의 암흑기
- 우주가 팽창하고 식으면서 **광자 에너지가 감소**한다.
- 어느 시점부터 가시광선 영역에서 보이지 않음
- **수억 년 지속 = 우주론적 암흑기**
## 5.2 거대 구조의 형성
- 빛보다 물질의 중력 효과가 중요해지는 시기 도달
- 초기 밀도 요동 = 주변 물질을 끌어모으는 씨앗
- 밀도가 높은 영역은 더 많은 물질을 끌어모으며 구조로 성장한다.
- 암흑 물질이 구조 형성 주도

| 구조   | 특징                 |
| ---- | ------------------ |
| 필라멘트 | 물질 밀도가 높은 거대 연결 구조 |
| 보이드  | 물질 밀도가 낮은 빈 공간     |
## 5.3 최초의 별: Pop III
| 항목    | Pop III 별                      |
| ----- | ------------------------------ |
| 구성    | 중금속 거의 없음, **수소/헬륨 중심**        |
| 형성 환경 | 초기 거대 구조 안의 수소 가스              |
| 질량/밝기 | 오늘날 별보다 훨씬 **무겁고 밝음**          |
| 역할    | core-collapse 초신성으로 **중금속 방출** |
- 2세대 별: 중금속 함량 높고, 질량/밝기 상대적으로 작음
- Pop III 별의 잔해 블랙홀은 초대질량 블랙홀의 씨앗이 되었을 가능성이 있다.

# 7. 우주의 운명과 암흑 에너지
## 7.1 임계 밀도와 밀도 파라미터
- 임계 밀도: 현재 우주의 팽창을 정지시킬 수 있는 밀도 (`수소원자5개/m^3`)
```text
Omega = rho / rho_c
```

| 기호      | 의미               |
| ------- | ---------------- |
| `rho`   | 우주의 실제 평균 밀도     |
| `rho_c` | 우주의 임계 밀도        |
| `Omega` | 실제 평균 밀도 / 임계 밀도 |
## 7.2 flat, open, closed 우주
| `Omega`     | 우주 모형                  | 설명                      |
| ----------- | ---------------------- | ----------------------- |
| `Omega = 1` | 편평한 우주, flat universe  | 계속 팽창, 감속/가속은 구성 성분에 좌우 |
| `Omega < 1` | 열린 우주, open universe   | 중력 약함, 팽창 되돌리기 어려움      |
| `Omega > 1` | 닫힌 우주, closed universe | 중력 강함, 팽창 정지/수축 가능      |
- 관측적으로 우리 우주: `Omega ~ 1`, 편평한 우주
- 미래 팽창은 공간 기하 + 암흑 에너지까지 고려
## 7.3 우주의 구성 성분
```text
Omega = Omega_m + Omega_rel + Omega_Lambda
```

| 성분             | 의미              | 포함                |
| -------------- | --------------- | ----------------- |
| `Omega_m`      | 물질 밀도 파라미터      | 일반 물질 + 암흑 물질     |
| `Omega_rel`    | 상대론적 성분 밀도 파라미터 | 광자 + 뉴트리노 등 복사에너지 |
| `Omega_Lambda` | 암흑 에너지 밀도 파라미터  | 암흑 에너지            |

| 성분 | 비율 |
|---|---:|
| 일반 물질 | 약 4% |
| 암흑 물질 | 약 23% |
| 암흑 에너지 | 약 73% |
## 7.4 가속 팽창과 암흑 에너지
- 1998년 **type Ia 초신성 관측**(`1.4 M_sun`)으로 **우주 가속 팽창**이 확인되었다.
- 먼 초신성이 예상보다 어둡게 보였고, 이는 **예상보다 더 멀리 있다는 뜻으로 해석**되었다.
- 팽창률: 과거처럼 계속 느려진 것이 아니라 최근 가속

| 성분     | 우주 팽창에 따른 변화                      |
| ------ | --------------------------------- |
| 물질     | 같은 양이 더 큰 부피에 퍼지므로 밀도 감소          |
| 암흑 에너지 | 공간 자체의 에너지처럼 취급되어 단위 부피당 밀도 거의 일정 |
- 우주가 팽창하면서 `Omega_m`의 상대 비중은 감소한다.
- 새 공간에도 같은 암흑 에너지 밀도가 있다고 봄
- 결과: 암흑 에너지 상대 비중 증가
## 7.5 우주의 종말
- 약 60억 년 전부터 암흑 에너지가 우주 팽창을 지배하며 가속 팽창이 시작되었다.
- 장기적으로 은하 사이 공간 증가, 우주 밀도 감소, 점점 어두워짐
### 7.5.1 Big Rip
- 가정: 암흑 에너지 밀도가 시간에 따라 급격히 증가
- 결과: 가속 팽창 극단화
- 은하, 별, 원자까지 분리될 수 있는 종말 시나리오
