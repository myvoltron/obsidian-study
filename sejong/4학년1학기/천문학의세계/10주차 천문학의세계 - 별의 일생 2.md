# 1. 항성 진화의 기본 원리
## 1.1 중력수축과 내부 압력
- 별 내부: 안쪽 **중력수축** vs 바깥쪽 **내부 압력**
- 압력: 기체압, 복사압, 축퇴압
- 별의 일생 = 핵융합 연료 변화 + 중력/압력의 새 평형 찾기

| 압력 | 의미 | 관련 단계 |
|---|---|---|
| 기체압 | 수소 기체 자체가 만드는 압력 | 주계열성, 거성 |
| 복사압 | 핵융합으로 생긴 빛/복사가 만드는 압력 | 질량 큰 밝은 별 |
| 전자축퇴압 | 전자의 양자역학적 효과 | 백색왜성, 저질량별의 헬륨 핵 |
| 중성자축퇴압 | 중성자의 양자역학적 효과 | 중성자별 |
## 1.2 항성 진화
- 중심부 연료가 변하거나 소진되면 기존 평형이 깨진다.
- 반지름, 표면 온도, 광도 변화
- 시간에 따른 물리적 변화 = **항성 진화**
# 2. H-R(Hertzsprung-Russell) 다이어그램
![[Pasted image 20260614175843.png]]
## 2.1 의미와 축
| 항목 | 의미 |
|---|---|
| H-R 다이어그램 | 별의 표면 온도와 광도 관계 |
| 세로축 위 | 광도 큼, 밝음 |
| 세로축 아래 | 광도 작음, 어두움 |
| 가로축 왼쪽 | 표면 온도 높음, 푸른색 |
| 가로축 오른쪽 | 표면 온도 낮음, 붉은색 |
| 태양 위치 | 중간 온도, `1 L_sun` |
- 별의 위치를 보면 현재 상태와 진화 단계를 추정할 수 있다.
## 2.2 주요 영역
| 영역 | 위치 | 의미 |
|---|---|---|
| 주계열 | 왼쪽 위 -> 오른쪽 아래 띠 | 중심부 수소 핵융합 |
| 적색거성 | 오른쪽 위 | 낮은 표면온도 + 큰 반지름 때문에 광도 큼 |
| 초거성 | 매우 높은 광도 | 매우 크고 밝은 별 |
| 백색왜성 | 왼쪽 아래 | 뜨겁지만 작아서 어두움 |
## 2.3 광도와 반지름
```text
L = 4 pi R^2 sigma T^4
```

| 기호 | 의미 |
|---|---|
| `L` | 광도 |
| `R` | 반지름 |
| `T` | 표면 온도 |
| `sigma` | 슈테판-볼츠만 상수 |
- 같은 온도라면 반지름이 큰 별이 더 밝다.
- 적색거성은 차갑지만 반지름이 커서 밝다.
- 백색왜성은 뜨겁지만 반지름이 작아서 어둡다.
- 질량이 큰 별은 중심온도가 높고 핵융합이 빨라 밝고 뜨거운 주계열에 놓인다.
# 3. 항성 진화의 전체 흐름
## 3.1 공통 단계
| 단계 | 핵심 변화 |
|---|---|
| 전주계열 | 성간 가스 구름 중력수축 -> 원시성 |
| 주계열 | 중심부 수소 핵융합 |
| 거성 | 중심 수소 소진 -> 핵 수축, 외곽층 팽창 |
| 후기 핵융합 | 질량에 따라 헬륨/무거운 원소 핵융합 |
| 점근거성 | 저질량/중간질량 별의 후기 거성 단계 |
| 마지막 단계 | 백색왜성, 중성자별, 블랙홀 |
- ZAMS = 중심부 수소 핵융합을 안정적으로 시작한 시점
## 3.2 질량에 따른 분기
| 초기 질량 | 후기 진화 | 마지막 잔해 |
|---|---|---|
| 작은 별, `< 8 M_sun` | 적색거성 -> 점근거성 -> 외곽층 방출 | 백색왜성 |
| 큰 별, `> 8 M_sun` | 초거성 -> 무거운 원소 핵융합 -> 중심핵 붕괴 | 중성자별/블랙홀 |
- 초기 질량 = 중심온도, 핵융합 단계, 수명, 최종 운명 결정
# 4. 전주계열과 주계열
## 4.1 전주계열
- 성간 가스 구름 중력수축
- 중력 위치에너지가 열운동에너지로 바뀐다.
- 중심부 온도와 압력이 증가하며 원시성이 형성된다.
- 원자가 전리되어 플라즈마 상태가 된다.
- 중심온도 수백만 도 이상에서 수소 핵융합이 시작되고 주계열 단계로 들어간다.
## 4.2 주계열
- 중심부 수소가 헬륨으로 바뀌며 에너지를 낸다.
- 핵융합 에너지가 내부 압력을 유지한다.
- 내부 압력과 중력이 균형을 이루면 별은 안정하다.
- 별의 일생 중 가장 안정적인 단계

| 주계열 위치 | 별의 성질 |
|---|---|
| 왼쪽 위 | 질량 큼, 표면 온도 높음, 광도 큼, 핵융합 빠름 |
| 오른쪽 아래 | 질량 작음, 표면 온도 낮음, 광도 작음, 핵융합 느림 |
# 5. 거성 단계
## 5.1 중심 수소 소진
- 주계열 동안 중심부 수소는 헬륨으로 바뀐다.
- 중심 수소가 거의 소진되면 중심부 핵융합이 약해진다.
- 남은 헬륨 핵은 수축하고 중심온도는 상승한다.
- 핵융합 압력이 줄어들면서 중력수축이 강해진다.
## 5.2 수소 껍질 핵융합과 적색거성
- 헬륨 핵 주변 수소층 존재
- 핵이 수축하면 온도와 압력이 올라가 수소 껍질 핵융합이 시작된다.
- 외곽층에 전달되는 에너지가 증가하면 바깥층이 팽창한다.
- 반지름이 커지고 표면온도가 낮아지면 **적색거성**이 된다.
- 표면 온도 `4500K-5000K`, 반지름 증가로 광도 큼
## 5.3 태양의 미래
| 항목 | 내용 |
|---|---|
| 현재 태양 | 주계열성 |
| 주계열 이탈 | 약 50억 년 후 |
| 이후 단계 | 준거성 -> 적색거성 |
| 반지름 변화 | 현재보다 수십 배-백 배 이상 팽창 가능 |
| 지구 환경 | 더 강한 복사 에너지 -> 현재 생명체 거주 환경 유지 어려움<br>ps. 현재 태양-지구 거리 약 1억 5천만 KM |
# 6. 노년기의 핵융합
## 6.1 질량별 헬륨 연소
- 축퇴 상태: 온도/압력 변화에도 쉽게 팽창/수축하지 않는 상태

| 질량 범위 | 중심핵 상태 | 헬륨 핵융합 시작 | 이후 변화 |
|---|---|---|---|
| `0.5-2.5 M_sun` | 헬륨 핵 축퇴 | 헬륨 핵섬광 | 수평계열 또는 유사 영역 |
| `2.5-8 M_sun` | 강한 축퇴 없음 | 안정적 헬륨 연소 | 더 높은 온도 방향 이동 가능 |
| `> 8 M_sun` | 중심온도/압력 매우 높음 | 헬륨 이후 무거운 원소 연소 | 초거성, 강한 항성풍, 초신성 가능 |
## 6.2 헬륨 핵섬광
- 저질량별의 헬륨 핵은 고밀도 축퇴 상태가 될 수 있다.
- 축퇴 상태: 온도 상승에도 팽창/냉각 어려움
- 중심온도 약 `1억 K`에 도달하면 헬륨 핵융합이 시작된다.
- 반응이 급격히 진행되어 짧은 시간에 큰 에너지를 방출하는 현상이 **헬륨 핵섬광**이다.
- 이후 헬륨은 탄소/산소로 바뀐다.
- 태양 정도 질량: 탄소 핵융합까지 진행 X
## 6.3 무거운 별의 후기 진화
- 수소, 헬륨 이후 탄소/네온/산소/규소 연소까지 가능하다.
- 강한 항성풍으로 바깥층을 잃을 수 있다.
- 내부 헬륨, 탄소, 질소, 산소 층 노출 가능
- 후기 단계: 청색초거성, 적색초거성, 밝은 청색 변광성, 울프-레이에 별
- 울프-레이에 별: 강한 항성풍 + 높은 표면 온도
# 7. 점근거성 단계
## 7.1 대상과 구조
- 점근거성 = AGB(Asymptotic Giant Branch)
- 대상: 작은 별/중간질량 별의 후기 진화
- 중심 헬륨이 소진되면 탄소-산소 핵이 남는다.
- 핵융합 위치: 중심부 X, 중심핵 주변 껍질

| 위치 | 핵융합 |
|---|---|
| 중심핵 | 탄소-산소 핵, 활발한 핵융합 없음 |
| 안쪽 껍질 | 헬륨 껍질 핵융합 |
| 바깥 껍질 | 수소 껍질 핵융합 |
## 7.2 H-R 다이어그램에서의 이동
- 껍질 핵융합으로 외곽층에 전달되는 에너지가 증가한다.
- 별 팽창 + 표면온도 감소
- H-R 다이어그램 오른쪽 위로 이동
# 8. 별의 마지막 단계
## 8.1 작은 별: 행성상 성운과 백색왜성
- 탄소 이후 핵융합 X
- 점근거성 단계에서 외곽층이 방출되고 중심에는 탄소-산소 핵이 남는다.
- 중심핵 = **백색왜성**
- 백색왜성: 핵융합 X, 서서히 냉각
- 방출된 외곽층이 백색왜성의 자외선에 의해 이온화되면 **행성상 성운**으로 보인다.
- 행성상 성운: 실제 행성과 관련 X, 초기 망원경에서 둥글고 흐릿해 붙은 이름
## 8.2 큰 별: 초신성, 중성자별, 블랙홀
### 8.2.1 철핵 형성
- 큰 별: 수소/헬륨 이후 무거운 원소 핵융합
- 연료가 소진될 때마다 중심핵은 수축하고, 더 높은 온도에서 다음 핵융합이 시작된다.
- 철 근처까지 진행 가능
- 철: 핵융합해도 에너지 방출 효율 X
### 8.2.2 중심핵 붕괴와 초신성
- 철핵이 형성되면 핵융합 에너지로 중력을 지탱하기 어렵다.
- 중심핵 급격히 붕괴 + 바깥층 낙하 => **중심핵 붕괴**
- 충격파가 외곽층을 방출하면 **초신성 폭발**로 관측된다.
- SN1987A: 초신성 전후 밝기 변화 대표 사례
### 8.2.3 최종 잔해
| 남은 중심핵 조건 | 최종 천체 |
|---|---|
| 비교적 작은 중심핵 | 중성자별 |
| 더 무거운 중심핵 | 블랙홀 |
- 초신성은 무거운 원소를 우주 공간으로 방출한다.
- 방출된 물질은 새로운 별, 행성, 생명체의 재료가 될 수 있다.
