# 1. 별과 별 형성
## 1.1 별의 기본 관점
- 별 = 형성과 진화의 관점에서 이해
- 태양 = 가장 가까운 별, 다른 별 이해의 기준
- 별 = 내부 구조 + 표면 활동 + 핵융합을 가진 물리적 천체
## 1.2 별의 정의와 재료
| 항목 | 핵심 |
|---|---|
| 별/항성 | 중력수축한 수소 가스 구름에서 형성, 핵융합으로 빛남 |
| 주요 재료 | 수소, 헬륨, 소량의 무거운 원소 |
| 수소 원자 | 전자 1개 + 양성자 1개 |
| 수소 원자 크기 | 약 `0.1 nm = 10^-10 m` |
| 형성 장소 | 성간 가스와 먼지가 모인 성운 |
- 별 형성 과정: 물질 유입 + 원반 형성 + 제트/분출류
# 2. 태양계와 별의 형성
## 2.1 원시 먼지/가스 구름
| 물리량 | 값/내용 |
|---|---|
| 구성 | 수소, 헬륨, 무거운 원소 |
| 밀도 | 약 `10^6 / cm^3` |
| 온도 | 약 `10-50 K` |
| 질량 조건 | 진스 질량의 수천 배 |
- 태양계 시작: 원시 먼지/가스 구름의 중력수축
- 진스 질량보다 충분히 큰 구름은 자체 중력으로 붕괴할 수 있다.
- 인접 초신성의 충격파는 구름 수축과 자전을 유도할 수 있다.
- 큰 구름은 여러 조각으로 분열하고, 각 조각이 별을 만들 수 있다.
## 2.2 원시 태양과 원시행성계 원반
### 2.2.1 원시 태양
- 초기 별 = T-Tauri 별
- 원시 태양 질량 > 현재 태양 질량
- 핵융합이 시작되면 항성풍이 강해지고 주변 물질/각운동량 분포가 변한다.
### 2.2.2 원반과 행성 형성
| 단계 | 핵심 과정 |
|---|---|
| 원반 형성 | 각운동량 때문에 중심 별 주변에 원반 형성 |
| 각운동량 전달 | 중력/점성 토크와 입자 충돌로 각운동량이 외곽으로 이동 |
| 먼지 성장 | 반 데르 발스 힘과 충돌로 `micrometer` 입자가 `mm` 수준까지 성장 |
| 미행성 형성 | 입자 충돌이 누적되어 수 m-km 크기 형성 |
| 행성 형성 | 미행성 충돌 + 중력 상호작용 |
## 2.3 행성 형성 시간 규모
| 행성 종류 | 형성 시간 규모 |
|---|---|
| 목성/토성 | 수천 년-만 년 |
| 지구형 행성 | 수백만 년-천만 년 |
| 천왕성/해왕성 | 수천만 년-억 년 |
# 3. 항성 내부 구조와 평형
## 3.1 내부 구조 물리량
| 기호 | 의미 |
|---|---|
| `P(r)` | 반지름 `r`에서의 압력 |
| `L(r)` | 반지름 `r` 안쪽에서 생성/통과하는 광도 |
| `M(r)` | 반지름 `r` 안쪽에 포함된 질량 |
| `T(r)` | 반지름 `r`에서의 온도 |
- 변화율 `dP/dr`, `dL/dr`, `dM/dr`, `dT/dr`은 평형, 질량 분포, 에너지 생성/전달을 나타낸다.
- 중심부에서 생성된 에너지는 복사층/대류층을 지나 표면으로 전달된다.
### 3.1.1 태양의 내부와 대기층
| 층 | 위치/성격 | 핵심 역할 |
|---|---|---|
| 중심핵, core | 가장 안쪽 | 수소 핵융합, 에너지 생성 |
| 복사층, radiative zone | 중심핵 바깥 | 광자 흡수/재방출로 에너지 전달 |
| 대류층, convective zone | 복사층 바깥 | 플라즈마 대류로 에너지 전달 |
| 광구, photosphere | 보이는 표면 | 가시광선 대부분 방출 |
| 채층, chromosphere | 광구 위 | 붉은빛, 홍염 등 태양 활동 |
| 코로나, corona | 가장 바깥 대기 | 매우 뜨겁고 희박, 개기일식 때 관측 |
## 3.2 별 내부의 압력
| 압력 | 의미 | 주요 상황 |
|---|---|---|
| 기체압 | 입자 열운동이 만드는 압력 | 일반적인 별 내부 |
| 복사압 | 빛/복사가 바깥쪽으로 미는 압력 | 매우 밝고 무거운 별 |
| 축퇴압 | 양자역학적 효과로 생기는 압력 | 백색왜성, 중성자별 |
- 안정 조건: 안쪽 중력 = 바깥쪽 내부 압력
- 태양 안정성: 중력-압력 평형 + 지속적 핵융합
# 4. 별의 에너지원: 핵융합
## 4.1 핵융합 조건
- 핵융합 = 가벼운 원자핵이 결합해 무거운 원자핵을 만들고 에너지를 방출하는 과정
- 원자핵은 양전하를 띠므로 서로 전기적으로 밀어낸다.
- 고온/고압에서는 원자핵이 빠르게 충돌해 반발력을 극복할 수 있다.

| 관계식 | 의미 |
|---|---|
| `E = 3/2 kT` | 온도가 높을수록 평균 열운동 에너지 증가 |
| `v = sqrt(3kT/m)` | 온도가 높을수록 입자 속도 증가 |
## 4.2 질량 결손과 에너지
- 핵융합 에너지 = 질량 결손에서 나옴
- 수소 4개가 헬륨 1개가 될 때 생성물 질량이 더 작다.
- 사라진 질량 `Delta m`은 `E = Delta m c^2`에 의해 에너지로 바뀐다.

| 항목 | 값/내용 |
|---|---|
| 수소 4개 -> 헬륨 1개 질량 차이 | 약 `4.6 x 10^-29 kg` |
| 방출 에너지 | 약 `4.1 x 10^-12 J` |
| 에너지 전환 비율 | 반응 질량의 약 `0.7%` |
| 수소 1 kg 기준 | 약 `6.4 x 10^14 J/kg` |
## 4.3 질량과 중심온도
- 질량이 큰 별일수록 중심온도와 압력이 높다.
- 중심온도가 높을수록 더 무거운 원소의 핵융합이 가능하다.
- 원자번호가 높은 원소일수록 핵융합에 더 높은 온도가 필요하다.
- 별의 질량은 주된 핵융합 반응과 진화를 결정한다.
# 5. 핵융합 반응과 원소 합성
## 5.1 수소 핵융합
| 반응 | 조건/대상 | 핵심 |
|---|---|---|
| pp-chain | 중심온도 약 2,000만 도 이하, 태양 정도 이하 | 수소 -> 헬륨, 태양의 주요 에너지원 |
| CNO-cycle | 중심온도 약 2,000만 도 이상, 약 `1.5 M_sun` 이상 | C, N, O 촉매로 수소 -> 헬륨 |
### 5.1.1 pp-chain
- 경로: ppI, ppII, ppIII
- 비율: ppI 약 91%, ppII 약 9%, ppIII 약 0.1%
- 방출: 양전자, 중성미자, 감마선
- 중심온도 `2000만도 이하` 별의 주요 에너지원
### 5.1.2 CNO-cycle
```text
12C + 1H -> 13N + gamma
13N -> 13C + e+ + neutrino
13C + 1H -> 14N + gamma
14N + 1H -> 15O + gamma
15O -> 15N + e+ + neutrino
15N + 1H -> 12C + 4He
```
- 전체 결과: 수소가 헬륨으로 바뀜
- `12C`는 마지막에 재생성되므로 촉매 역할
- 중심온도 `2000만도 이상` 별의 주요 에너지원
## 5.2 헬륨 핵융합: 3중 알파 반응
- 조건: 중심온도 약 `1억 도` 이상
- 헬륨 원자핵 = 양성자 2개 + 중성자 2개 = **알파입자**
	- 별 중심부에서는 대부분 전자를 잃은 핵 형태로 존재함 -> **전리 상태**
- 핵심: 헬륨 3개가 탄소를 만듦
```text
4He + 4He -> 8Be + gamma
4He + 8Be -> 12C + gamma
```
- `8Be`는 매우 불안정하여 곧바로 헬륨핵 2개로 붕괴하기 쉽다.
- 그래서 Li/Be에 안정적으로 머무르기 어려움
- 결론: `8Be`의 불안정성 때문에 3중 알파 반응으로 `12C`가 형성된다.
## 5.3 그 외 핵융합과 원소 합성
- 질량 큰 별: 수소/헬륨 이후 무거운 원소 핵융합 가능
- 연료가 소진되면 중심핵이 수축하고, 중심온도가 올라가 다음 핵융합이 시작된다.
- 철 근처까지는 에너지 방출 가능
### 5.3.1 철까지 이어지는 핵융합
| 연소 단계 | 대표 반응/조건 | 생성 원소 |
|---|---|---|
| 탄소 연소 | 탄소 + 탄소, 중심온도 매우 높음 | Mg, Na, Ne, O |
| 산소 연소 | 산소 + 산소 | S, P, Si, Mg |
| 규소 연소 | 규소 + 규소 | Ni, Fe |
- 탄소, 산소, 규소 연소: 중심온도 약 `100억도` 이상에서 가능
### 5.3.2 철보다 무거운 원소
- 철보다 무거운 원소를 만들려면 에너지 공급이 필요하다.
- 일반적인 별 내부 핵융합만으로는 잘 생성 X
- 철핵이 형성되면 핵융합으로 중력을 지탱하기 어려워 중심핵 붕괴/초신성으로 이어질 수 있다.
- 초신성 폭발 같은 격렬한 사건에서는 중성자 포획으로 철보다 무거운 원소가 만들어질 수 있다.
