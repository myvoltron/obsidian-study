# 1. 별과 별 형성의 기본 관점
## 1.1 별을 보는 핵심 관점
- 별, 은하, 행성, 우주는 모두 **형성과 진화**의 관점에서 이해한다.
- 태양은 지구에서 가장 가까운 별이며, 다른 별을 이해하는 기준점이다.
- 별은 단순한 빛점이 아니라 내부 구조, 표면 활동, 에너지 생성 과정을 가진 물리적 천체이다.
## 1.2 별의 정의와 재료
| 항목       | 핵심 내용                               |
| -------- | ----------------------------------- |
| 별/항성     | 중력수축하는 수소 가스 구름에서 형성되어 핵융합으로 빛나는 천체 |
| 주요 재료    | 수소, 헬륨, 소량의 무거운 원소                  |
| 수소 원자    | 전자 1개 + 양성자 1개                      |
| 수소 원자 크기 | 약 `0.1 nm = 10^-10 m`               |
- 별은 성간 가스와 먼지가 모인 성운에서 만들어진다.
- 별 형성 과정에는 물질 유입, 원반 형성, 제트/분출류가 함께 나타날 수 있다.
# 2. 태양계와 별의 형성
## 2.1 원시 먼지/가스 구름
| 물리량 | 값/내용 |
|---|---|
| 구성 | 수소, 헬륨, 무거운 원소 |
| 밀도 | 약 `10^6 / cm^3` |
| 온도 | 약 `10-50 K` |
| 질량 조건 | 진스 질량의 수천 배 |
- 태양계는 원시 먼지/가스 구름의 중력수축에서 시작한다.
- 진스 질량보다 충분히 큰 구름은 자체 중력으로 붕괴할 수 있다.
- 인접한 초신성 폭발의 충격파는 구름 수축과 자전을 유도하는 외부 자극이 될 수 있다.
- 큰 구름은 수축하면서 여러 조각으로 분열하고, 각 조각은 독립적으로 별을 만들 수 있다.
## 2.2 원시 태양과 원시행성계 원반
### 2.2.1 원시 태양
- 초기 단계의 별은 T-Tauri 별로 설명된다.
- 원시 태양의 질량은 현재 태양 질량보다 컸다.
- 중심부에서 핵융합이 시작되면 항성풍이 강해지고, 주변 물질과 각운동량 분포가 변한다.
### 2.2.2 원반과 행성 형성
| 단계 | 핵심 과정 |
|---|---|
| 원반 형성 | 수축하는 구름의 각운동량 때문에 중심 별 주변에 원반 형성 |
| 각운동량 전달 | 중력/점성 토크와 입자 충돌로 각운동량이 원반 외곽으로 이동 |
| 먼지 성장 | 반 데르 발스 힘과 충돌로 `micrometer` 크기 입자가 `mm` 수준까지 성장 |
| 미행성 형성 | 입자들이 계속 충돌해 수 m-km 크기의 미행성 형성 |
| 행성 형성 | 미행성 사이의 충돌과 중력 상호작용으로 행성 성장 |
## 2.3 행성 형성 시간 규모
| 행성 종류 | 형성 시간 규모 |
|---|---|
| 목성/토성 | 수천 년-만 년 |
| 지구형 행성 | 수백만 년-천만 년 |
| 천왕성/해왕성 | 수천만 년-억 년 |
# 3. 항성 내부 구조와 평형
## 3.1 내부 구조를 나타내는 물리량
- 항성 내부 구조는 반지름 `r`에 따라 물리량이 어떻게 변하는지로 기술한다.

| 기호 | 의미 |
|---|---|
| `P(r)` | 반지름 `r`에서의 압력 |
| `L(r)` | 반지름 `r` 안쪽에서 생성/통과하는 광도 |
| `M(r)` | 반지름 `r` 안쪽에 포함된 질량 |
| `T(r)` | 반지름 `r`에서의 온도 |
- `dP/dr`, `dL/dr`, `dM/dr`, `dT/dr`은 별 내부의 평형, 질량 분포, 에너지 생성, 에너지 전달을 나타내는 핵심 변화율이다.
- 별 내부에서는 중심부에서 에너지가 생성되고, 그 에너지가 복사층/대류층을 거쳐 표면으로 전달된다.

### 3.1.1 태양의 내부와 대기층
| 층 | 위치/성격 | 핵심 역할 |
|---|---|---|
| 중심핵, core | 태양의 가장 안쪽 | 수소 핵융합이 일어나 에너지가 생성되는 영역 |
| 복사층, radiative zone | 중심핵 바깥 | 광자가 흡수와 재방출을 반복하며 에너지를 바깥쪽으로 전달 |
| 대류층, convective zone | 복사층 바깥 | 뜨거운 플라즈마가 상승하고 식은 물질이 하강하며 대류로 에너지 전달 |
| 광구, photosphere | 우리가 보는 태양의 표면 | 태양의 가시광선 대부분이 방출되는 층 |
| 채층, chromosphere | 광구 위의 얇은 대기층 | 붉은빛을 띠며 홍염 같은 태양 활동과 관련 |
| 코로나, corona | 태양의 가장 바깥 대기 | 매우 뜨겁고 희박한 외곽 대기, 개기일식 때 관측 가능 |

## 3.2 별 내부의 압력
| 압력 | 의미 | 주로 중요한 상황 |
|---|---|---|
| 기체압 | 입자의 열운동이 만드는 압력 | 일반적인 별 내부 |
| 복사압 | 빛과 복사가 바깥쪽으로 미는 압력 | 매우 밝고 무거운 별 |
| 축퇴압 | 양자역학적 효과로 생기는 압력 | 백색왜성, 중성자별 등 고밀도 천체 |
- 별은 안쪽으로 작용하는 중력과 바깥쪽으로 작용하는 내부 압력이 균형을 이루어 안정하게 유지된다.
- 태양이 약 46억 년 동안 안정적으로 빛나는 이유도 중력-압력 평형과 지속적인 핵융합 때문이다.
# 4. 별의 에너지원: 핵융합
## 4.1 핵융합의 조건
- 핵융합은 가벼운 원자핵이 결합해 더 무거운 원자핵을 만들고 에너지를 방출하는 과정이다.
- 원자핵은 모두 양전하를 띠므로 서로 전기적으로 밀어낸다.
- 핵융합이 일어나려면 원자핵이 전기적 반발력을 이길 만큼 빠르게 충돌해야 한다.
- 온도와 압력이 높을수록 핵융합이 일어나기 쉽다.

| 관계식 | 의미 |
|---|---|
| `E = 3/2 kT` | 온도가 높을수록 입자의 평균 열운동 에너지가 커짐 |
| `v = sqrt(3kT/m)` | 온도가 높을수록 입자 속도가 커짐 |
## 4.2 질량 결손과 에너지
- 핵융합 에너지는 **질량 결손**에서 나온다.
- 수소 원자핵 4개가 헬륨 원자핵 1개가 될 때, 생성된 헬륨의 질량은 처음 수소 4개의 질량 합보다 작다.
- 사라진 질량 `Delta m`은 `E = Delta m c^2`에 의해 에너지로 바뀐다.

| 항목 | 값/내용 |
|---|---|
| 수소 4개 -> 헬륨 1개 질량 차이 | 약 `4.6 x 10^-29 kg` |
| 방출 에너지 | 약 `4.1 x 10^-12 J` |
| 에너지 전환 비율 | 반응 질량의 약 `0.7%` |
| 수소 1 kg 기준 | 약 `6.4 x 10^14 J/kg` |
## 4.3 질량과 중심온도
- 별은 질량이 클수록 중심부 온도와 압력이 높다.
- 중심온도가 높을수록 더 무거운 원소의 핵융합이 가능하다.
- 원자번호가 높은 원소의 핵융합에는 더 높은 온도가 필요하다.
- 별의 질량은 어떤 핵융합 반응이 주된 에너지원이 되는지를 결정한다.
# 5. 핵융합 반응과 원소 합성
## 5.1 수소 핵융합
| 반응 | 조건/대상 | 핵심 내용 |
|---|---|---|
| pp-chain | 중심온도 약 2,000만 도 이하, 태양 정도 또는 그보다 작은 별 | 수소를 헬륨으로 바꾸는 태양의 주요 에너지원 |
| CNO-cycle | 중심온도 약 2,000만 도 이상, 태양 질량 약 `1.5 M_sun` 이상 | C, N, O가 촉매처럼 작용해 수소를 헬륨으로 변환 |
### 5.1.1 pp-chain(양성자-양성자 연쇄반응)
- pp-chain에는 ppI, ppII, ppIII 경로가 있다.
- 비율은 ppI 약 91%, ppII 약 9%, ppIII 약 0.1%로 제시된다.
- 반응 과정에서 양전자, 중성미자, 감마선이 방출된다.
- 별의 중심온도가 2000만도 이하인 별에서 주요 에너지원이 된다. 
### 5.1.2 CNO-cycle
```text
12C + 1H -> 13N + gamma
13N -> 13C + e+ + neutrino
13C + 1H -> 14N + gamma
14N + 1H -> 15O + gamma
15O -> 15N + e+ + neutrino
15N + 1H -> 12C + 4He
```
- 전체 결과는 수소가 헬륨으로 바뀌는 것이다.
- `12C`는 마지막에 다시 만들어지므로 촉매 역할을 한다.
- 별의 중심온도가 2000만도 이상인 별에서 주요 에너지원이 된다.
## 5.2 헬륨 핵융합: 3중 알파 반응
- **중심온도 약 1억 도 이상**에서 헬륨 핵융합이 가능하다.
- 헬륨 원자핵은 양성자 2개와 중성자 2개로 이루어진 **알파입자**이다.
	- 별의 중심부분에서 대부분의 원소들은 전자를 모두 잃고 핵의 형태로 존재함 -> **전리 상태**
- 3중 알파 반응은 헬륨 3개가 **탄소를 만드는 과정**이다.
```text
4He + 4He -> 8Be + gamma
4He + 8Be -> 12C + gamma
```
- `8Be`는 매우 불안정하여 곧바로 두 개의 헬륨핵으로 붕괴하기 쉽다.
- 따라서 탄소가 만들어지려면 세 개의 알파입자가 거의 동시에 반응해야 한다.
- 수소, 헬륨 다음 원소가 리튬/베릴륨이라고 해서 헬륨 핵융합의 주생성물이 리튬/베릴륨이 되는 것은 아니다.
- 안정적으로 축적되는 핵합성 경로에서는 `8Be`의 불안정성 때문에 헬륨 3개가 결합해 탄소로 넘어가는 3중 알파 반응이 중요하다.
## 5.3 그 외 핵융합과 원소 합성
- 수소 핵융합과 헬륨 핵융합 이후에도, 질량이 큰 별에서는 더 무거운 원소의 핵융합이 이어질 수 있다.
- 별은 핵연료가 소진될 때마다 중심핵이 수축하고, 중심온도가 더 높아지면 다음 단계의 핵융합을 시작한다.
- 이 과정은 대체로 철 근처 원소까지 에너지를 방출하는 방향으로 진행된다.
### 5.3.1 무거운 별에서 철까지 이어지는 핵융합
- 탄소, 산소, 규소 모두 **중심온도가 약 100억도 이상**일 때 시작될 수 있다.

| 연소 단계 | 대표 반응/조건            | 생성 원소         |
| ----- | ------------------- | ------------- |
| 탄소 연소 | 탄소 + 탄소, 중심온도 매우 높음 | Mg, Na, Ne, O |
| 산소 연소 | 산소 + 산소             | S, P, Si, Mg  |
| 규소 연소 | 규소 + 규소             | Ni, Fe        |
### 5.3.2 철보다 무거운 원소가 특별한 이유
- 철보다 무거운 원소를 만들려면 **에너지를 공급**해야 한다.
- 따라서 철보다 무거운 원소는 별 내부의 일반적인 에너지 생산 핵융합만으로는 잘 만들어지지 않는다.
- 철핵이 만들어지면 더 이상 핵융합으로 중력을 지탱할 에너지를 충분히 얻기 어렵고, 질량이 큰 별은 중심핵 붕괴와 초신성 폭발로 이어질 수 있다.
- 철보다 무거운 원소는 초신성 폭발 같은 격렬한 사건에서 **중성자 포획** 과정을 통해 만들어질 수 있다.
