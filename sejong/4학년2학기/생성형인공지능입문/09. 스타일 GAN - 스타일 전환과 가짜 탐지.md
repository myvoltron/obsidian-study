# 09. 스타일 GAN - 스타일 전환과 가짜 탐지

## 1. 스타일 생성 (Style Generation)

### 1.1 스타일 생성 개요

스타일 생성은 이미지에 예술적 표현과 생성 기술을 결합해 여러 시각적 스타일을 적용하는 작업이다. 특정 예술가의 표현 방식, 역사적 미술 사조 또는 목적에 맞춘 디자인을 반영하여 같은 소재를 새로운 방식으로 표현할 수 있다.

### 1.2 스타일 전환 (Style Transfer)

스타일 전환은 **콘텐츠 이미지**의 내용에 별도의 **스타일 이미지**가 가진 예술적 특성을 결합하는 기술이다. 콘텐츠의 형태나 배치를 유지하면서 색상, 질감, 붓질 등 시각적 특성이 스타일 이미지와 비슷해지도록 콘텐츠 이미지를 변형한다. 예를 들어 같은 고양이 사진에도 회화의 붓질이나 모자이크 질감 등 서로 다른 스타일을 적용할 수 있다.

### 1.3 신경망 스타일 전환 (Neural Style Transfer, NST)

NST는 심층 신경망으로 콘텐츠와 스타일의 세밀한 특징을 표현한다. CNN을 사용해 두 이미지에서 콘텐츠 정보와 스타일 정보를 추출하고, 두 정보를 하나의 결과에 반영한다. 결과 이미지의 콘텐츠 특징은 콘텐츠 이미지에 가깝게, 스타일 특징은 스타일 이미지에 가깝게 최적화한다.

합성 결과의 인접한 픽셀 사이에 급격한 변화가 생기는 것을 줄이기 위해 **Total variation loss**를 함께 쓰는 구성도 있다.

### 1.4 CycleGAN (1)

**CycleGAN**은 짝지어지지 않은 이미지 사이의 변환을 학습하기 위해 설계한 생성 모델이다. 두 도메인에 속하는 각 이미지가 일대일로 대응하지 않아도 변환을 학습할 수 있다. 예를 들어 같은 자세로 찍은 말 사진과 얼룩말 사진 한 쌍을 준비하지 않아도, 각각의 사진 모음을 사용해 말과 얼룩말 사이의 변환을 학습할 수 있다.

순환 일관성을 적용해 다른 도메인으로 바꾼 뒤 다시 원래 도메인으로 되돌렸을 때 원본과 가까워지도록 학습한다.

### 1.5 CycleGAN (2)

CycleGAN은 **생성자 두 개와 판별자 두 개**로 구성된다.

- 생성자 $G$는 도메인 $X$의 이미지를 $Y$로, 생성자 $F$는 $Y$의 이미지를 $X$로 변환한다.
- 판별자 $D_X$와 $D_Y$는 각 도메인에서 실제 이미지와 다른 도메인에서 변환된 이미지를 구분한다. **Adversarial loss**는 변환된 결과가 목표 도메인의 실제 이미지처럼 보이도록 유도한다.
- **순환 일관성 손실** (Cycle-consistency loss)은 변환한 이미지를 반대 방향으로 다시 변환했을 때 원본과 가까워지게 한다. 두 방향에서 $F(G(x))\approx x$, $G(F(y))\approx y$를 만족하도록 학습해 원본의 주요 내용을 보존한다.

### 1.6 예술적 렌더링

사진을 반 고흐나 피카소 같은 예술가의 작품을 연상시키는 이미지로 변환할 수 있다. 작가의 붓질, 색상 팔레트, 질감을 반영해 사진의 실제 장면과 회화적 표현을 결합한다.

### 1.7 맞춤형 디자인

브랜딩이나 주제별 목적에 맞는 스타일을 적용한다. 로고, 광고, 홍보 자료의 이미지를 브랜드의 시각적 기준에 맞추고, 같은 방식을 특정 행사의 주제에 맞는 디자인에도 활용할 수 있다.

### 1.8 과제

| 과제 | 설명 |
|---|---|
| **콘텐츠 보존** | 원래 객체와 배치를 알아볼 수 있도록 콘텐츠를 유지하면서 스타일도 충분히 반영해야 한다. |
| **스타일 일관성** | 이미지의 서로 다른 영역에서 색상·질감·붓질이 어색하게 끊기지 않도록 전체에 조화롭게 적용해야 한다. |
| **주관성** | 사람마다 원하는 스타일과 적용 강도가 다르다. 사용자가 스타일이나 강도를 선택할 수 있게 하면 서로 다른 선호를 반영할 수 있다. |

## 2. 예술 작품 생성 실습 (Generation of Artwork)

### 2.1 개관

신경망으로 예술 작품의 스타일을 사진의 콘텐츠에 결합한다. 결과 이미지가 맞춰야 하는 거리는 두 가지다. 콘텐츠 거리 $D_c$는 결과와 콘텐츠 이미지의 특징이 얼마나 다른지 나타낸다. 스타일 거리 $D_s$는 결과와 스타일 이미지의 특징이 얼마나 다른지 나타낸다. 결과 이미지의 픽셀을 바꾸어 두 거리를 줄인다.

### 2.2 데이터셋

예제에서는 ImageNet으로 사전학습한 VGG-19를 사용한다. ImageNet이나 MS-COCO 같은 대규모 데이터셋에서 콘텐츠 이미지나 스타일 이미지에 사용할 자료를 선택할 수도 있다.

두 입력 중 춤추는 사진인 dancing.jpg는 콘텐츠 이미지이고, picasso.jpg는 스타일 이미지다. 춤추는 인물의 형태와 배치를 유지하면서 피카소 그림의 예술적 스타일을 입히는 것이 목표다.

### 2.3 모델 아키텍처

VGG-19의 특징 추출부를 사용한다. 콘텐츠와 스타일을 비교할 Convolution 층을 선택하고 그 층 뒤에서 해당 손실을 계산한다. VGG-19의 가중치는 고정하고 결과 이미지의 픽셀을 갱신한다.

| 손실 | 비교 대상 |
|---|---|
| **콘텐츠 손실** (Content loss) | 선택한 층에서 결과 이미지와 콘텐츠 이미지의 특징 맵을 비교한다. 결과가 콘텐츠 이미지의 형태와 배치를 따라갈수록 손실이 작아진다. |
| **스타일 손실** (Style loss) | 선택한 층에서 결과 이미지와 스타일 이미지의 Gram matrix를 비교한다. 특징 채널 간 상관관계를 맞춰 질감이나 색상 패턴을 반영한다. |

### 2.4 학습

두 손실을 합칠 때는 각각 가중치를 적용한다.

$$
L=\alpha D_c+\beta D_s
$$

1. 현재 결과 이미지를 VGG-19에 입력한다.
2. 선택한 층의 특징으로 콘텐츠 손실과 스타일 손실을 다시 계산한다.
3. 두 손실을 가중합하고, 역전파로 결과 이미지의 픽셀이 어느 방향으로 바뀌어야 하는지 계산한다.
4. 최적화 단계에서 픽셀을 갱신하고, 새 결과 이미지를 다시 입력해 같은 과정을 반복한다.

## 3. 유명 인물 생성 실습 (Generation of Celebrity)

### 3.1 개요

DCGAN으로 유명인 얼굴 데이터에 나타나는 특징을 학습하고, 학습한 분포에서 새로운 합성 얼굴 이미지를 생성한다. 데이터셋으로 CelebA를 사용한다.

### 3.2 데이터셋 (CelebA)

예제에 쓰인 **CelebA**는 유명인의 얼굴 이미지 **202,599개**로 구성된 데이터셋이다. 얼굴 속성 인식, 얼굴 인식·감지, 얼굴 랜드마크 위치 추정, 얼굴 편집과 합성 등의 작업에 사용된다.

### 3.3 DCGAN의 생성자

생성자는 잠재 공간의 노이즈 벡터 $z$를 데이터 공간의 이미지로 변환한다. 2차원 Transposed Convolution에 Batch Normalization과 ReLU를 조합하고, 출력에는 Tanh를 적용한다.

### 3.4 DCGAN 생성자의 층 구성

2차원 Transposed Convolution 층 5개를 사용해 공간 크기를 **4×4 → 8×8 → 16×16 → 32×32 → 64×64**로 늘린다.

처음 네 층에는 Transposed Convolution 뒤에 Batch Normalization과 ReLU를 적용한다. 마지막 층에서 RGB 세 채널의 출력을 만들고, **Tanh**로 픽셀 값을 $[-1,1]$ 범위에 맞춘다.

### 3.5 DCGAN의 판별자

판별자는 입력이 실제 얼굴인지 합성 얼굴인지 판단하는 이진 분류 신경망이다. RGB 이미지 $3\times64\times64$를 입력받아 Convolution, Batch Normalization, LeakyReLU로 처리하고, Sigmoid로 실제 이미지일 확률을 출력한다.

### 3.6 DCGAN 판별자의 층 구성

RGB 이미지 $3\times64\times64$를 입력받아 다섯 개의 Convolution 층으로 처리한다. 처음 네 층을 거치며 특징 맵의 공간 크기가 **32×32 → 16×16 → 8×8 → 4×4**로 줄어들고, 다섯 번째 층에서 점수 하나를 얻는다.

첫 번째 층에는 LeakyReLU를, 두 번째부터 네 번째 층에는 Batch Normalization과 LeakyReLU를 사용한다. 마지막 층의 **Sigmoid**가 점수를 0과 1 사이의 실제 이미지일 확률로 바꾼다.

### 3.7 손실 함수 (Loss Function)

**BCE**는 판별자가 예측한 확률 $p$와 학습에서 사용한 목표 레이블 $y$의 차이를 나타내는 손실이다.

$$
\operatorname{BCE}(y,p)=-[y\log p+(1-y)\log(1-p)]
$$

판별자를 학습할 때 실제 이미지의 목표 레이블은 1이고, 생성 이미지의 목표 레이블은 0이다. 생성자를 학습할 때는 생성 이미지가 실제로 분류되도록 목표 레이블 1을 사용한다.

### 3.8 판별자 학습

판별자는 실제 배치와 생성 배치의 진위를 정확히 분류하도록 학습한다. 학습 목표는 $\log D(x)+\log(1-D(G(z)))$를 높이는 것이며, BCE에서는 두 항의 음수를 손실로 사용한다. 판별자를 갱신하는 동안 생성자의 파라미터는 고정한다.

1. 학습 데이터에서 실제 샘플 배치를 가져와 판별자를 통과시킨다. 목표 레이블 1로 실제 배치의 손실을 구하고 역전파로 판별자의 기울기를 계산한다.
2. 현재 생성자가 만든 샘플 배치를 판별자에 입력한다. 목표 레이블 0으로 생성 배치의 손실을 구하고 역전파로 기울기를 누적한다. 두 배치에서 계산한 기울기로 판별자의 파라미터를 갱신한다.

### 3.9 생성자 학습

생성자는 생성 결과에 대한 판별자의 실제 점수 $D(G(z))$가 커지도록 학습한다.

1. 생성자의 출력을 판별자에 넣어 실제 이미지일 확률을 계산한다.
2. 목표 레이블을 1로 두어 생성자 손실 $-\log D(G(z))$를 구한다. 이 레이블은 판별자가 생성 이미지를 실제로 판단하도록 유도하기 위해 사용한다.
3. 판별자의 파라미터를 고정한 채 판별 연산을 통해 생성자로 기울기를 전달한다.
4. 최적화 단계에서 생성자의 파라미터를 갱신한다.

### 3.10 학습 손실

학습 예시는 CelebA에 대해 **5 epoch, 약 8,000번의 배치 반복**으로 진행한다. 생성자와 판별자는 각각 자기 손실을 줄이며, 학습 중 두 손실이 어떻게 변하는지 함께 살핀다. 예시에서는 생성자 손실이 판별자 손실보다 높게 나타난다. 두 손실은 서로의 성능에 영향을 받으므로 절대 크기와 함께 생성 샘플의 사실감과 다양성을 확인한다.

### 3.11 출력 생성

생성된 얼굴 중에는 자연스러운 결과와 품질이 낮은 결과가 함께 나타날 수 있다. 학습 횟수나 최적화 설정을 조정하고 결과를 다시 비교할 수 있다. 모델 구조를 바꾸거나 더 높은 품질의 학습 이미지를 사용하는 방법도 있다.

## 4. 가짜 식별 네트워크 1 (Fake Detection Network)

### 4.1 가짜 식별 네트워크의 정의

**가짜 식별 네트워크**는 진짜 콘텐츠와 합성·변조 콘텐츠를 구분하는 네트워크다. 가짜 영상, 조작된 사진, 가짜 텍스트 등의 탐지에 사용된다.

### 4.2 작동 원리

네트워크는 학습 데이터에서 실제 콘텐츠와 가짜 콘텐츠에 각각 나타나는 특징과 패턴을 학습한다. 합성이나 조작을 나타내는 결함·불일치·이상 징후 등의 특징을 포착한다. 이렇게 얻은 특징을 학습에서 익힌 패턴과 비교해 진위를 판단한다.

### 4.3 특징 추출 (Feature Extraction)

실제 콘텐츠와 가짜 콘텐츠에 나타나는 고유한 특징과 패턴을 분석한다. 입력을 모델이 이해하고 비교할 수 있는 작은 구성 요소로 나눈다.

**얼굴 랜드마크**는 눈·코·입과 같이 얼굴 구조의 기준이 되는 점이다. 영상에서 이 점들의 분포와 움직임을 분석하고 실제 얼굴에서 보이는 패턴과 비교하면, 조작으로 생긴 얼굴 형태나 프레임 간 움직임의 불일치를 찾을 수 있다.

### 4.4 가짜 탐지를 위한 GAN

적대적 학습에서 실제 미디어와 합성 미디어를 구분하도록 훈련한 판별자를 탐지 모델로 활용한다. 판별자는 학습에서 접한 조작이나 합성에 나타나는 미세한 특징과 불일치를 찾아낸다.

### 4.5 가짜 탐지용 CNN

이미지에서 경계·질감 같은 낮은 수준의 시각 단서와 얼굴 형태·구조 같은 높은 수준의 특징을 추출해 진위를 판단한다.

영상에는 CNN과 RNN을 함께 사용할 수 있다. 프레임에서 얼굴을 검출하고 잘라 정렬한 뒤, CNN으로 각 프레임의 얼굴 특징을 추출한다. RNN은 프레임 순서에 따라 특징의 변화를 분석한다. 이렇게 얻은 공간·시간 정보를 마지막 CNN 분류기에 전달해 영상의 진위를 판단한다.

### 4.6 가짜 탐지 평가 지표

가짜 콘텐츠를 양성으로 두면 **TP**는 가짜를 가짜로 맞힌 수, **FP**는 진짜를 가짜로 잘못 판단한 수, **FN**은 가짜를 놓친 수다.

| 지표 | 평가 내용 |
|---|---|
| **정확도** (Accuracy) | 전체 샘플 중 옳게 분류한 비율이다. 데이터에 진짜가 압도적으로 많으면 가짜를 많이 놓쳐도 정확도가 높을 수 있다. |
| **정밀도** (Precision) | 가짜라고 분류한 항목 중 실제 가짜의 비율이다. $\mathrm{TP}/(\mathrm{TP}+\mathrm{FP})$로 계산한다. 진짜를 가짜로 잘못 판단하는 오탐의 영향을 받는다. |
| **재현율** (Recall, Sensitivity) | 실제 가짜 중 가짜로 찾아낸 비율이다. $\mathrm{TP}/(\mathrm{TP}+\mathrm{FN})$으로 계산한다. 가짜를 놓치는 미탐의 영향을 받는다. |
| **F1 점수** | 정밀도와 재현율의 조화평균이다. 정밀도·재현율 중 한쪽이 낮으면 F1도 낮아져 두 지표의 균형을 평가할 수 있다. |

## 5. 가짜 식별 네트워크 2

### 5.1 응용 — 이미지 조작 탐지

얼굴 표정 변경, 객체 제거, 배경 교체 등으로 생긴 시각적 불일치를 찾아 조작된 이미지를 식별한다.

### 5.2 응용 — 비디오 변조 탐지

영상에서 변조된 구간이나 프레임을 찾는다. 프레임 사이의 시간적 불규칙성이나 화면에 남은 시각적 이상을 탐지 단서로 사용한다.

### 5.3 응용 — 콘텐츠 진위 검증

저널리즘과 소셜 미디어에서 배포 전에 콘텐츠의 진위를 확인한다. 잘못된 정보의 확산을 줄이고 디지털 콘텐츠의 신뢰를 높이는 데 활용한다.

### 5.4 도전 과제와 한계

| 과제 | 설명 |
|---|---|
| **적대적 공격** | 탐지기를 속이도록 의도적으로 변형한 콘텐츠는 판별 성능을 떨어뜨릴 수 있다. 조작과 탐지 기술이 발전하면서 탐지기도 새로운 입력에 대한 성능을 점검해야 한다. |
| **데이터 다양성과 일반화** | 실제와 가짜 콘텐츠의 다양한 유형을 학습해야 새로운 사례에도 대응할 수 있다. 학습 데이터가 제한적이거나 편향되면 새 조작 기법을 만났을 때 성능이 떨어질 수 있다. |
| **조작 기법의 빠른 변화** | 새 기법이 계속 생기므로 기존 탐지기가 새 조작을 얼마나 잘 찾는지 확인하고 필요하면 갱신해야 한다. |
| **미관측 조작** (제로데이) | 학습에서 본 적 없는 조작 기법은 기존에 학습한 특징만으로 발견하기 어렵다. 처음 등장한 조작에도 빠르게 대응할 수 있어야 한다. |
| **맥락 이해** | 한 이미지나 프레임의 특징만으로 확인하기 어려운 조작이 있다. 주변 문장이나 영상의 앞뒤 장면과 같은 시각·언어 맥락을 함께 이해해야 한다. |
| **학습 데이터의 개인정보와 권리** | 탐지를 위해 충분한 자료를 수집해야 하지만, 자료에 포함된 개인정보와 당사자의 권리도 존중해야 한다. |

### 5.5 윤리적 고려 사항

| 고려 사항 | 설명 |
|---|---|
| **개인정보 보호** | 합법적인 가짜 탐지 목적이라도 콘텐츠를 분석하고 분류하는 과정에서 개인의 사생활을 침해할 수 있다. 탐지 필요성과 프라이버시 보호를 함께 고려한다. |
| **편향과 공정성** | 모델이 학습 데이터의 편향을 반영하면 특정 집단이나 콘텐츠 유형에서 오류가 더 많이 발생할 수 있다. 집단과 자료 유형에 따른 성능 차이를 확인해야 한다. |
| **오탐과 미탐** | 진짜를 가짜로 판단하면 정상 콘텐츠가 피해를 입고, 가짜를 놓치면 조작 콘텐츠가 유통될 수 있다. 두 오류의 영향을 함께 고려해 판정 기준을 조정한다. |
| **투명성과 설명 가능성** | 모델의 판정 과정이 불투명하면 결과를 검토하기 어렵다. 어떤 단서로 진위를 판단했는지 설명할 수 있으면 이용자가 결과를 검토할 수 있다. |
| **검열과 표현의 자유** | 탐지 결과를 부적절하게 적용하면 합법적인 콘텐츠가 차단되고 표현이 위축될 수 있다. 가짜 콘텐츠의 유통을 줄이면서 열린 의견 교환을 보호해야 한다. |
| **의도하지 않은 결과** | 탐지 기술을 배포하면 탐지에 대응하는 새로운 조작 기법이 발전할 수 있다. 배포 이후 실제 환경에서 발생하는 영향도 살펴야 한다. |
