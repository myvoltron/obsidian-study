# 05. 트랜스포머 2 - ViT와 U-Net
[[00. 생성형인공지능입문 - 시험 대비 목차|과목 목차]] · [[04. 트랜스포머 1 - 임베딩과 Attention|이전 주차]] · [[06. 언어 모델 - BERT와 GPT|다음 주차]]
## 1. 영상 패치 임베딩
### 1.1 영상 패치 임베딩이 필요한 이유
Transformer는 벡터가 순서대로 나열된 **토큰 시퀀스**를 입력받는다. 2차원 영상은 일정한 크기의 패치로 나눠 각 패치를 토큰으로 바꾼다. 패치 하나는 작은 영역의 특징을 담고, Self-Attention은 패치 사이의 관계를 계산해 영상 전체의 문맥을 파악한다. 픽셀마다 토큰을 만드는 경우보다 입력 토큰 수도 줄어든다.
### 1.2 패치 분할·펼치기·선형 투영
높이 $H$, 너비 $W$, 채널 수 $C$인 영상에 한 변의 길이가 $P$인 패치를 사용한다.
1. **패치 분할** — 영상을 겹치지 않는 $P\times P$ 패치로 자른다. $H$와 $W$가 $P$의 배수라면 패치 수는 $N=HW/P^2$다. 채널 우선 표기에서 패치 묶음의 형태는 $N\times C\times P\times P$다.
2. **펼치기** — 각 패치를 길이 $P^2C$의 1차원 벡터로 펼친다. 벡터 $N$개를 모으면 $N\times(P^2C)$ 행렬이 된다.
3. **선형 투영** — 학습 가능한 선형 변환으로 각 벡터를 모델 차원 $D$에 맞춘다. 결과는 $N\times D$ 형태의 패치 임베딩 시퀀스다. 투영 전 길이 $P^2C$와 모델 차원 $D$는 서로 다를 수 있다.
### 1.3 패치 크기에 따른 차이
$224\times224\times3$ RGB 영상을 $16\times16$ 패치로 나누면 $14\times14=196$개가 생긴다. 각 패치의 $16\cdot16\cdot3=768$개 값을 펼치면 선형 투영 전의 형태는 $196\times768$이다.

| 패치 크기 | 패치 수 | 공간 정보 | 패치 간 Attention 점수 수 |
|---|---:|---|---:|
| $16\times16$ | 196개 | 더 작은 영역마다 토큰을 만들어 세부 위치를 촘촘하게 남긴다. | $196^2=38{,}416$ |
| $32\times32$ | 49개 | 더 넓은 영역을 한 토큰으로 묶으며 작은 구조를 놓칠 수 있다. | $49^2=2{,}401$ |
같은 영상에서 패치의 한 변을 절반으로 줄이면 패치 토큰은 4배로, 패치끼리 계산하는 Attention 점수 수는 16배로 늘어난다.
## 2. ViT 모델
### 2.1 ViT의 분류 흐름
**Vision Transformer** (ViT)는 영상 전체의 클래스를 예측한다.
패치 임베딩 → Class token 추가 → 위치 임베딩 추가 → Transformer Encoder → MLP Head
### 2.2 Class token과 위치 임베딩

| 구성 | 입력에 반영하는 방법 | 역할 |
|---|---|---|
| **Class token** (CLS) | 패치 시퀀스 앞에 학습 가능한 토큰을 하나 붙인다. $N\times D$였던 입력이 $(N+1)\times D$가 된다. | Encoder를 거친 CLS의 최종 출력을 영상 전체의 표현으로 사용한다. |
| **위치 임베딩** (Positional embedding) | 각 토큰의 임베딩에 해당 위치의 벡터를 더한다. | Encoder에 패치가 영상의 어느 위치에서 나왔는지 알려준다. 가까운 위치의 임베딩끼리 높은 유사도가 나타날 수 있다. |
### 2.3 Transformer Encoder

| 구성                            | 역할                                                                                 |
| ----------------------------- | ---------------------------------------------------------------------------------- |
| **Multi-Head Self-Attention** | 헤드마다 가까운 패치 관계와 영상 전반의 관계 등 서로 다른 패턴을 본다. 헤드별 계산을 병렬로 수행하고 결과를 합쳐 복잡한 공간 관계를 표현한다. |
| **MLP**                       | 두 선형 층 사이에 GELU 활성화 함수를 적용해 각 토큰의 벡터를 독립적으로 변환한다.                                  |
| **LayerNorm**                 | Attention과 MLP 앞에서 토큰별로 특징 차원을 정규화해 학습을 안정화한다. 배치 단위 통계가 필요 없어진다.                  |
| **잔차 연결**                     | 블록의 입력을 출력에 더해 정보와 기울기가 직접 전달되는 경로를 만든다.                                           |
패치 토큰의 관계도 4주차와 같은 헤드별 투영과 가중합으로 계산한다. [[04. 트랜스포머 1 - 임베딩과 Attention#4. Multi-Head Attention|헤드별 투영과 가중합]]
### 2.4 MLP Head
Encoder를 통과한 **CLS의 최종 표현**을 받아 영상 전체의 클래스 점수로 바꾼다. Encoder 안의 MLP는 각 토큰을 변환하고, MLP Head는 최종 CLS로 분류 결과를 계산한다.
### 2.5 ViT 성능
대규모 데이터셋에서 사전학습한 ViT를 작은 데이터셋에 전이학습하면 비교적 적은 데이터로도 영상 인식 모델을 만들 수 있다. 대규모 사전학습을 거친 ViT는 ImageNet 분류에서도 기존 CNN과 경쟁할 만한 성능을 보였다.
### 2.6 ViT 모델의 한계 및 단점

| 한계 | 이유 |
|---|---|
| **계산 비용** | 토큰 수가 많아지면 표준 Self-Attention의 점수 행렬이 커져 학습과 추론에 더 많은 연산과 메모리가 필요하다. |
| **데이터 양** | 작은 데이터셋에서 처음부터 학습하면 과적합할 수 있다. 대규모 사전학습 후 전이학습으로 완화한다. |
| **입력 영상 크기** | 같은 패치 크기로 더 큰 영상을 처리하면 패치 수가 증가한다. 학습 때와 패치 격자가 달라지면 위치 임베딩도 맞춰야 한다. |
| **공간 정보 손실** | 한 패치에 있는 여러 픽셀을 하나의 토큰으로 묶어, 과제에 따라 패치 내부의 위치나 작은 구조를 놓칠 수 있다. |
| **패치·모델 크기 조정** | 패치 크기와 모델 규모에 따라 세부 정보, 계산량, 인식 성능이 달라져 과제에 맞게 조정해야 한다. |
| **영상에 특화된 구조의 필요성** | Transformer는 자연어 처리에서 먼저 발전했으므로 초기 영상 Transformer는 영상 과제에 맞게 구조를 최적화할 여지가 있었다. 검출·분할에서는 객체의 위치나 픽셀 단위 출력을 반영하는 설계가 추가로 필요할 수 있다. |
## 3. U-Net 모델
### 3.1 U-Net의 영상 분할
U-Net은 의료 영상 분할을 위해 제안된 U자형 Encoder–Decoder 모델이다. 각 픽셀에 클래스를 할당한다. 출력 높이와 너비가 $H,W$이고 클래스마다 점수 하나를 출력하면, $C$개 클래스의 점수 맵은 $H\times W\times C$다.
### 3.2 Encoder
**ConvBlock**으로 특징을 추출한다. Batch Normalization을 쓰는 구현에서는 $3\times3$ Convolution → Batch Normalization → ReLU를 두 번 적용한다. ConvBlock의 출력은 다음 두 경로로 간다.
- **다운샘플링** — $2\times2$ Max Pooling으로 높이와 너비를 줄여 다음 Encoder 블록에 전달한다. 깊은 층은 더 넓은 영역의 문맥을 반영한다.
- **Skip connection** — Pooling 전의 특징 맵을 대응하는 Decoder 블록에 전달한다.
예를 들어 $512\times512\times3$ RGB 영상에서 $256\times256\times128$ 크기의 중간 특징 맵을 얻을 수 있다.
### 3.3 Skip connection
Encoder의 위치·경계 정보를 대응하는 Decoder 블록에 전달한다. Decoder에서 업샘플링한 깊은 특징과 채널 축으로 **이어 붙인다**. 원래 U-Net에서는 필요할 때 Encoder 특징 맵의 가장자리를 잘라 크기를 맞춘다. 이 결합 덕분에 Decoder는 깊은 특징의 문맥과 얕은 특징의 세부 위치를 함께 이용한다.
### 3.4 Decoder
Transposed Convolution으로 특징 맵의 높이와 너비를 두 배로 늘리고 채널 수를 줄인다. Skip connection으로 받은 특징을 결합한 뒤 Encoder와 같은 구성의 ConvBlock으로 정제한다. 이 블록을 반복해 픽셀별 예측에 필요한 해상도를 복원한다.
### 3.5 Prediction Network
$1\times1$ Convolution으로 각 픽셀의 특징을 클래스 점수로 바꾼다. 이진 분할에서 출력 채널이 하나면 Sigmoid를, 서로 배타적인 여러 클래스를 고르면 Softmax를 적용한다.
### 3.6 U-Net의 장점 및 성능

| 장점 | 이유와 활용 |
|---|---|
| **분할에 적합한 구조** | 완전 합성곱 구조로 공간 격자를 유지하며 픽셀마다 클래스 점수를 계산할 수 있다. |
| **U자형 구조의 공간 정보 보존** | Decoder가 깊은 층의 문맥과 Skip connection이 전달한 위치·경계 특징을 결합해 작은 구조의 분할을 돕는다. |
| **소규모 데이터에서의 활용** | 레이블된 영상이 비교적 적은 의료 영상 분할에도 활용할 수 있다. 원형 U-Net은 데이터 증강으로 학습 예시의 변형을 늘렸다. |
| **다양한 응용** | 픽셀별 분할이 필요한 도로·건물, 얼굴·사물 영역에도 같은 구조를 적용할 수 있다. |
### 3.7 U-Net의 단점 및 한계

| 한계 | 이유와 대응 |
|---|---|
| **채널 표현의 한계** | 특징을 압축하는 과정에서 일부 영상 정보가 사라질 수 있다. 국소 특징만으로 부족한 경우 영상 전체의 문맥을 충분히 파악하기 어렵다. |
| **클래스 불균형** | 관심 클래스의 픽셀 수가 매우 적으면 다수 클래스인 배경에 예측이 치우쳐 작은 영역을 놓칠 수 있다. |
| **정확도와 처리 속도의 절충** | 고해상도 특징은 경계를 세밀하게 복원하는 데 유리하지만, 큰 특징 맵의 연산과 저장에 시간과 메모리가 든다. |
| **회전·크기 변환 민감성** | 학습에서 보기 어려웠던 방향이나 크기에서는 분할이 흔들릴 수 있다. 회전·크기 변환을 포함한 데이터 증강으로 완화할 수 있다. |
## 4. 영상 캡셔닝에서의 Attention

| 방식                 | 참조할 영역과 계산                                                   | 예시와 고려점                                                              |
| ------------------ | ------------------------------------------------------------ | -------------------------------------------------------------------- |
| **Soft Attention** | 모든 영역에 0과 1 사이의 연속 가중치를 준다. 가중치의 합이 1이 되도록 정규화한 뒤 특징을 가중합한다. | 우산 영역에 높은 가중치를 주면서 사람과 배경도 반영한다. 작은 물체에 낮은 가중치가 배정되면 그 특징이 약해질 수 있다. |
| **Hard Attention** | 각 시점에서 일부 영역을 이산적으로 선택해 그 특징을 사용한다.                          | 우산이 있는 영역을 고른다. 처리할 특징을 줄일 수 있으며 선택한 곳 밖의 물체나 관계는 놓칠 수 있다.           |
## 5. 영상 Transformer의 응용
### 5.1 분류·객체 감지·영상 분할
자연어 처리에 쓰이던 Transformer는 영상에서도 과제에 따라 서로 다른 단위의 출력을 만든다.

| 과제                             | 출력          | 모델과 활용                                                                                                                                                                 |
| ------------------------------ | ----------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **영상 분류**                      | 영상 전체의 클래스  | ViT는 패치 시퀀스를 인코딩해 영상 전체를 분류한다. Transformer를 CNN과 결합해서 사용할 수도 있다.                                                                                                       |
| **객체 감지**                      | 객체별 위치와 클래스 | **DETR** (Detection Transformer)은 영상 특징과 Object query를 사용해 객체의 바운딩 박스와 클래스를 예측한다. 별도의 후보 생성과 후처리를 줄이는 구조로, COCO에서 기존 검출 방식에 견줄 만한 결과를 보였다. 주행 카메라 영상의 객체 감지에 활용할 수 있다. |
| **영상 분할** (Image segmentation) | 픽셀별 클래스     | **SETR**은 Transformer Encoder로 넓은 문맥을 반영한 패치 특징을 얻고 Decoder에서 픽셀별 분할 결과를 만든다. 주행 영상의 도로·차선과 보행자·차량 영역을 구분하는 데 쓸 수 있다.                                                  |
### 5.2 응용과 발전 가능성
- **멀티모달 처리** — 카메라 영상, LiDAR, 레이더의 정보를 결합해 주행 환경을 더 안정적으로 파악할 수 있다.
- **지능형 로봇과 드론** — 로봇은 환경과 물체를 인식하고, 드론은 공간 탐색과 자율 비행에 영상 정보를 활용한다.
- **AR과 VR** — 현실의 물체와 배경 영역을 구분해 가상 콘텐츠가 놓일 위치를 정하거나 실제 환경과 합성한다.
- **의료 영상 분석과 진단** — 픽셀 단위로 구조를 구분한 결과를 의료 영상 판독과 치료 계획에 활용한다.
- **환경 모니터링과 보안** — 공공장소나 중요 시설의 카메라 영상에서 관심 영역과 상황을 파악해 이상 징후를 점검할 수 있다.
