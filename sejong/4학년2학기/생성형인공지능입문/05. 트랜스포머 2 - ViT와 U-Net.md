## 1. 영상 패치 임베딩
### 1.1 영상 패치 임베딩이 필요한 이유
- **입력 형식 변환** — NLP에서 출발한 Transformer는 **1차원 토큰 시퀀스**를 입력받는다. 뚜렷한 구분선이 없는 2차원 영상을 고정 크기 패치로 분할해 단어처럼 1차원 임베딩 벡터로 변환한다.
- **계산 효율** — 픽셀마다 토큰을 만들면 시퀀스 길이와 Self-Attention 연산량 ($O(N^2)$)이 폭증한다. 패치 단위로 묶어 토큰 수를 줄여 큰 영상도 효율적으로 처리한다.
- **지역·전역 특징 동시 반영** — 각 패치가 작은 영역의 **지역 특징**을 담고, Self-Attention이 패치 간 관계를 계산해 영상 전체의 **전역 문맥**을 함께 파악한다.

### 1.2 패치 분할·펼치기·선형 투영과 패치 크기
높이 $H$, 너비 $W$, 채널 수 $C$인 영상에 한 변이 $P$인 패치를 사용한다.
1. **패치 분할** — 영상을 겹치지 않는 $P\times P$ 패치 $N=HW/P^2$개로 자른다 ($N\times C\times P\times P$).
2. **펼치기** — 각 패치를 길이 $P^2C$의 1차원 벡터로 펼쳐 $N\times(P^2C)$ 행렬을 만든다.
3. **선형 투영** — 학습 가능한 선형 변환으로 각 벡터를 모델 차원 $D$에 맞춰 $N\times D$ 시퀀스를 얻는다.

- **패치 크기 트레이드오프** — $224\times224\times3$ 영상을 $16\times16$ 패치로 나누면 $N=196$개 ($196\times768$), $32\times32$ 패치로 나누면 $N=49$개가 된다. 패치 한 변을 절반으로 줄이면 세부 공간 정보 보존에는 유리하지만, 패치 토큰 수는 **4배**, 패치 간 Attention 점수 수는 **16배**로 증가한다.

## 2. ViT 모델
### 2.1 ViT 구조와 분류 흐름
**Vision Transformer** (ViT)는 영상 전체의 클래스를 분류하는 모델이다.

**패치 임베딩 → Class token 추가 → 위치 임베딩 추가 → Transformer Encoder → MLP Head**

| 구성 | 역할 |
|---|---|
| **Class token** (CLS) | 패치 시퀀스 앞에 학습 가능한 토큰을 붙여 입력을 $(N+1)\times D$로 만든다. Encoder를 통과한 CLS의 최종 출력을 영상 전체 표현으로 사용한다. |
| **위치 임베딩** (Positional embedding) | 각 토큰에 위치 벡터를 더해 패치의 원래 공간 위치를 전달한다 (가까운 패치끼리 높은 유사도가 학습된다). |
| **Transformer Encoder** | **Multi-Head Self-Attention** (지역·전역 패치 관계 병렬 포착), **MLP** (두 선형 층 + GELU), 각 블록 앞의 **LayerNorm** (배치 통계 불필요·학습 안정화), **잔차 연결** (기울기 직접 전달)로 구성된다. |
| **MLP Head** | Encoder를 통과한 **CLS 최종 표현**을 받아 영상 전체의 클래스 점수로 분류한다. |

- **성능과 전이학습** — 대규모 데이터셋에서 사전학습한 ViT를 작은 데이터셋에 **전이학습**하면 비교적 적은 데이터로도 기존 CNN과 경쟁할 만한 분류 성능을 얻는다. [[04. 트랜스포머 1 - 임베딩과 Attention#4. Multi-Head Attention|헤드별 투영과 가중합]]

### 2.2 ViT 모델의 한계 및 단점

| 한계 | 이유 |
|---|---|
| **계산 비용** | 토큰 수가 많아지면 표준 Self-Attention 점수 행렬이 커져 CNN 대비 많은 연산과 메모리가 필요하다. |
| **데이터 양** | 작은 데이터셋에서 처음부터 학습하면 과적합하기 쉬워, 대규모 사전학습 후 전이학습이 필요하다. |
| **입력·패치 크기 민감성** | 영상이 커지면 패치 수가 늘고 위치 임베딩 조정이 필요하며, 패치·모델 규모에 따라 세부 정보와 연산량이 크게 달라진다. |
| **공간 정보 손실** | 패치 안의 여러 픽셀을 하나의 토큰으로 묶어 패치 내부의 미세 위치나 작은 구조를 놓칠 수 있다. |
| **영상 특화 구조 필요** | NLP에서 출발한 구조이므로 검출·분할 같은 밀집 예측 과제에는 픽셀·객체 위치를 반영하는 추가 설계가 필요하다. |

## 3. U-Net 모델
### 3.1 구조와 동작 원리
**U-Net**은 의료 영상 분할을 위해 제안된 U자형 **완전 합성곱** (FCN) Encoder–Decoder 모델로, 각 픽셀에 클래스를 할당해 $H\times W\times C$ 크기 맵을 출력한다.

**입력 → Encoder → Decoder + Skip connection → Prediction Network**

| 구성 | 역할 |
|---|---|
| **Encoder** | **ConvBlock** ($3\times3$ Conv → BatchNorm → ReLU 2회)으로 특징을 추출하고, $2\times2$ **Max Pooling**으로 공간 크기를 줄여 깊은 층에서 넓은 문맥을 포착한다. |
| **Skip connection** | Pooling 전의 얕은 특징 맵 (위치·경계 정보)을 대응하는 Decoder 블록에 전달해 채널 축으로 **이어 붙인다** (Concatenation). |
| **Decoder** | **Transposed Convolution**으로 해상도를 2배 키우고 채널을 줄인 뒤, Skip connection 특징과 결합해 ConvBlock으로 정제하며 해상도를 복원한다. |
| **Prediction Network** | $1\times1$ Convolution으로 각 픽셀 특징을 클래스 점수로 변환한다. 이진 분할은 **Sigmoid**, 다중 클래스 분할은 **Softmax**를 적용한다. |

### 3.2 U-Net의 장점과 한계

| 장점 | 이유와 활용 |
|---|---|
| **분할에 적합한 구조** | FCN 구조로 공간 격자를 유지하며 픽셀별 클래스 점수를 예측한다. |
| **U자형 공간 정보 보존** | Decoder가 깊은 문맥과 Skip connection의 경계·위치 특징을 결합해 작은 구조 분할에 강하다. |
| **소규모 데이터 활용** | 데이터 증강과 함께 레이블이 적은 의료 영상 분할에서 효과적이다. |
| **다양한 응용** | 의료 영상뿐 아니라 자율주행 도로·건물, 얼굴·사물 분할에도 적용한다. |

| 한계 | 이유와 대응 |
|---|---|
| **채널·전역 문맥 한계** | 특징 압축 과정에서 일부 정보가 사라지고 국소 합성곱 중심이라 영상 전체 문맥 파악에 한계가 있다. |
| **클래스 불균형** | 관심 클래스 픽셀이 매우 적으면 배경에 예측이 치우쳐 작은 영역을 놓칠 수 있다. |
| **정확도·속도 절충** | 고해상도 특징 맵은 경계 복원에 유리하지만 연산과 메모리 비용이 크다. |
| **회전·크기 변환 민감성** | 학습에 없던 방향·크기에서 성능이 흔들려 회전·크기 데이터 증강으로 완화한다. |

## 4. 영상 캡셔닝에서의 Attention

| 방식 | 참조할 영역과 계산 | 예시와 고려점 |
|---|---|---|
| **Soft Attention** | 모든 영역에 0과 1 사이의 연속 가중치 (합 1)를 부여해 특징을 가중합한다. | 우산 영역에 높은 가중치를 주면서 사람·배경도 함께 반영한다. 작은 물체 특징이 약해질 수 있다. |
| **Hard Attention** | 각 시점에서 일부 영역만 이산적으로 선택해 그 특징을 사용한다. | 우산 영역만 골라 연산량을 줄이지만, 선택한 영역 밖의 물체·관계는 놓칠 수 있다. |

## 5. 영상 Transformer의 응용

| 과제 | 출력 | 대표 모델과 활용 |
|---|---|---|
| **영상 분류** | 영상 전체의 클래스 | **ViT**가 패치 시퀀스를 인코딩해 분류하며, CNN과 결합해 사용할 수도 있다. |
| **객체 감지** | 객체별 위치와 클래스 | **DETR** (Detection Transformer)이 영상 특징과 Object query로 바운딩 박스와 클래스를 직접 예측한다 (별도 후보 생성·후처리 축소). |
| **영상 분할** | 픽셀별 클래스 | **SETR**이 Transformer Encoder로 넓은 문맥의 패치 특징을 얻고 Decoder에서 픽셀별 분할을 수행한다 (도로·차선·보행자 구분). |

- **확장 분야** — 카메라·LiDAR·레이더 멀티모달 자율주행, 지능형 로봇·드론 탐색, AR·VR 객체 합성, 의료 영상 판독, 보안 모니터링 등에 활용한다.
