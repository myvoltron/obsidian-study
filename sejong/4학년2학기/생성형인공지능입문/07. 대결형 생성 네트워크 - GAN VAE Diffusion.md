## 1. GAN의 원리
### 1.1 GAN의 정의 (Generative Adversarial Network)
- GAN은 서로 경쟁하는 두 신경망으로 구성된 머신러닝 프레임워크다.
- 생성자는 이미지나 텍스트 등의 합성 데이터를 만들고, 판별자는 실제 데이터와 생성 데이터를 구분한다.
- 이미지 생성, 스타일 전환, 데이터 증강에 쓰인다.
### 1.2 듀얼 네트워크 아키텍처
두 네트워크는 게임처럼 경쟁하며 성능을 개선한다.
- **생성자** (Generator, G)는 **무작위 노이즈를 의미 있는 표현으로 변환**해 합성 샘플을 만든다.
- **판별자** (Discriminator, D)는 **실제 샘플과 생성 샘플을 구분**하고 각 샘플이 실제일 확률을 출력한다.
### 1.3 적대적 과정
- **생성자와 판별자의 대결** — G는 생성 샘플이 실제로 판정되도록, D는 실제 샘플과 생성 샘플을 정확히 구분하도록 학습한다.
- **속임수와 반복** — D가 진짜와 가짜를 더 잘 구별할수록 G는 더 사실적인 샘플을 만들어야 D를 속일 수 있다.
- **상호 개선** — 두 네트워크는 상대의 변화에 맞춰 학습하며, G는 D의 평가를 학습 신호로 받아 생성 결과를 개선한다.
### 1.4 반복 훈련
1. **데이터 생성** — G에 무작위 노이즈를 넣어 합성 샘플을 만든다.
2. **판별자 평가** — G를 고정하고 실제 샘플과 생성 샘플을 함께 D에 넣는다. 실제 샘플에는 높은 진짜 점수를, 생성 샘플에는 낮은 진짜 점수를 주도록 D를 갱신한다.
3. **생성자에 피드백 제공** — D를 고정하고 생성 샘플을 D에 넣는다. D를 통과한 기울기로 G를 갱신해 생성 샘플이 실제로 판정될 가능성을 높인다.
4. **반복적인 개선** — D와 G의 갱신을 반복하며 두 네트워크가 상대의 변화에 적응하도록 한다.
### 1.5 손실 함수 (Loss function)
- **손실 함수 활용** — 판정 결과와 학습 목표의 차이를 수치화해 각 네트워크의 갱신 방향을 정한다.
- **생성자 손실** — D가 생성 샘플을 실제로 판단하도록 G의 손실을 줄인다.
- **판별자 손실** — D가 실제 샘플과 생성 샘플을 올바르게 구분하도록 D의 손실을 줄인다.
- **학습 균형** — G가 받는 학습 신호는 D의 판정에 달려 있으므로 두 네트워크의 학습 균형이 중요하다.
### 1.6 내시 균형 (Nash equilibrium)
- **내시 균형의 개념** — 상대의 전략이 주어졌을 때 어느 쪽도 자기 전략만 바꿔 이득을 높일 수 없는 상태다.
- **균형 달성** — 생성 분포가 실제 분포와 같아져 **판별자가 실제 샘플과 생성 샘플을 구별할 수 없게 되는 상태**가 이상적인 균형이다.
- **품질 기준** — 이상적인 균형은 G가 실제 데이터의 분포를 재현했다는 이론적 기준이다.
### 1.7 과제 및 고려 사항
- **모드 붕괴** (Mode collapse) — 서로 다른 노이즈를 넣어도 G가 비슷한 샘플을 반복해서 만들면 생성 분포가 실제 데이터의 일부에 몰려 다양성이 줄어든다.
- **학습 불안정** — G와 D가 번갈아 변해 상대의 학습 목표도 계속 달라지므로 손실이 진동하거나 수렴하기 어려울 수 있다.
- **하이퍼파라미터 튜닝** — 두 네트워크의 학습 균형에 맞는 설정을 찾아야 한다. 이 과정에는 시간과 전문 지식이 필요하다.
- **윤리적 문제** — GAN으로 만든 데이터는 딥페이크에 악용되거나 학습 데이터의 편향을 반영할 수 있다. 이런 영향을 고려해 개발하고 배포해야 한다.
**보충** · 학습이 불안정하면 G와 D의 학습률이나 갱신 횟수를 조정해 한쪽이 지나치게 앞서지 않도록 한다. 모드 붕괴를 완화하기 위해 D가 한 배치 안의 생성 샘플 다양성도 평가하도록 설계할 수 있다.
## 2. 영상 생성 원리
### 2.1 생성 모델 개요
**생성 모델** (Generative model)은 데이터셋의 기본 분포를 학습하고, 그 분포를 바탕으로 **원본과 비슷한 새 데이터를 만드는 것을 목표**로 한다. 학습 데이터와 같은 맥락에 맞는 새로운 콘텐츠를 생성할 수 있다.
**판별 모델**은 서로 다른 클래스나 범주를 구분하고 데이터에 레이블을 붙인다. 생성 모델은 새로운 데이터 샘플을 만들며, 이미지 생성·텍스트 합성·데이터 증강 등에 사용된다.
### 2.2 데이터 표현
이미지를 수치 데이터로 표현하려면 시각 정보를 컴퓨터와 알고리즘이 처리할 수 있는 형식으로 바꿔야 한다.
이미지의 수치 표현을 구성하는 요소에는 **픽셀과 그리드**, **컬러 채널**, **이미지 크기**, **채널 깊이**, **정규화와 스케일링**이 있다.
### 2.3 영상 생성 모델
이미지 생성 모델은 기존 데이터를 학습하고, 학습 데이터와 유사한 새로운 이미지를 생성하는 알고리즘과 구조를 제공한다.
- 확산 모델은 가우시안 노이즈를 단계적으로 더하는 과정의 역과정을 학습한다.
- VAE는 변분 하한을 최대화하도록 학습한다.
- GAN은 생성자와 판별자의 적대적 학습을 사용한다.
### 2.4 노이즈 (Noise)
생성 과정에 제어된 노이즈를 도입하면 **같은 조건에서도 세부가 조금씩 다른 이미지를 만들 수 있다**. 이 변동 덕분에 생성 결과에 현실에서 볼 수 있는 미묘한 차이가 나타날 수 있다.
실제 이미지는 작은 불규칙성과 차이를 포함한다. 생성 모델이 그런 변동을 반영하면 지나치게 획일적인 결과를 줄이고 사람이 보는 사실감을 높일 수 있다.
### 2.5 잠재 공간 (Latent space)
잠재 공간은 생성 모델이 **데이터의 핵심 특징을 간결하게 표현하는 추상적인 공간**이다. 신경망의 은닉층에서 이런 내부 표현을 사용해 다양한 이미지를 생성할 수 있다.
- **데이터 매핑** — 실제 이미지를 잠재 표현으로 변환하는 모델은 이미지의 특징·질감·모양·패턴을 잠재 변수로 나타낸다.
- **변수 조정** — 잠재 변수를 조정하면 새로운 스타일이나 테마를 가진 이미지를 만들어 볼 수 있다.
- **부드러운 전환** — 연속적인 잠재 공간의 두 지점 사이를 이동하면 이미지의 속성도 점진적으로 변할 수 있다. 표정, 눈을 뜬 정도, 스타일의 변화가 그 예다.
### 2.6 조건부 이미지 생성
조건부 이미지 생성은 **특정 속성이나 조건에 맞는 이미지를 생성하는 방식**이다. 모델에 텍스트, 레이블, 참조 이미지 등의 추가 정보를 넣으면 그 정보가 이미지 합성 과정을 안내한다. 따라서 요구 사항이나 창작 의도에 부합하는 결과를 만들 수 있다.
### 2.7 조건부 이미지 생성 응용

| 응용             | 입력·조건            | 생성 결과                                          |
| -------------- | ---------------- | ---------------------------------------------- |
| **스타일 전환**     | 콘텐츠 이미지와 스타일 이미지 | 콘텐츠 이미지의 형태와 배치를 유지하고 스타일 이미지의 색상·질감·붓질을 반영한다. |
| **텍스트-이미지 합성** | 텍스트 설명           | GAN이나 VAE 등이 문장에 지정한 속성을 반영한 이미지를 생성한다.        |
| **이미지 편집**     | 원본 이미지와 편집 지시    | 원본의 전체 맥락을 유지하면서 지정한 색상·모양·객체를 바꾼다.            |
### 2.8 평가 지표
| 지표                                   | 평가 내용                                                                                                              |
| ------------------------------------ | ------------------------------------------------------------------------------------------------------------------ |
| **Inception Score** (IS)             | 사전학습한 Inception 모델로 각 생성 이미지가 특정 클래스로 얼마나 뚜렷하게 분류되는지, 생성 이미지 전체가 얼마나 다양한 클래스를 포함하는지 평가한다. 점수가 높을수록 이 두 기준을 잘 충족한다. |
| **Fréchet Inception Distance** (FID) | Inception의 특징 공간에서 실제 이미지 분포와 생성 이미지 분포 사이의 차이를 측정한다. 값이 낮을수록 두 분포가 가깝다.                                           |
| **사람 평가**                            | 사람이 시각적 품질·사실감·매력을 판단한다. 자동 지표로 잡기 어려운 미묘한 차이를 평가하는 데 도움이 된다.                                                      |
## 3. 생성형 네트워크 구조
### 3.1 생성형 네트워크란?
생성형 네트워크는 주어진 데이터의 분포를 학습하고, 이 **분포를 바탕으로 새 데이터를 생성하거나 기존 데이터를 변환**하는 인공 신경망이다. 주로 확률적인 방식으로 작동해 여러 종류의 샘플을 만들 수 있다. 대표 구조로 Autoencoder, VAE, GAN, 확산 모델이 있다.
### 3.2 Autoencoder
Autoencoder는 Encoder와 Decoder로 구성된다. Encoder는 입력 데이터를 저차원 잠재 표현으로 바꾸어 압축한다. Decoder는 압축한 표현을 사용해 원래 입력을 재구성한다.
### 3.3 VAE (Variational Autoencoder)
VAE는 Autoencoder에 **확률적 잠재 변수**를 도입한다. 연속적인 잠재 변수로 학습 데이터의 특징과 미묘한 변화를 표현한다.
- **학습** — Encoder는 입력에 대한 잠재 분포를 추정하고, Decoder는 이 분포에서 뽑은 잠재 벡터로 입력을 복원한다. 재구성 항과 잠재 분포의 정규화 항을 포함하는 변분 하한을 최대화한다.
- **생성** — 잠재 사전분포에서 벡터를 뽑아 Decoder에 넣어 새 이미지를 만든다.
### 3.4 GAN
- **학습** — G와 D가 경쟁하며, 이상적인 균형에서는 생성 분포가 실제 분포와 같아진다.
- **생성** — 무작위 노이즈 벡터를 학습한 G에 넣어 새 샘플을 만든다.
### 3.5 확산 모델 (Diffusion model)
확산 모델은 **데이터 분포에 작고 제어된 변화를 반복해서 적용**하는 과정을 모델링한다.
- **학습** — 순방향 과정에서 실제 데이터에 가우시안 노이즈를 단계적으로 더한다. **모델은 이를 되돌려 노이즈를 제거하는 역과정을 학습**한다.
- **생성** — 무작위 가우시안 노이즈에서 시작해 학습한 역과정으로 여러 번 정제한다.

## 4. GAN 응용
| 응용         | 모델                                 | 핵심 작동 방식                                                                                                  |
| ---------- | ---------------------------------- | --------------------------------------------------------------------------------------------------------- |
| 이미지 생성     | **DCGAN** (Deep Convolutional GAN) | G는 Transposed Convolution으로 해상도를 높이고, D는 Strided Convolution으로 낮춘다. 중간층의 Batch Normalization으로 학습을 안정화한다. |
| 얼굴 생성      | **StyleGAN**                       | 잠재 벡터를 스타일 벡터로 변환해 합성 네트워크의 여러 층에 반영하고, 생성된 얼굴의 속성을 조절한다.                                                 |
| 이미지-이미지 변환 | **CycleGAN**                       | 짝지어지지 않은 이미지로 두 도메인 사이의 양방향 변환을 학습한다. 순환 일관성으로 왕복 변환 결과가 원본에 가까워지도록 한다.                                   |
| 음악 생성      | **MuseGAN**                        | 무작위 노이즈에서 여러 트랙의 음표를 생성하고, 판별자는 생성된 음악과 실제 음악을 구분한다.                                                      |
| 자연어 생성     | **TextGAN**                        | 생성자는 노이즈나 시작 문장으로부터 토큰을 순차적으로 만들고, 판별자는 생성 텍스트와 실제 텍스트를 구분한다.                                             |
| 자연어 생성     | **SeqGAN**                         | Monte Carlo rollout으로 미완성 시퀀스를 여러 번 완성한다. 판별자의 보상으로 현재 토큰 선택의 기대 보상을 추정해 정책 경사로 생성자를 갱신한다.                |
| 자연어 생성     | **LeakGAN**                        | 판별자가 생성 중인 문장의 내부 특징을 전달한다. Manager가 이를 바탕으로 하위 목표를 정하면 Worker가 다음 토큰을 생성한다.                              |
