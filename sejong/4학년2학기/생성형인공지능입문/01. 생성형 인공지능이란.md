# 01. 생성형 인공지능이란

## 1. ChatGPT란 무엇일까?

| 항목 | 핵심 내용 |
|---|---|
| **ChatGPT** | ChatGPT는 OpenAI에서 개발한 대규모 언어 모델(LLM) 기반 서비스다. GPT (Generative Pre-trained Transformer)를 기반으로 사용자 질의에 대한 텍스트 응답을 생성한다. |
| **GPT 구조** | Transformer Decoder 기반이다. **Masked Multi-Head Self-Attention**으로 현재 위치까지의 토큰만 참조한다. |
| **학습** | 사람의 피드백을 사용하는 강화학습인 **RLHF** (Reinforcement Learning from Human Feedback)로 **Fine-tuning**한다. |
| **한계** | 때때로 사실에 근거하지 않는 부정확한 답변을 생성할 수 있다. 불확실한 질의가 주어지면 추측해서 답할 수 있으며 이런 오류를 **환각** (Hallucination)이라 한다. |
## 2. 생성형 인공지능이란?
### 2.1 생성형 인공지능
- **생성형 인공지능** (Generative AI)은 텍스트, 이미지, 음악 등의 콘텐츠 생성을 중점으로 하는 인공지능 분야다.
- 대표 플랫폼은 **ChatGPT**와 **DALL-E**다.
### 2.2 생성형 인공지능의 출력

| 출력 | 대표 모델 |
|---|---|
| 이미지 생성 | **GAN** (Generative Adversarial Network)과 Autoencoder를 이용해 실제와 유사한 이미지를 생성할 수 있다. |
| 텍스트 생성 | **RNN** (Recurrent Neural Network)이나 Transformer로 텍스트를 생성할 수 있다. |
| 비디오 생성 | **3D CNN**이나 **GAN**으로 동영상을 생성할 수 있다. |
| 오디오 생성 | **1D CNN**이나 **GAN**으로 오디오를 생성할 수 있다. |
### 2.3 Encoder–Decoder 구조
Encoder–Decoder 구조에서 **Encoder**는 입력을 해석하고 **문맥 정보** (Contextual information)를 생성한다. **Decoder**는 이 문맥 정보를 바탕으로 출력을 생성한다.
**입력 → Encoder → 문맥 정보 → Decoder → 출력**
### 2.4 생성 모델의 다양한 구조

| 모델 | 구성 | 핵심 원리 |
|---|---|---|
| **GAN** | Generator·Discriminator | 실제·생성 데이터를 구분하는 판별 신호로 경쟁 학습 |
| **VAE** (Variational Autoencoder) | Encoder·Decoder | 변분 하한을 최대화해 확률적 잠재 표현을 학습 |
| **Flow-based Models** | 가역 변환·역변환 | 데이터와 잠재 표현을 가역적으로 변환 |
| **Diffusion Models** | 순방향 확산·학습된 역과정 | 가우시안 노이즈를 점진적으로 추가하고 제거하는 역과정을 학습 |
[[07. 대결형 생성 네트워크 - GAN VAE Diffusion|GAN·VAE·Diffusion 비교]]
### 2.5 문제점

| 문제 | 핵심 내용 |
|---|---|
| **데이터셋** | 대규모 모델에는 많은 데이터가 필요하다. 데이터가 부족하거나 품질이 낮으면 생성 결과에 영향을 준다. |
| **보안·윤리** | 위험한 요청에 유해한 답을 생성할 수 있다. 법적 규제는 이런 위험에 대응하는 방법 중 하나다. |
## 3. 인지형 AI와의 차이점
### 3.1 인지형 인공지능
**인지형 인공지능** (Cognitive AI)은 컴퓨터가 인간의 사고와 인지 과정을 모사하는 방법을 연구하는 인공지능 분야다. 학습, 추론, 언어 이해, 지식 표현 등의 기술을 통해 지능적인 의사 결정과 문제 해결을 수행한다. 이를 위해 데이터 마이닝, 머신러닝, 자연어 처리를 활용한다.
### 3.2 인지형 인공지능의 구성 요소

| 구성 요소 | 설명 |
|---|---|
| **지식 표현** | 여러 종류의 지식을 설명하고 정리해 지식 간의 추론과 활용을 지원한다. |
| **학습** | 많은 데이터에서 패턴을 자동으로 학습하고 자체 모델을 계속 최적화한다. |
| **자연어 처리** (NLP) | 컴퓨터가 자연어로 이루어진 사람의 의사소통을 이해하고 처리하도록 지원한다. |
| **컴퓨터 비전** | 이미지와 영상의 시각 정보를 처리한다. |
| **추론 및 의사 결정** | 기존 정보를 바탕으로 추론하고 의사 결정을 내려 해결책을 제시한다. |
### 3.3 인지형 인공지능의 응용

| 응용 | 설명 |
|---|---|
| **지능형 고객 서비스** | 사용자와 상호작용하고 음성 또는 텍스트로 도움을 제공한다. |
| **지능형 검색** | 사용자 요구에 따라 많은 데이터에서 관련 정보를 찾는다. |
| **지능형 번역** | 한 자연어를 다른 자연어로 번역한다. |
| **지능형 이미지 분석** | 의료 이미지에서 종양이나 질환에 해당하는 특징을 분석하고 판단한다. |
| **자율주행** | 컴퓨터 비전과 센서를 이용해 차량의 이동을 관리한다. |
### 3.4 인지형 AI와 생성형 AI의 차이
두 유형은 자연어 처리와 머신러닝 같은 구성 기술을 공유할 수 있다. 차이는 시스템의 주된 목적과 출력에 있다.

| 유형 | 목적 | 같은 이미지로 하는 작업 |
|---|---|---|
| **인지형 AI** | 입력을 이해·추론하고 판단한다. | 이미지 속 객체의 종류를 판별해 ‘고양이’라는 레이블을 붙인다. |
| **생성형 AI** | 입력이나 학습한 패턴을 바탕으로 새로운 콘텐츠를 만든다. | 같은 이미지에 대해 ‘고양이가 창가에 앉아 있다’라는 설명문을 생성한다. |
## 4. 언어 및 영상 생성
### 4.1 언어 생성
**언어 생성** (Language generation)은 컴퓨터 프로그램을 사용하여 자연스러운 인간 언어의 규범에 부합하는 텍스트를 생성하는 과정이다. 언어학, 컴퓨터과학, 인공지능을 함께 활용하는 **자연어 처리**의 한 분야다.
언어 생성 기술은 자동 질의응답 시스템, 챗봇, 지능형 고객 서비스 시스템, 자동 콘텐츠 생성에 쓰인다. 사용되는 모델에는 **Markov chain, RNN, Transformer**가 있다.
### 4.2 자연어 생성 네트워크
신경망 기반 언어 생성은 언어 생성에 대한 딥러닝 기반 접근 방식이다. 신경망은 데이터로부터 언어의 규칙과 특징을 학습해 새로운 텍스트를 생성한다. 문맥 정보를 처리하여 자연스럽고 유창하며 표현력이 풍부한 텍스트를 생성할 수 있다. 직접 설계해야 할 특징이나 규칙을 줄일 수 있다.
### 4.3 신경망 기반 언어 생성 모델

| 모델 | 핵심 특징 |
|---|---|
| **LSTM** (Long Short-Term Memory) | 장기 정보를 유지하도록 설계된 순환 신경망 |
| **RNN** | 이전 hidden state를 다음 시점으로 전달 |
| **Transformer** | 위치 정보와 Attention을 사용해 토큰 간 관계를 처리 |
### 4.4 GPT 기반 언어 생성
GPT는 책·기사·웹사이트 등의 텍스트로 언어 패턴을 학습하고, 프롬프트나 시작 문장에 이어지는 텍스트를 생성한다. [[06. 언어 모델 - BERT와 GPT#2. GPT|GPT의 학습과 생성]]
### 4.5 이미지 생성
- **Image Generation**은 컴퓨터 알고리즘으로 이미지를 만드는 과정이다.
- 생성물에는 사진, 그림, 3D 렌더링, 가상의 이미지 등이 있다.
- 규칙 기반, 통계 기반, 딥러닝 기반 등 여러 방법을 사용할 수 있다.
### 4.6 딥러닝 기반 이미지 생성
**딥러닝 기반 이미지 생성**은 입력 표현과 출력 이미지 사이의 관계를 학습하도록 훈련한 신경망을 사용한다. GAN과 VAE는 실제와 유사한 이미지를 생성할 수 있는 대표적인 모델이다.
예를 들어 GAN은 잠재 벡터를 Generator에 입력해 사진과 유사한 이미지를 생성한다.
## 5. 언어 생성 방법
### 5.1 언어 모델을 만드는 단계
**데이터셋 선택 → 입력 텍스트 전처리 → 언어 모델 선택 → 모델 학습 → 모델 평가**
### 5.2 데이터셋
- 언어 생성에 사용하는 데이터 집합을 **Text Corpus**라고 한다.
- 여러 문장으로 구성되며, 클래스 레이블이나 품사 태그, 번역문 같은 정보를 포함할 수 있다.
### 5.3 전처리

| 방법 | 역할 |
|---|---|
| **Tokenization** | 텍스트를 문자·단어·서브워드 등 모델의 입력 요소로 분리한다. |
| **Vectorization** | 토큰이나 텍스트를 수치로 표현한다. 단어 인덱스와 TF-IDF가 예다. |
| **Embedding** | 의미 관계나 문맥 정보를 담은 벡터로 토큰을 표현한다. |
**Tokenization 예시** — `This is tokenizing.`

| 단위 | 분리 결과 |
|---|---|
| Character | `[T] [h] [i] [s] [i] [s] [t] [o] [k] [e] [n] [i] [z] [i] [n] [g] [.]` |
| Word | `[This] [is] [tokenizing] [.]` |
| Subword | `[This] [is] [token] [izing] [.]` |
### 5.4 언어 모델
전처리된 토큰의 문맥을 처리할 모델을 선택한다. [[02. 언어 처리 신경망 개요#1. RNN의 구조|RNN]] · [[04. 트랜스포머 1 - 임베딩과 Attention#2. Transformer 전체 흐름과 위치 인코딩|Transformer]]
### 5.5 훈련
1. 모델의 가중치를 초기화한다.
2. 학습 데이터를 모델에 공급하여 예측값을 얻는다.
3. 예측된 출력과 실제 목표 출력 사이의 손실을 계산한다.
4. 역전파로 기울기를 계산하고, 최적화 알고리즘으로 모델의 가중치를 갱신하여 손실을 줄인다.
5. 학습 데이터에 대해 이 과정을 반복하여 모델의 성능을 개선한다.
충분한 성능을 달성하거나 손실이 안정되면 학습을 종료한다.
### 5.6 평가

| 지표 | 평가 내용 |
|---|---|
| **Perplexity** (PPL) | 실제 다음 토큰에 높은 확률을 부여할수록 값이 낮아진다. |
| **BLEU** | 생성문과 참조문에서 일치하는 단어 및 연속된 단어 묶음을 바탕으로 유사성을 측정한다. |
| **사람 평가** | 평가자가 생성 결과를 보고 주관적으로 평가한다. |
| **정성적 분석** | 생성 텍스트의 일관성, 문법, 주어진 문맥과의 관련성을 직접 검토한다. |
| **과제별 지표** | 요약에서는 **ROUGE** (Recall-Oriented Understudy for Gisting Evaluation)로 생성 요약과 참조 요약의 중첩을 측정할 수 있다. |
