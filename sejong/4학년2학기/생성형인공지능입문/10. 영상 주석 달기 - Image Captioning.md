# 10. 영상 주석 달기 - Image Captioning
[[00. 생성형인공지능입문 - 시험 대비 목차|과목 목차]] · [[09. 스타일 GAN - 스타일 전환과 가짜 탐지|이전 주차]] · [[11. 언어 명령을 이용한 영상 생성|다음 주차]]
## 1. Encoder–Decoder 구조
### 1.1 Encoder–Decoder 개요
**Encoder**는 입력을 특징이나 문맥을 담은 수치 표현으로 바꾸고, **Decoder**는 이 표현을 바탕으로 출력을 만든다.
### 1.2 영상·언어 Encoder와 Decoder

| 구성 | 입력 | 출력과 역할 |
|---|---|---|
| **영상 Encoder** | 이미지·영상 | CNN이나 ViT로 시각 특징을 추출한다. |
| **언어 Encoder** | 단어·토큰 | RNN이나 BERT 등으로 문맥을 담은 수치 표현을 얻는다. |
| **영상 Decoder** | 잠재 표현 | 목표 해상도의 이미지를 생성하거나 복원한다. |
| **언어 Decoder** | 문맥과 앞선 토큰 | 다음 토큰을 예측해 텍스트를 생성한다. |
### 1.3 Encoder와 Decoder의 다양한 결합

| 과제 | 조합 |
|---|---|
| **이미지 캡셔닝** | 영상 Encoder → 언어 Decoder |
| **텍스트-이미지 생성** | 언어 Encoder → 영상 Decoder 또는 생성 모델 |
| **시각적 질문 답변** (VQA) | 영상 Encoder와 언어 Encoder → 언어 Decoder |
## 2. Encoder–Decoder 동작 원리
### 2.1 특징 추출 (Feature Extraction)
영상의 경계·질감·형태나 텍스트의 의미 관계를 수치 특징으로 표현한다. 이렇게 얻은 특징은 후속 처리에 필요한 정보를 드러낸다.
### 2.2 문맥 벡터 생성 (Context Vector)
문맥 벡터는 출력에 필요한 특징을 요약한 표현이다.

| 방식 | 작동 방식 |
|---|---|
| **Global Average Pooling** | 채널마다 공간 위치의 평균을 구해 압축한다. 위치 정보는 줄어든다. |
| **Flattening** | 특징 맵의 개별 값을 유지한 채 1차원 벡터로 펼친다. |
### 2.3 문맥 디코딩
이미지를 만들 때는 문맥 벡터가 생성 모델의 조건이 될 수 있다. 텍스트를 만들 때는 문맥과 앞선 토큰으로 다음 토큰을 예측한다. 필요하면 클래스 레이블이나 텍스트 설명을 추가 조건으로 준다.
### 2.4 Attention의 역할
- **정보 선택** — 출력에 관련된 입력 특징에 높은 가중치를 준다.
- **입출력 정렬** — 출력 토큰을 관련 입력 위치나 영상 영역과 연결한다.
- **문맥의 동적 갱신** — 생성하는 토큰에 따라 참조할 위치의 가중치를 바꾼다.
### 2.5 손실 함수
- **Cross-Entropy** — 토큰의 예측 확률과 정답을 비교한다.
- **MSE** (Mean Squared Error) — 이미지 복원 등에서 기준 이미지와 출력의 픽셀값 차이를 제곱해 평균한다.
### 2.6 학습의 목표
- **최대우도추정** (Maximum Likelihood Estimation, MLE) — 정답 시퀀스의 확률을 높인다. 이는 정답 토큰에 대한 Cross-Entropy를 줄이는 것과 연결된다.
- **GAN의 적대적 학습** — 판별자는 실제와 생성 이미지를 구분하고, 생성자는 실제로 판정될 이미지를 만들도록 학습한다.
### 2.7 평가

| 지표                  | 평가 대상                                 |
| ------------------- | ------------------------------------- |
| **BLEU**            | 생성문에서 참조문과 일치하는 단어나 연속된 단어 묶음을 평가한다.  |
| **ROUGE**           | 생성문이 참조문의 단어나 구문을 얼마나 포함하는지 평가한다.     |
| **Inception Score** | 생성 이미지의 분류 명확성과 클래스 다양성을 평가한다.        |
| **FID**             | 실제 이미지 집합과 생성 이미지 집합의 특징 분포 차이를 측정한다. |

## 3. 영상 주석 생성 1 (Image Captioning)
### 3.1 영상 주석 만들기
이미지 캡셔닝은 입력 이미지의 내용을 설명하는 텍스트를 생성하는 작업이다.
1. 영상 Encoder가 이미지 영역별 특징을 추출한다.
2. Attention은 앞서 생성한 캡션을 바탕으로 다음 토큰을 예측하는 데 관련된 영역에 더 큰 가중치를 주고, 영역별 특징을 가중합해 문맥 벡터를 만든다.
3. 언어 Decoder는 문맥 벡터와 앞선 토큰으로 다음 토큰을 예측한다. 종료 토큰 (EOS)이 나올 때까지 반복한다.
### 3.2 주요 구성 요소
영상 Encoder, 언어 Decoder, 문맥 벡터, Attention이 캡션 생성에 쓰인다. 어휘는 사용할 토큰의 범위를 정하고, 언어 모델은 문맥에 맞는 토큰을 예측한다. BLEU·ROUGE는 생성 캡션을 참조 캡션과 비교한다.
### 3.3 이미지 캡션의 과제

| 과제            | 어려운 점                                                                           |
| ------------- | ------------------------------------------------------------------------------- |
| **세밀한 물체 인식** | 복잡한 장면에서 작은 물체와 세부 특징을 놓치기 쉽다. 객체 분할 결과를 Attention의 단서로 쓸 수 있다.                 |
| **장거리 의존성**   | 떨어져 있는 물체와 배경의 관계를 파악해야 한다. RNN은 먼 위치의 정보를 연결하기 어렵고, Transformer에는 위치 정보가 필요하다. |
| **모호성 처리**    | 한 이미지에 여러 설명이 가능하므로 상황과 문맥에 맞는 정보를 골라야 한다.                                      |
## 4. 영상 주석 생성 2
### 4.1 개요
- Pokémon BLIP Captions의 이미지·캡션을 모델에 맞게 전처리한 뒤, Hugging Face에서 가져온 사전학습 GIT를 Fine-tuning한다.
- GIT(Generative Image-to-text Transformer)은 영상 Encoder와 텍스트 Decoder에 Transformer를 사용함.
## 5. 네트워크 응용

| 응용                  | 입력            | 출력·활용                              |
| ------------------- | ------------- | ---------------------------------- |
| **이미지 설명**          | 사진·게시물 이미지    | 시각 보조나 소셜 미디어에 활용할 캡션을 만든다.        |
| **콘텐츠 색인·검색**       | 이미지와 자동 생성 캡션 | 캡션의 키워드를 이미지와 연결해 검색할 수 있게 한다.     |
| **자동화된 보고**         | 차트·그래프·지도     | 시각 자료의 정보나 변화를 보고서에 쓸 문장으로 바꾼다.    |
| **의료 영상**           | X선 등 의료 영상    | 전문가가 검토할 영상 설명이나 보고서 초안을 생성한다.     |
| **교육용 콘텐츠**         | 교육 자료의 이미지    | 학습에 필요한 설명문을 만든다.                  |
| **자동 감시**           | 보안 카메라 영상     | 장면 속 행동이나 사건을 문장으로 기술해 사고 분석을 돕는다. |
| **시각적 질문 답변** (VQA) | 이미지와 질문       | 이미지 속 물체·속성·수량 등에 관한 질문에 답한다.      |
