# 10. 영상 주석 달기 - Image Captioning

[[00. 생성형인공지능입문 - 시험 대비 목차|과목 목차]] · [[09. 스타일 GAN - 스타일 전환과 가짜 탐지|이전 주차]] · [[11. 언어 명령을 이용한 영상 생성|다음 주차]]

## 1. Encoder–Decoder 구조

### 1.1 Encoder–Decoder 개요

Encoder–Decoder 구조는 입력을 표현하는 **Encoder**와 그 표현으로 출력을 만드는 **Decoder**로 이루어진다. Encoder는 입력의 주요 특징과 문맥을 임베딩 등 수치 표현으로 바꾼다. Decoder는 그 표현을 바탕으로 출력을 생성한다.

문맥은 이미지나 텍스트 등 서로 다른 종류의 데이터를 표현할 수 있다. 입력 종류와 원하는 출력에 따라 Encoder와 Decoder를 바꾸어 조합한다. 예를 들어 이미지 복원에서는 이미지 Encoder와 이미지 Decoder를 쓰고, 기계 번역에서는 원문을 인코딩한 뒤 목표 언어의 문장을 디코딩한다.

### 1.2 영상 Encoder

입력 영상에서 내용에 중요한 시각적 특징을 추출한다. 고정된 크기의 벡터로 요약하는 경우 이 벡터를 임베딩 또는 잠재 표현이라 한다. CNN으로 시각 특징을 추출하거나, Vision Transformer (ViT)로 패치 사이의 관계를 학습해 영상을 표현할 수 있다.

### 1.3 언어 Encoder

단어나 토큰의 시퀀스를 처리해 수치 표현으로 바꾸고 문맥 정보를 담는다. 이 정보를 고정 크기의 임베딩으로 요약할 수 있다. LSTM·GRU 등 RNN이 사용되어 왔으며, BERT처럼 Self-Attention을 사용하는 Transformer Encoder도 쓰인다.

### 1.4 영상 Decoder

잠재 표현을 입력받아 목표 해상도의 이미지로 변환한다. 영상 생성, 복원, 복원 결과를 활용한 이상 감지 등 과제에 따라 구조가 달라진다. VAE나 GAN에 CNN 기반 구조를 쓸 수 있으며, Transformer나 확산 모델 기반 구조도 활용된다.

### 1.5 언어 Decoder

초기 상태나 입력 문맥을 바탕으로 단어 또는 토큰의 시퀀스를 생성한다. RNN Decoder는 이전 hidden state와 이전에 생성한 토큰을 이용해 상태를 갱신하고 다음 토큰을 예측한다. Transformer Decoder는 앞선 토큰의 정보를 Attention으로 반영한다. 학습 때 정답 시퀀스가 주어지면 Mask를 적용해 여러 위치의 예측을 병렬 계산할 수 있다. 자기회귀 생성에서는 앞서 생성한 토큰을 사용해 다음 토큰을 순차적으로 예측한다.

### 1.6 Encoder와 Decoder의 다양한 결합

| 과제 | Encoder와 Decoder의 조합 |
|---|---|
| **이미지 캡셔닝** | 영상 Encoder가 이미지 특징을 추출하고 언어 Decoder가 그 이미지를 설명한다. |
| **텍스트-이미지 생성** | 언어 Encoder가 텍스트 프롬프트를 표현하고 영상 Decoder 또는 영상 생성 모델이 조건에 맞는 이미지를 만든다. |
| **VQA** (Visual Question Answering) | 영상 Encoder와 언어 Encoder가 이미지와 질문을 각각 표현하고, 언어 Decoder가 두 정보를 바탕으로 답변한다. |

## 2. Encoder–Decoder 동작 원리

### 2.1 특징 추출 (Feature Extraction)

특징 추출은 데이터의 차원을 줄이거나 노이즈의 영향을 줄이고, 구분에 중요한 정보가 잘 드러나게 해 후속 분석과 모델 학습을 돕는다. 영상에서는 경계, 질감, 모양 등 의미 있는 시각 요소를 검출해 복잡한 픽셀 정보를 특징 집합으로 압축한다. 자연어 처리에서는 단어 임베딩 등을 이용해 텍스트를 수치로 바꾸고 단어 사이의 의미 관계를 표현한다.

### 2.2 문맥 벡터 생성 (Context Vector)

문맥 벡터는 Encoder가 얻은 특징에서 출력에 필요한 정보를 간결하게 요약한 표현이다. 영상의 특징 맵으로부터 벡터를 만드는 두 가지 방법이 있다.

| 방식 | 작동 방식 |
|---|---|
| **Global Average Pooling** | Encoder가 만든 특징 맵에서 채널마다 공간 위치의 평균을 구한다. 채널별 대표값으로 압축할 수 있지만, 특징이 정확히 어디에 있었는지에 대한 정보는 줄어든다. |
| **Flattening** | 다차원 특징 맵의 값을 일정한 순서로 펼쳐 1차원 벡터로 만든다. 개별 값을 남긴 채 Decoder가 처리할 수 있는 형태로 바꾼다. |

### 2.3 문맥 디코딩

**영상 출력**에서는 GAN이나 VAE와 같은 생성 모델에서 문맥 벡터를 조건으로 사용할 수 있다. 문맥이 생성기의 출력을 안내해 원하는 형태나 질감 등 시각적 특성이 결과에 반영되도록 한다.

**언어 출력**에서는 RNN 또는 Transformer 기반 Decoder가 문맥 정보와 앞서 생성한 단어를 조건으로 다음 토큰 하나를 예측한다. 이 과정을 반복해 문맥에 맞는 일관된 문장을 생성한다.

출력이 특정 요구 사항을 충족해야 하는 작업에서는 클래스 레이블, 텍스트 설명 등의 추가 정보를 Decoder의 조건으로 제공할 수 있다.

### 2.4 Attention의 역할

- **정보 흐름 개선** — Attention은 동적인 정보 필터로 작동한다. Decoder가 Encoder 출력에서 현재 작업과 관련된 특징에 선택적으로 더 큰 비중을 둘 수 있다.
- **시퀀스 간 정렬** — 입력과 출력을 대응시켜 번역, 캡셔닝, 요약 등의 결과를 개선할 수 있다. 번역은 원문의 관련 표현을, 이미지 캡셔닝은 해당 단어와 관련된 영상 영역을 참고한다.
- **문맥의 동적 갱신** — Decoder가 각 출력 토큰을 만들 때 참고할 입력 위치를 바꿀 수 있다. 관련 위치가 멀리 떨어져 있어도 참조해 출력에 필요한 문맥을 얻는 데 도움이 된다.

### 2.5 손실 함수

손실 함수는 예측값과 학습 목표 사이의 차이를 수치화한다. 언어와 영상은 출력 형태가 달라 손실과 목표도 다르게 설정할 수 있다.

| 작업 | 손실 함수 |
|---|---|
| **언어 생성과 기계 번역** | **Cross-Entropy**로 토큰의 예측 확률 분포와 실제 정답 분포 사이의 차이를 계산한다. 손실을 줄이면 정답 토큰에 더 높은 확률을 부여하도록 학습한다. |
| **영상 생성과 복원** | 기준 영상이 주어진 재구성·복원 작업에서는 **MSE** (Mean Squared Error)로 출력과 기준 영상 사이의 픽셀별 차이를 제곱해 평균할 수 있다. 손실이 줄어들면 출력의 픽셀 값이 기준 영상에 가까워진다. |

### 2.6 학습의 목표

- **텍스트 생성의 학습 목표** — 최대우도추정 (Maximum Likelihood Estimation, MLE)은 데이터에 있는 정답 시퀀스에 모델이 부여하는 확률을 높이는 학습 목표다. 정답 시퀀스의 음의 로그우도를 줄이는 것은 정답 토큰에 대한 Cross-Entropy를 줄이는 것과 연결된다.
- **GAN의 학습 목표** — 판별자는 실제 영상과 생성 영상을 구별하도록 학습한다. 생성자는 판별자가 실제로 판단할 영상을 생성하도록 학습한다. 두 네트워크의 경쟁을 통해 결과의 사실감을 개선할 수 있다.

### 2.7 평가

| 지표 | 평가 대상 |
|---|---|
| **BLEU** | 생성문과 참조문 사이에 일치하는 단어나 연속된 단어 묶음을 바탕으로 텍스트를 평가한다. 기계 번역과 캡셔닝 등에 사용할 수 있다. |
| **ROUGE** | 생성문이 참조문의 단어나 구문을 얼마나 포함하는지 등을 평가한다. 텍스트 요약과 캡셔닝 등에 사용할 수 있다. |
| **Inception Score** | 사전학습 분류기가 각각의 생성 이미지를 얼마나 뚜렷하게 분류하는지, 생성 이미지 집합은 전체적으로 얼마나 다양한 클래스를 포함하는지 평가한다. |
| **FID** (Fréchet Inception Distance) | 특징 공간에서 실제 이미지 집합과 생성 이미지 집합의 분포 차이를 측정한다. 낮을수록 두 분포가 가깝다. |

## 3. 영상 주석 생성 1 (Image Captioning)

### 3.1 영상 주석 만들기

Image Captioning은 입력 영상의 내용을 설명하는 텍스트 캡션을 만드는 작업이다. CNN 등의 영상 Encoder로 입력 이미지에서 시각적 특징을 추출하고, RNN 또는 Transformer 기반 언어 Decoder가 그 특징을 바탕으로 캡션을 생성한다.

Attention을 사용하는 경우 현재까지 생성한 캡션을 바탕으로 영상의 영역별 관련도를 계산한다. 영역별 특징의 가중합과 앞선 토큰을 이용해 다음 토큰을 예측한다. 사람과 우산이 함께 있는 이미지라면 ‘사람’을 예측할 때와 ‘우산’을 예측할 때 더 많이 참고하는 영역이 달라질 수 있다. 종료 토큰 (EOS)이 생성될 때까지 이 과정을 반복한다.

### 3.2 주요 구성 요소

| 구성 요소 | 역할 |
|---|---|
| **영상 Encoder** | 입력 이미지에서 시각 정보가 담긴 고수준 특징 또는 임베딩을 추출한다. |
| **언어 Decoder** | 인코딩된 시각 정보를 입력받아 이미지에 대한 설명을 토큰 단위로 생성한다. |
| **문맥 벡터** | 이미지의 내용이나 현재 생성할 토큰에 필요한 특징을 일정한 크기의 수치 표현으로 요약한다. |
| **Attention** | 캡션의 단어를 생성할 때마다 영상에서 관련된 영역에 더 높은 가중치를 준다. |
| **어휘와 언어 모델** | 사용할 단어 또는 토큰을 정하고 임베딩으로 표현한다. 언어 모델은 앞선 문맥과 어울리는 토큰을 예측해 일관된 설명을 구성한다. |
| **평가 지표** | BLEU·ROUGE 등으로 생성한 캡션을 참조 캡션과 비교해 품질을 평가한다. |

### 3.3 응용 1 — 시각 보조 도구

시각장애인에게 이미지의 내용을 텍스트로 설명한다. 웹사이트나 소셜 미디어의 사진에서 사람, 물체, 동작 등을 파악하는 데 도움을 준다.

### 3.4 응용 2 — 이미지 기반 콘텐츠 색인과 검색

자동 생성한 캡션의 키워드를 이미지와 연결해 색인한다. 사용자는 이미지에 있는 내용과 관련된 문구를 입력해 검색할 수 있다.

### 3.5 응용 3 — 소셜 미디어 콘텐츠

사용자가 올린 이미지에 정보가 담긴 캡션을 자동으로 붙인다. 게시물의 맥락을 쉽게 파악할 수 있고 이미지 콘텐츠의 접근성도 높아진다.

### 3.6 이미지 캡션의 과제 1 — 세밀한 물체 인식

복잡한 장면이나 추상적인 개념이 담긴 이미지에서는 작은 물체와 세부 특징을 정확히 인식하고 설명하기 어렵다. 예를 들어 해변을 걷는 사람에게서 서핑보드를 놓치면 동작의 목적을 설명하기 어렵다. 영상 분할로 객체를 구분해 Attention의 단서로 사용할 수 있다.

### 3.7 이미지 캡션의 과제 2 — 장거리 의존성

떨어져 있는 객체와 배경의 관계를 함께 이해해야 문맥에 맞는 캡션을 만들 수 있다. RNN은 멀리 떨어진 정보를 연결하는 데 어려움을 겪을 수 있다. Transformer에서는 패치나 토큰의 위치를 반영하는 적절한 위치 인코딩이 필요하다. 예를 들어 시계탑뿐 아니라 다리와 강의 관계를 파악하면 장면을 더 구체적으로 설명할 수 있다.

### 3.8 이미지 캡션의 과제 3 — 모호성 처리

한 이미지에는 여러 유효한 설명이 있을 수 있다. 같은 해변 사진도 의자에 초점을 맞추거나 배에 초점을 맞춰 설명할 수 있다. 모델은 눈에 보이는 정보 가운데 상황과 문맥에 맞는 내용을 골라 일관된 문장을 만들어야 한다.

## 4. 영상 주석 생성 2

### 4.1 개요

Hugging Face에서 사전학습한 이미지 캡셔닝 모델을 가져와 Pokémon BLIP Captions 데이터로 Fine-tuning하고, 이미지에 대한 캡션을 생성한다.

### 4.2 Hugging Face

Hugging Face는 Transformer를 비롯한 딥러닝 모델과 데이터셋을 업로드하고 공유하는 플랫폼이다. PyTorch나 TensorFlow 기반 모델을 공유할 수 있으며, 이 예제는 PyTorch 기반 모델을 사용한다.

### 4.3 데이터셋

**Pokémon BLIP Captions** 예제에는 이미지와 텍스트 설명으로 구성된 샘플 833개가 사용된다. 예를 들어 초록색 캐릭터 이미지에 눈의 색을 설명하는 문장이 붙어 있다. FastGAN 연구에서 사용한 Pokémon 이미지에 BLIP으로 캡션을 붙여 이 이미지·텍스트 데이터셋을 만들었다.

### 4.4 전처리

이미지와 텍스트 전처리는 사용할 모델이 기대하는 입력 형식에 맞춰 수행한다. 이미지의 크기와 값의 범위를 맞추고, 캡션을 해당 모델의 토크나이저로 토큰화한다. 모델에 대응하는 Processor를 함께 사용하면 학습과 생성에서 입력 표현을 일관되게 만들 수 있다.

### 4.5 모델 — GIT

**GIT** (Generative Image-to-text Transformer)는 Microsoft의 영상·언어용 모델이다. 영상 Encoder와 텍스트 Decoder 모두에 Transformer를 사용한다. 이미지 캡션, 시각적 질문 답변, 비디오 이해에 활용할 수 있다.

1. 영상 Encoder가 이미지에서 패치별 임베딩을 얻는다.
2. 텍스트 캡션을 토큰화하고 임베딩한 뒤, 이미지 임베딩 다음에 이어 붙인다.
3. 텍스트 Decoder의 Self-Attention은 이미지 토큰 전체와 현재까지의 텍스트 토큰을 참고한다. 뒤쪽 텍스트 토큰은 Causal Mask로 가린다.
4. 학습에서는 이미지와 정답 캡션의 앞부분을 바탕으로 다음 토큰을 예측한다. 생성할 때는 예측한 토큰을 문장 뒤에 붙여 반복하고, 종료 토큰에서 멈춘다.

시각적 질문 답변에서는 이미지 특징과 질문 텍스트를 바탕으로 답변을 생성한다. 동영상을 입력할 때는 여러 프레임의 특징에 시간 정보를 반영해 처리할 수 있다.

### 4.6 훈련

사전학습 모델과 전처리한 학습·평가 데이터를 준비한다. Trainer에 모델과 데이터셋, 에포크 수·학습률·배치 크기 등 학습 설정을 전달한다. 학습을 실행해 이미지에 맞는 다음 캡션 토큰을 예측하도록 모델을 갱신하고, 평가 데이터에서 생성한 캡션을 확인한다.

## 5. 네트워크 응용

### 5.1 이미지 캡션

이미지에 대한 텍스트 설명을 자동으로 만든다. 시각장애가 있는 사용자도 이미지에 표시된 내용을 이해할 수 있도록 돕는다.

### 5.2 자동화된 보고

차트, 그래프, 지도 같은 시각 자료를 텍스트로 설명해 보고서와 문서를 작성하기 쉽게 한다. VisText는 차트의 축이나 주요 변화 등을 문장으로 설명하는 예다.

### 5.3 의료 영상

영상에 대한 설명이나 보고서 초안을 생성해 의료 전문가의 검토를 돕는다. 예를 들어 사전학습한 생성 Transformer를 사용해 흉부 X선 영상의 소견을 문장으로 표현할 수 있다.

### 5.4 교육용 콘텐츠

이미지가 포함된 교육 자료에 설명문을 붙여 시각 자료를 이해하기 쉽게 만들고 접근성을 높인다.

### 5.5 자동 감시

보안 카메라 영상에서 사람들의 행동이나 사건을 문장으로 설명해 위협 탐지와 사고 분석을 돕는다. 예를 들어 사람들이 주차장을 걷는 장면과 자전거를 타고 원을 그리는 장면을 서로 다른 캡션으로 구분할 수 있다.

### 5.6 시각적 질문 답변

이미지와 질문을 함께 받아 질문에 맞는 답을 생성한다. 사진에서 안경을 쓴 사람이 누구인지, 침대에 아이가 몇 명인지처럼 필요한 정보를 찾아 답한다. 챗봇, 가상 비서, 고객 지원 시스템에 활용할 수 있다.
