# 12. 확산 기반 영상 생성 - Stable Diffusion과 DALL-E
[[00. 생성형인공지능입문 - 시험 대비 목차|과목 목차]] · [[11. 언어 명령을 이용한 영상 생성|이전 주차]]
## 1. 영상 생성 동작 1 (Stable Diffusion)
### 1.1 Stable Diffusion 개요
**Stable Diffusion**은 **잠재 확산 모델** (Latent Diffusion Model, LDM)에 기반한 이미지 생성 모델이다. 사전학습한 Autoencoder로 이미지의 특징을 압축된 잠재 공간에 표현하고, 이 공간에서 확산을 수행한다. 여러 종류의 조건을 반영하면서 고품질 이미지를 효율적으로 생성하는 것이 목적이다.

| 구성 | 역할 |
|---|---|
| **VAE** (Variational Autoencoder) | Encoder로 이미지를 압축하고, Decoder로 잠재 표현을 픽셀 공간에 복원한다. |
| **U-Net** | 노이즈가 있는 잠재 표현과 시간 단계, 조건을 받아 노이즈를 예측한다. |
| **텍스트 Encoder** | 텍스트 조건을 사용하는 구성에서 프롬프트의 의미를 토큰 임베딩으로 표현한다. |
픽셀 공간에서 고해상도 이미지를 매 단계 처리하면 위치 수와 계산량이 커진다. 잠재 확산은 VAE로 압축한 표현을 사용해 노이즈 제거를 반복한다. 반복 단계의 계산량과 메모리 사용을 줄이고, 정제가 끝난 표현을 VAE Decoder에서 한 번 픽셀 공간으로 복원한다.
### 1.2 Stable Diffusion 모델의 학습
1. **잠재 공간으로 압축** — VAE Encoder가 픽셀 공간의 입력 이미지에서 내용과 특징을 담은 압축 표현 $z_0$을 얻는다.
2. **순방향 확산** — 잠재 표현에 정해진 스케줄로 가우시안 노이즈를 더한다. 시간 단계가 진행될수록 이미지의 원래 정보가 줄고 노이즈가 늘어난다.
3. **노이즈 예측과 역방향 정제** — 학습에서는 U-Net이 노이즈가 있는 잠재 표현 $z_t$, 시간 단계, 조건을 받아 추가된 노이즈를 예측한다. 실제로 넣은 노이즈와 예측 사이의 차이를 줄인다. 생성에서는 잠재 공간의 무작위 가우시안 노이즈에서 시작해 U-Net의 예측을 이용한다. Scheduler가 다음 잠재 상태를 계산하고, 이 과정을 반복해 잠재 표현을 정제한다.
4. **픽셀 공간으로 복원** — 생성이 끝난 잠재 표현을 VAE Decoder에 넣어 최종 이미지를 얻는다. 같은 프롬프트를 사용해도 시작 노이즈가 다르면 다른 결과를 얻을 수 있다.
[[11. 언어 명령을 이용한 영상 생성#3. 확산 모델 (Diffusion Model)|확산 과정과 응용]]
### 1.3 텍스트 기반 조건 제어
텍스트 조건으로 이미지를 생성할 때는 입력 프롬프트를 수치 표현으로 변환한다. 초기 Stable Diffusion에 사용된 사전학습 텍스트 Encoder의 예는 **CLIP ViT-L/14의 텍스트 Encoder**다. 입력 문장의 의미와 개념이 담긴 토큰 임베딩을 만든다.
U-Net은 **Cross-Attention**으로 텍스트 임베딩의 관련 부분을 참조한다. 영상의 잠재 특징에서 Query를 만들고, 텍스트 임베딩에서 Key와 Value를 만든다. 노이즈 제거 단계마다 영상의 각 위치와 관련된 텍스트 토큰에 가중치를 주어, 생성 결과에 프롬프트의 물체·특징·개념을 반영한다.
## 2. 영상 생성 동작 2 (DALL-E)
### 2.1 DALL-E 소개
초기 **DALL-E**는 텍스트 토큰과 이미지 토큰을 하나의 시퀀스로 이어 붙여 자기회귀적으로 모델링한다. Transformer는 약 **120억 개의 파라미터**로 이루어지며, 인터넷에서 수집한 약 **2억 5천만 개의 이미지·텍스트 쌍**으로 학습했다.
학습은 이미지 토큰을 만들 시각 코드북을 먼저 학습하고, 이어서 텍스트와 이미지 토큰의 결합 시퀀스를 사전학습하는 두 단계로 진행한다.
### 2.2 1단계 — 시각 코드북 학습
**이산 VAE** (dVAE)를 학습해 $256\times256$ RGB 이미지를 $32\times32$ 격자의 이미지 토큰으로 변환한다. 각 위치는 코드북에 있는 이산 토큰 하나로 표현되며, Decoder는 이 토큰으로 이미지를 재구성한다.
학습 목표는 이미지의 **증거 하한** (Evidence Lower Bound, ELBO)을 최대화하는 것이다. 이산 코드 선택을 학습할 수 있도록 **Gumbel-Softmax 완화**를 적용하고, Adam으로 최적화하면서 파라미터의 지수 가중 평균을 사용한다.
### 2.3 2단계 — 사전학습 (Pre-training)
학습한 dVAE를 사용해 이미지를 토큰 열로 변환한다. 텍스트와 이미지를 각각 다음과 같이 인코딩한다.

| 입력 | 인코딩과 어휘 |
|---|---|
| **텍스트** | BPE (Byte Pair Encoding)로 최대 256개의 토큰을 만든다. 텍스트 어휘의 크기는 16,384개다. |
| **이미지** | dVAE Encoder의 위치별 점수에서 가장 높은 토큰을 선택한다. $32\times32$ 격자, 즉 1,024개의 이미지 토큰으로 표현하며 이미지 어휘는 8,192개다. |
텍스트 토큰을 먼저 놓고 이미지 토큰을 뒤에 연결한다. Transformer Decoder는 텍스트와 이미지를 합친 토큰 열에서 앞선 토큰을 사용해 다음 토큰을 예측한다. 텍스트와 이미지의 참조 범위에 맞게 Attention Mask를 사용한다. 이미지 토큰은 앞선 텍스트에 조건을 걸고, 앞에서 생성된 이미지 토큰을 이용한다.
각 배치에서 텍스트와 이미지의 교차 엔트로피 손실을 해당 토큰 수로 각각 정규화한다. 이미지 모델링에 비중을 두기 위해 텍스트 손실에는 **1/8**, 이미지 손실에는 **7/8**을 곱해 합친다. dVAE의 파라미터를 고정한 채 텍스트와 이미지 토큰의 결합 사전분포를 학습해 전체 모델의 ELBO를 높인다.
생성할 때는 프롬프트를 BPE 텍스트 토큰으로 바꾸어 입력한다. Transformer가 그 뒤에 이미지 토큰을 하나씩 붙여 완성하면, dVAE Decoder가 이미지 토큰을 픽셀 이미지로 복원한다.
### 2.4 데이터 수집과 훈련
이미지·텍스트 쌍에는 Conceptual Captions와 YFCC100M의 일부 등이 포함됐다. MS-COCO의 캡션 데이터셋은 학습에 직접 사용하지 않았고, 평가는 MS-COCO 프롬프트에 대해 제로샷으로 진행했다. 인터넷에서 모은 학습 이미지 중에는 MS-COCO 검증 이미지와 겹치는 것이 있어, 이 이미지를 제외한 평가도 별도로 비교했다.
**혼합 정밀도 학습**은 16비트 연산을 활용해 GPU 메모리 부담을 낮추고 처리량을 높인다. 표현 가능한 범위가 작아 작은 값이 사라질 수 있으므로 학습 중 값의 스케일을 관리한다. 또한 파라미터를 분할해 여러 GPU에 학습 연산을 나누었다.
### 2.5 정량 결과 — 제로샷 비교
MS-COCO의 텍스트 프롬프트로 생성한 결과를 AttnGAN, DM-GAN, DF-GAN과 비교했다. Inception Score와 FID 등으로 생성 결과를 평가했다. 고양이와 자전거, 공항의 비행기, 탁자 위의 모형 기차처럼 캡션에 나온 물체와 배치를 반영했는지는 생성 결과와 사람 평가로도 확인했다.
### 2.6 사람에 의한 평가
DF-GAN과 동일한 캡션에서 만든 이미지들을 비교했다. 다섯 명의 평가자 중 과반이 DALL-E의 이미지를 더 실제 같다고 선택한 경우는 **90.0%**, 캡션과 더 잘 맞는다고 선택한 경우는 **93.3%**였다.
### 2.7 생성 결과 — 새로운 조합과 이미지 간 변환
아코디언으로 만든 맥 (tapir)이나 아코디언의 질감을 가진 맥처럼 뜻밖의 조합을 묘사한 이미지를 생성할 수 있었다. 고양이 사진을 받아 같은 고양이를 스케치로 표현하는 예도 있었다. 복잡한 변환에서는 결과가 일관되지 않아, 이미지 간 변환 능력은 일부 예에서 확인됐다.
## 3. DALL-E 2 소개
### 3.1 DALL-E 2 개요
**DALL-E 2** (unCLIP)는 텍스트와 이미지의 의미를 같은 공간에서 표현하는 CLIP을 사용한다. 텍스트를 조건으로 CLIP 이미지 임베딩을 먼저 생성하고, 이 임베딩에서 이미지를 만드는 계층적인 생성 방식이다.
### 3.2 CLIP (Contrastive Language–Image Pre-training)
CLIP에는 텍스트 Encoder와 이미지 Encoder가 있다. 같은 학습 배치의 캡션과 이미지를 각각 임베딩하고 코사인 유사도를 계산한다. 실제로 대응하는 이미지와 텍스트의 유사도는 높이고, 다른 쌍의 유사도는 낮추는 **대조학습**으로 두 공간을 맞춘다.
이를 이용하면 새 분류 과제에서 ‘개 사진’과 같이 클래스 이름을 자연어 설명으로 나타낼 수 있다. 입력 영상의 임베딩과 각 클래스 설명의 임베딩을 비교해, 유사도가 가장 높은 클래스를 제로샷으로 선택한다.
### 3.3 Prior와 Diffusion Decoder
- **Prior** — 캡션 또는 그 텍스트 표현을 조건으로 대응하는 **CLIP 이미지 임베딩**을 만든다. 이미지 임베딩 공간 자체를 생성 대상으로 학습하며, 자기회귀 Prior나 확산 Prior를 사용할 수 있다.
- **Diffusion Decoder** — Prior가 만든 이미지 임베딩을 조건으로 픽셀 공간에서 노이즈를 제거해 이미지를 생성한다. CLIP 이미지 Encoder가 얻은 표현을 다시 이미지로 바꾸는 역할이다. 이후 Upsampler가 해상도를 단계적으로 높인다.
### 3.4 결과 1 — 사람 평가
**Guidance scale**은 샘플링 중 조건을 얼마나 강하게 반영할지 조절한다. 값을 높이면 결과의 사실감이나 프롬프트와의 일치도가 높아질 수 있다. 조건을 강하게 반영할수록 결과가 서로 비슷해져 다양성이 줄어들 수 있다.
unCLIP과 서로 다른 Guidance 설정의 GLIDE를 **사실성, 캡션과의 일치도, 다양성**으로 비교했다. 각 설정에서 unCLIP은 적어도 한 기준에서 선호됐다. Guidance가 높은 GLIDE와 비교했을 때 unCLIP은 사실성과 캡션 일치도를 유지하면서 더 다양한 결과를 보였다.
### 3.5 결과 2 — 제로샷 FID 비교
MS-COCO에서 unCLIP과 GLIDE의 Guidance를 바꾸며 FID를 측정했다. unCLIP의 Prior에 사용하는 Guidance는 고정하고 Decoder의 값만 바꿨다. Guidance를 높이면 GLIDE에서 다양성이 크게 줄었고, unCLIP의 FID는 상대적으로 적게 악화됐다.
### 3.6 결과 3 — 생성 예시와 확산 Prior
MS-COCO 프롬프트의 물체와 장면을 반영한 이미지를 생성했다. 당시 제로샷 평가에서 확산 Prior를 사용한 unCLIP의 FID는 **10.39**였다.
## 4. DALL-E의 응용 사례
### 4.1 콘텐츠 생성
- **아트 및 디자인** — 텍스트 설명으로 예술 작품·일러스트·콘셉트 디자인을 시각화한다.
- **광고** — 광고 문구에 맞는 이미지와 그래픽을 제작한다.
### 4.2 이커머스
- **제품 시각화** — 제품 설명에서 판매용 제품 이미지나 시제품 시안을 만든다.
- **카탈로그 생성** — 이미지와 설명을 함께 담은 인쇄·디지털 카탈로그에 활용한다.
### 4.3 엔터테인먼트와 스토리텔링
- **비디오 게임 디자인** — 이야기나 게임플레이 설명에서 게임 에셋·캐릭터·장면을 만든다.
- **스토리보드** — 대본이나 줄거리로 영화·애니메이션·만화의 스토리보드 시안을 만들 수 있다.
### 4.4 인테리어 설계
- **공간 시각화** — 공간에 대한 텍스트 설명으로 실내 배치를 시각화한다. 디자이너나 거주자가 공간의 레이아웃을 계획하는 데 활용한다.
### 4.5 패션 및 의류
- **의상 제안** — 선호하는 스타일이나 의상 설명에 맞춰 의상 아이디어를 제안한다.
- **패션 디자인** — 텍스트로 표현한 디자인 콘셉트를 의류 일러스트와 시안으로 만든다.
### 4.6 건축 시각화
- **건물 설계** — 텍스트로 주어진 요구 사항에서 건물과 평면도의 시안을 시각화한다.
- **도시 계획** — 도시 계획 문서를 바탕으로 개발 프로젝트의 모습을 표현하는 데도 활용한다.
### 4.7 과학 및 연구
- **과학 시각화** — 과학 개념, 데이터, 시뮬레이션을 시각적으로 설명한다.
- **의료 영상** — 의료 보고서의 내용을 바탕으로 해부학 도표나 설명용 합성 의료 이미지를 만든다.
### 4.8 디지털 아트와 밈
- **디지털 아트** — 텍스트를 추상적인 이미지나 디지털 예술 작품으로 변환한다.
- **밈 생성** — 글로 제시한 상황에 맞는 밈, 만화, 유머 이미지를 만들 수 있다.
### 4.9 콘텐츠 개인 맞춤화
- **개인 아바타** — 사용자 설명과 선호에 맞춘 아바타나 프로필 이미지를 만든다.
- **맞춤형 콘텐츠** — 인사말 카드, 일러스트, 선물에 들어갈 이미지를 맞춤 제작할 수도 있다.
## 5. 생성 모델의 확장성
### 5.1 확장성 개요
생성 모델의 **확장성**은 요구 사항과 계산 제약에 적응하면서 여러 복잡도·크기·해상도의 결과를 생성할 수 있는 능력이다. 확장성에는 해상도 유연성, 자원 효율, 입력 적응, 점진적 개선, 스케일 간 일관성, 응용 다양성, 가용 자원에 따른 조정, 다중 스케일 표현의 여덟 가지 특성이 있다.
### 5.2 해상도 유연성
사용 목적에 따라 저해상도·중간 해상도·고해상도에서 필요한 크기와 세부 수준을 선택할 수 있다.
### 5.3 자원 효율
출력 규모가 커져도 필요한 연산과 메모리의 증가를 줄이도록 설계한다. 목표 품질을 달성하는 데 드는 계산 자원과 비용을 함께 고려한다.
### 5.4 입력 적응
입력 조건이나 파라미터가 달라지면 그에 맞게 결과를 바꿀 수 있다. 텍스트·참조 이미지나 사용자의 선호를 조건으로 주어 원하는 기준을 반영한다.
### 5.5 점진적 개선
기본적인 형태나 거친 표현에서 시작한다. 후속 단계에서 세부 사항과 복잡성을 반복적으로 추가해 큰 규모나 높은 해상도의 결과를 만든다.
여러 해상도를 사용하는 점진적 생성에서는 낮은 해상도에서 전체 배치와 큰 형태를 만든다. 후속 Upsampler가 이 결과를 조건으로 받아 해상도를 높이면서 경계·질감 등 세부를 추가한다. 처음부터 높은 해상도로 모든 단계를 계산하는 부담을 줄일 수 있다.
### 5.6 스케일 간 일관성
낮은 해상도에서 높은 해상도로 바뀌어도 주요 객체의 형태와 위치 등 큰 구조가 시각적으로 유지되도록 한다.
### 5.7 응용 다양성
이미지 합성, 초고해상도, 콘텐츠 제작, 스타일 전환 등 여러 작업에 확장 방식을 적용할 수 있다.
### 5.8 가용 자원에 따른 조정
사용 가능한 하드웨어·소프트웨어 환경에 맞춰 생성 설정을 바꾼다. 장치의 계산 능력에 맞게 속도와 품질 사이의 균형을 조절한다.
### 5.9 다중 스케일 표현
전체 구조처럼 추상적인 특징부터 작은 질감까지 서로 다른 수준의 표현을 처리한다. 각 스케일을 모델의 서로 다른 구성 요소가 맡을 수 있다.
