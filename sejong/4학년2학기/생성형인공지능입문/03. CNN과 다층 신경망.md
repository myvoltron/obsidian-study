## 1. Convolution이란?
### 1.1 특징 추출과 머신러닝·딥러닝 비교
**특징 추출** (Feature extraction)은 입력에서 후속 작업에 유용한 패턴을 찾아 모델이 사용할 수 있는 표현으로 바꾸는 과정이다.

| 방식 | 특징 추출과 다운스트림 작업 |
|---|---|
| **전통적인 머신러닝** | 특징 추출과 후속 작업을 따로 수행한다. 영상에서 경계·질감·모양 등을 수작업으로 추출한 뒤 분류에 사용한다. |
| **딥러닝** | 다층 신경망이 특징 추출과 후속 작업을 함께 학습한다. 특징을 수작업으로 설계할 필요가 없다. |
- **추출한 특징의 생성 모델 활용** — **텍스트 생성**에서는 토큰의 의미와 문맥을 벡터로 표현해 다음 토큰 예측에 사용하고, **이미지 생성**에서는 참조 영상의 형태·배치·질감을 추출해 복원하거나 생성 조건으로 반영한다.
### 1.2 Convolution · Stride · Padding의 역할
합성곱은 입력의 각 픽셀과 주변 영역에 **커널** (필터)을 적용해 특징을 추출하는 연산이다. 여러 층에 걸쳐 합성곱을 쌓으면 경계 같은 저수준 특징부터 복잡한 **계층적 특징**까지 학습한다.

| 구성 | 역할과 작동 방식 |
|---|---|
| **Convolution** (합성곱) | 커널과 같은 크기의 입력 영역에서 대응 원소끼리 곱해 모두 더한 값으로 **특징 맵** (Feature map)의 한 원소를 만든다. 영상 전체에 커널을 이동 적용해 패턴을 감지한다. |
| **Stride** | 필터가 가로·세로 방향으로 한 번에 이동하는 간격이다. Stride가 커지면 계산 위치가 줄어 출력 특징 맵 크기가 작아진다. |
| **Padding** | 입력 둘레에 값 (주로 0, Zero padding)을 덧붙여 필터 적용 영역을 넓힌다. **가장자리 정보 손실을 줄이고** 출력 특징 맵의 크기를 유지·조절한다. |
Dilation이 1이고 양쪽 Padding이 같을 때, 한 축의 출력 크기는 다음과 같다 ($N_\text{in}$: 입력 크기, $K$: 필터 크기, $P$: 한쪽 Padding, $S$: Stride).
$$
N_\text{out}=\left\lfloor\frac{N_\text{in}+2P-K}{S}\right\rfloor+1
$$
### 1.3 Convolution 응용
**CNN** (Convolutional Neural Network)은 합성곱으로 이미지의 특징을 추출하는 신경망으로, 다양한 컴퓨터 비전 과제에 쓰인다.

| 과제 | 출력 |
|---|---|
| **이미지 분류** (Image classification) | 영상 전체의 클래스를 예측한다. |
| **객체 감지** (Object detection) | 물체마다 위치와 클래스를 예측한다. |
| **인스턴스 분할** (Instance segmentation) | 같은 클래스의 물체도 개체별로 구분한 영역을 예측한다. |
| **시맨틱 분할** (Semantic segmentation) | 각 픽셀의 의미 클래스를 예측한다. |
| **파놉틱 분할** (Panoptic segmentation) | 픽셀별 의미 클래스와 물체별 개체 구분을 함께 수행한다. |
## 2. 다층 신경망
### 2.1 다층 신경망의 구성
다층 인공 신경망 (ANN)은 사람의 신경 구조에서 영감을 얻은 딥러닝의 기본 모델이며 입력층·은닉층·출력층으로 나뉜다.

| 레이어 | 받는 정보 | 역할 |
|---|---|---|
| **입력층** (Input layer) | 영상의 픽셀값이나 데이터셋 특징값 | 원시 입력값을 다음 층으로 전달한다. |
| **은닉층** (Hidden layer) | 앞선 층의 출력 | 학습을 통해 계층적 중간 표현과 패턴을 만든다. 층이 깊을수록 복잡한 특징을 표현한다. |
| **출력층** (Output layer) | 마지막 은닉층의 표현 | 과제에 맞는 최종 예측을 만든다 (다중 클래스 분류에서는 클래스마다 하나의 출력). |
### 2.2 활성화 함수 (Activation function)
ReLU와 Sigmoid 같은 비선형 활성화 함수는 신경망에 **비선형성**을 도입해 복잡한 패턴을 학습하게 한다.

| 함수 | 특징 |
|---|---|
| **Linear** | 입력을 선형 변환한다. 비선형성이 없어 여러 층을 쌓아도 표현력은 한 층과 같다. |
| **ReLU** (Rectified Linear Unit) | 음수는 0으로 바꾸고 0 이상의 값은 그대로 전달하는 비선형 함수다. |
| **Sigmoid** | 입력을 0과 1 사이의 값으로 변환하는 비선형 함수다. |
### 2.3 하이퍼파라미터 (Hyperparameter)
학습으로 추정하는 가중치와 달리 **학습 전에 사용자가 설정**하는 값으로, 적절히 선택해야 과적합·과소적합을 줄일 수 있다.

| 설정 | 조절하는 것 |
|---|---|
| **Epoch 수** | 전체 훈련 데이터셋을 몇 번 학습에 반복 사용할지 정한다. |
| **학습률** (Learning rate) | 기울기를 반영해 파라미터를 한 번에 얼마나 갱신할지 조절한다. |
| **배치 크기** (Batch size) | 한 번의 파라미터 갱신에 사용할 훈련 샘플 수를 정한다. |
| **Optimizer** | 가중치와 편향을 어떤 규칙으로 갱신할지 정한다. |
## 3. 다층 신경망의 구조
### 3.1 CNN 구성 레이어

| 레이어 | 구분 | 역할 |
|---|---|---|
| **Convolution** | 기본 | 입력 데이터에 필터를 적용해 패턴과 특징을 감지한다. |
| **Pooling** | 기본 | 공간 크기를 줄이면서 주요 특징을 요약해 필수 정보를 보존한다. |
| **Fully Connected** | 기본 | 이전 층의 모든 뉴런을 현재 층의 각 뉴런에 연결해 가중합과 활성화로 최종 출력을 만든다. |
| **Normalization** | 보조 | 이전 층의 활성화 값을 정규화해 학습 안정성과 수렴 속도를 높인다. |
| **Dropout** | 보조 | 학습 중 일부 뉴런을 무작위로 비활성화해 과적합을 줄이고 견고성을 높인다. |
| **Flatten** | 보조 | 다차원 특징 맵을 1차원 벡터로 펼쳐 Fully Connected 층에 입력할 수 있게 한다. |
### 3.2 대표 CNN 모델

| 모델 | 핵심 구조 | 목적과 효과 |
|---|---|---|
| **LeNet** | Convolution, 평균 Pooling 계열 서브샘플링, 분류용 후단 레이어로 구성된 초기 CNN이다. | 손글씨 숫자 인식에서 CNN의 효율성을 확립했다. |
| **AlexNet** | 심층 Convolution과 Fully Connected 층을 쌓은 구조다. | 2012년 ImageNet 대회 우승으로 심층 CNN의 영상 분류 성능을 입증했다. |
| **VGG** | $3\times3$ 작은 Convolution 필터를 깊고 균일하게 반복 적층한다 (VGG-16·VGG-19). | 작은 필터 반복으로 단순하고 깊은 구조의 효과를 보여줬다. |
| **GoogLeNet** | Inception 모듈이 $1\times1$, $3\times3$, $5\times5$ 합성곱을 병렬 적용해 이어 붙인다 ($1\times1$로 채널 축소). | 다양한 크기의 특징을 포착하면서 파라미터와 연산량을 줄인다. |
| **ResNet** | 잔차 블록의 **Skip connection**으로 입력 $x$를 잔차 변환 $F(x)$에 더한다. | 기울기 소실을 완화해 ResNet-152 같은 매우 깊은 모델의 학습을 가능하게 한다. |
| **DenseNet** | 각 층이 앞선 모든 층의 특징 맵을 입력으로 받는 고밀도 연결 구조다. | 특징 재사용으로 파라미터를 효율화하고 기울기가 직접 흐르는 경로를 만든다. |
## 4. 다층 신경망의 학습
**순전파 → 손실 계산 → 역전파 → 파라미터 갱신**

| 단계 | 핵심 내용 |
|---|---|
| **순전파** (Feedforward) | 입력에 Convolution, 활성화 함수, Pooling 등을 차례로 적용해 예측값을 계산한다. |
| **손실 함수** (Loss function) | 예측값과 목표값의 차이를 수치화해 큰 오류에 불이익을 주며 과제에 맞춰 선택한다. 회귀의 대표 예시인 **MSE** (평균 제곱 오차)는 예측과 목표 차이의 제곱 평균으로, 작을수록 정확하다. |
| **역전파** (Backpropagation) | 출력층에서 입력 방향으로 **연쇄 법칙** (Chain rule)을 적용해 각 파라미터가 손실에 미치는 기울기를 계산한다. |
| **최적화 알고리즘** (Optimizer) | 기울기와 학습률로 손실을 줄이는 방향으로 가중치·편향을 갱신한다. 대표적으로 미니배치 단위로 반복 갱신하는 **SGD** (확률적 경사하강법)와 **Adam**, **RMSprop**, **AdaGrad**가 있다. |
## 5. CNN의 한계

| 한계 | 발생 이유 | 결과·예시·대응 |
|---|---|---|
| **대규모 데이터셋 요구** | 다양한 영상 패턴을 학습하려면 많은 예제가 필요하다. | 데이터가 부족하면 과적합해 새 영상에서 성능이 떨어진다. |
| **이동 불변성의 한계** | 같은 물체라도 위치나 방향이 달라지면 뉴런 반응이 달라질 수 있다. | 고양이 이미지의 위치·회전을 바꾸는 데이터 증강으로 완화할 수 있으나 완전하지 않다. |
| **Pooling Layer의 정보 손실** | 주변 값을 하나로 요약해 공간 크기를 줄인다. | 특징의 정확한 위치나 부분·전체 상관관계 같은 중요 정보가 손실될 수 있다. |
| **좌표계와 부분·전체의 관계** | 국소 특징은 잘 찾지만 물체 방향 기준의 좌표 프레임이 부족하다. | 눈·코·입을 각각 찾는 것과 그 배치가 얼굴을 이루는 관계를 이해하는 것은 별개다. |
| **적대적 공격에 대한 취약성** | 입력에 미세한 의도적 변형을 주면 CNN이 오분류할 수 있다. | 자율주행처럼 안전이 중요한 분야에서는 적대적 공격에 대한 견고성이 필수다. |
