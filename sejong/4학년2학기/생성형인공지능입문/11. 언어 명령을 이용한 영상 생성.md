## 1. 언어 기반 영상 생성 구조
### 1.1 아키텍처와 구성 요소
언어 명령과 시각 정보를 결합해 지시에 맞는 이미지를 생성하거나 기존 영상을 조작하는 구조다 (예: DALL-E 계열).
**언어·시각 Encoder → Transformer Encoder → 영상 Decoder**

| 구성 요소 | 역할과 대표 모델 |
|---|---|
| **언어 Encoder** (Language Encoder) | 언어 명령을 토큰화·임베딩해 문맥 특징을 추출한다 (예: BERT). |
| **시각 Encoder** (Visual Encoder) | 이미지·영상을 색상·형태·배치 등 시각 특징으로 변환한다 (예: CNN, ViT). |
| **Transformer Encoder** | 언어 특징과 시각 특징을 결합해 멀티모달 표현 (시각–언어 특징)을 추출한다. |
| **영상 Decoder** (Visual Decoder) | 결합된 시각–언어 특징으로 이미지를 생성하거나 다음 프레임을 예측한다 (CNN 기반 Decoder, DALL-E 2의 Diffusion Decoder 등). |
### 1.2 영상 생성 손실 함수
생성 결과를 기준 영상·분포와 비교해 작업 목적에 맞는 손실을 최소화한다.

| 손실 함수 | 계산 대상과 활용 |
|---|---|
| **평균 제곱 오차** (MSE) | 대응 픽셀값 차이를 제곱해 평균한다. 노이즈 제거·초고해상도처럼 기준 픽셀 복원에 적합하다. |
| **적대적 손실** (Adversarial loss) | 판별자의 실제·가짜 판정 차이를 활용한다. 생성자가 실제처럼 보이게 학습한다. |
| **지각 손실** (Perceptual loss) | 여러 신경망 층에서 추출한 특징 표현을 비교한다. 형태·질감 등 지각적 유사성과 사실감을 높인다. |
| **KL divergence** | 두 확률 분포 간 차이를 측정한다. VAE에서 잠재 분포를 사전분포에 가깝게 정규화한다. |
## 2. 다양한 방법의 생성 모델
다양한 해상도 (스케일)의 이미지를 생성·확장하기 위한 접근법이다.

| 모델·방식 | 다중 해상도·확장 방식 |
|---|---|
| **VAE** | 기본 Encoder–Decoder 구조를 유지한 채 Decoder를 수정해 여러 해상도를 생성한다. |
| **PGGAN** (Progressive Growing of GANs) | 저해상도부터 학습을 시작해 생성자·판별자에 층을 점진적으로 추가하며 고해상도 디테일을 학습한다. |
| **조건부 이미지 생성** | 이미지 크기·해상도를 입력 조건으로 설정해 원하는 스케일로 생성한다. |
| **MSG-GAN** (멀티스케일 GAN) | 여러 해상도의 생성 결과를 동시에 처리·판별해 스케일 간 일관성을 확보한다. |
| **확산 모델** | 기본 고정 해상도 구조에 아래 확장 기법을 결합해 다양한 크기의 이미지를 생성한다. |
- **확산 모델 확장 기법** — 멀티스케일 접근, 점진적 생성 (저해상도→고해상도), 해상도 조절, **전이학습** (타 해상도 Fine-tuning), **동적 스케일링** (출력 해상도에 맞춰 단계별 노이즈 양 조절)을 활용한다.
## 3. 확산 모델 (Diffusion Model)
### 3.1 순방향 확산과 역방향 과정
데이터에 가우시안 노이즈를 점진적으로 더하는 과정 (Forward)과 이를 되돌려 노이즈를 제거하는 과정 (Reverse)을 모델링해 데이터 분포와 유사한 새 이미지를 생성한다.
**원본** $x_0$ —Forward (노이즈 단계적 추가)→ **순수 노이즈** $x_T$ —Reverse ($p_\theta$로 노이즈 단계적 제거)→ **새 이미지** $\hat{x}_0$

| 과정 | 핵심 원리 |
|---|---|
| **순방향 확산** (Forward Process) | 실제 이미지 $x_0$에서 시작해 각 단계마다 직전 상태 $x_{t-1}$에 스케줄된 분산 $\beta_t$의 가우시안 노이즈를 추가하는 **Markov chain** ($q(x_t\mid x_{t-1})$)이다. 충분히 진행한 $x_T$는 표준 정규분포에 수렴한다. |
| **역방향 학습** (Reverse Training) | 실제 역분포 $q(x_{t-1}\mid x_t)$를 직접 구할 수 없으므로 신경망 $p_\theta(x_{t-1}\mid x_t)$로 근사한다 ($\beta_t$가 작을 때 역전이도 가우시안으로 근사 가능). 노이즈가 섞인 상태와 시점을 입력받아 추가된 노이즈나 이전 상태를 예측하도록 학습한다. |
| **역방향 생성** (Reverse Sampling) | 무작위 가우시안 노이즈 $x_T$에서 시작해 학습한 역전이를 반복 적용하며 노이즈를 단계적으로 제거한다. 텍스트 설명이나 저해상도 이미지를 조건으로 줄 수 있다. |
### 3.2 대표 모델과 응용
- **대표 모델** — **GLIDE** (텍스트 조건 기반 이미지 생성·편집)와 **DALL-E 2 / unCLIP** (CLIP 이미지 임베딩을 조건으로 확산 Decoder가 이미지 생성)이 대표적이다.

| 응용 | 활용 내용 |
|---|---|
| **이미지 노이즈 제거** | 잡음이 있는 영상에서 의미 정보를 보존하며 노이즈를 제거한다 (의료 영상·사진·과학 영상). |
| **이미지 초고해상도** | 저해상도 영상에서 고해상도 세부 구조를 복원한다 (의료·감시·위성 영상). |
| **이미지 보정** (인페인팅) | 손상된 사진을 복원하고 불필요한 물체를 지우거나 누락 영역을 채운다. |
| **이미지 합성** | 광고·디자인·아트용 시각 콘텐츠를 생성한다. |
- **의료 영상 활용** (MRI·CT) — 저선량 촬영 등으로 생긴 **노이즈 제거**나 저해상도 스캔을 조건으로 한 **초고해상도 복원**에 활용하며, 선명도뿐 아니라 **해부학적 구조와 병변이 보존**되었는지 검증해야 한다.
### 3.3 장점과 과제

| 장점 | 이유 |
|---|---|
| **고품질 생성** | 여러 단계로 노이즈를 정제해 세밀한 구조와 질감을 복원한다. |
| **무작위성 제어** | 초기 노이즈와 샘플링 방식으로 재현성과 다양성을 조절한다. |
| **생성 과정 관찰** | 단계별 중간 이미지를 확인해 구조·세부 형성 과정을 파악할 수 있다. |
| **범용 활용성** | 조건·입력을 바꿔 노이즈 제거, 초고해상도, 인페인팅, 합성에 두루 적용한다. |

| 과제 | 이유 |
|---|---|
| **계산 복잡성** | 다단계 학습·추론에 많은 연산과 GPU 자원이 필요하다. |
| **순차적 추론 시간** | 역과정은 앞 단계 출력을 다음 입력으로 쓰므로 반복 생성이 느리다. |
| **학습 요구량·모델 크기** | 대규모 데이터·긴 학습 시간과 큰 메모리 때문에 경량 환경 배포가 어렵다. |
### 3.4 고해상도 이미지 생성에 유리한 이유
1. **점진적 세부 복원과 학습 안정성** — 고해상도 픽셀을 한 번에 만들지 않고 여러 단계에 걸쳐 큰 구조부터 미세 질감까지 정제하므로, GAN 대비 **모드 붕괴**와 **학습 불안정**이 적다.
2. **연산 부담 완화 확장성** — 픽셀 공간의 높은 계산 비용은 VAE 압축 공간에서 확산하는 **Latent Diffusion** ([[12. 확산 기반 영상 생성 - Stable Diffusion과 DALL-E#1.1 Stable Diffusion 개요|Stable Diffusion]])이나 저해상도 생성 후 단계적으로 키우는 **점진적 업샘플링**으로 줄일 수 있다.
## 4. 확산 생성 모델 성능 비교
모델 장단점을 비교할 때는 생성 품질 지표와 함께 학습 시간·모델 복잡도를 고려한다.

| 지표 | 평가 내용 |
|---|---|
| **PSNR** (Peak Signal-to-Noise Ratio) | 기준 이미지와 결과 이미지의 대응 **픽셀 오차** (MSE) 대비 최대 신호 전력 비율 (dB)이다. **값이 높을수록** 품질이 좋으며, 영상 압축·복원의 화질 손실 평가에 쓰인다. |
| **SSIM** (Structural Similarity Index) | 기준 이미지와 비교 이미지의 **밝기·대비·구조** 유사성을 측정하는 지각 지표다. **1에 가까울수록** 유사하며, 압축·전송 과정의 품질 저하 평가에 쓰인다. |
| **FID** (Fréchet Inception Distance) | Inception 특징 공간에서 실제 이미지 집합과 생성 이미지 집합의 **특징 분포 차이**를 측정한다. **값이 낮을수록** 두 분포가 가까우며, GAN·Diffusion의 생성 품질 평가에 쓰인다. |
## 5. 응용 사례
- **VLN** (Vision-Language Navigation) — 에이전트가 현재 시야의 시각 특징과 자연어 지시를 멀티모달로 결합해 이동 행동 $a_t$을 선택하고 목표 물체를 찾는 작업이다. 시각 특징은 CNN·ResNet·ViT, 언어 지시는 LSTM·BERT·GPT로 처리하며 강화학습 보상 $r_t$을 활용할 수 있다.
- **Coarse-to-Fine Fusion** — 장면의 거친 전역 구조와 물체의 세밀한 특징을 다중 스케일로 추출해 지시 문장과 결합하는 방식이다 (예: CF+AE, Rec-BERT+REVERIE).
- **로봇 응용** — **ChatGPT for Robotics**처럼 자연어 지시를 로봇 팔 조작 등 실제 작업으로 연결한다.
