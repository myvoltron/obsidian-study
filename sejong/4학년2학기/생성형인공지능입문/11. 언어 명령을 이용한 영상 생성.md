# 11. 언어 명령을 이용한 영상 생성

## 1. 언어 기반 영상 생성 구조
### 1.1 언어 명령 기반 영상 생성용 Transformer 아키텍처
Transformer를 이용한 언어 기반 영상 생성 구조의 구성 요소는 다음과 같다.
- **언어 Encoder**
- **시각 Encoder**
- **Transformer Encoder**
- **영상 생성용 Decoder**
- **영상 생성 및 손실 함수**
### 1.2 언어 명령 기반 영상 생성용 Transformer 모델
언어 명령 기반 영상 생성 모델은 시각 특징과 언어 특징을 결합해, 입력된 지시에 맞는 영상을 생성하거나 기존 영상을 조작한다. 언어 Encoder는 지시를 임베딩하고, Transformer Encoder를 거쳐 시각·언어 특징을 얻는다. Decoder는 이 특징을 사용해 직전 프레임에 이어 다음 프레임을 예측하거나 전체 영상을 생성한다. DALL-E 계열의 텍스트-이미지 생성이 한 예다.
### 1.3 언어 Encoder
입력된 언어 명령을 토큰으로 나누고 임베딩으로 변환한다. 임베딩을 Transformer Encoder에 넣어 문장의 내용과 문맥을 담은 특징을 얻는다. BERT를 사용할 때는 토큰 임베딩에 세그먼트 임베딩과 위치 임베딩을 더해 입력을 만든다.
### 1.4 시각 Encoder
이미지나 영상도 수치 특징으로 변환한다. CNN이나 Transformer의 일부를 사용해 색상, 형태, 공간 배치 등 시각 정보를 표현한다.
### 1.5 Transformer Encoder
언어 Encoder와 시각 Encoder에서 얻은 특징을 결합해 Transformer 층에 넣는다. 결합된 표현에서 언어 지시와 시각 정보의 관계가 반영된 특징을 얻는다.
### 1.6 영상 Decoder
영상 Decoder는 Encoder에서 얻은 시각·언어 특징을 이용해 영상을 생성한다. 동영상의 경우 앞 단계에서 생성한 프레임을 바탕으로 다음 프레임을 예측하거나, 결합된 특징을 이용해 여러 프레임을 구성할 수 있다.
이미지 생성에서는 CNN 기반 Decoder로 잠재 표현을 픽셀 이미지로 복원할 수 있다. DALL-E 2처럼 확산 과정을 이용하는 Decoder도 있다. 모델은 지시에 맞는 시각 정보를 출력에 반영해 새 이미지를 만들거나 기존 영상의 속성을 바꾼다.
### 1.7 영상 생성 및 손실 함수
대응하는 기준 영상이 있는 학습에서는 결과를 실제 영상과 비교해 손실을 계산한다. 손실을 줄이는 방향으로 파라미터를 조정해, 모델이 목표에 맞고 실제와 비슷한 영상을 생성하도록 학습한다. 어떤 차이를 줄일지는 작업의 목적에 따라 정한다.

| 손실 | 계산 대상과 활용 |
|---|---|
| **평균 제곱 오차** (MSE) | 생성 이미지와 기준 이미지의 대응 픽셀값 차이를 제곱해 평균한다. 기준에 가까운 픽셀값을 예측해야 하는 노이즈 제거와 초고해상도에 쓸 수 있다. |
| **적대적 손실** (Adversarial loss) | 판별자의 출력과 실제·가짜 목표 레이블의 차이 등으로 학습 신호를 만든다. 생성자는 판별자가 결과를 실제로 판단하도록 학습한다. |
| **지각 손실** (Perceptual loss) | 생성 이미지와 기준 이미지에서 추출한 특징 표현을 여러 층에서 비교한다. 형태와 질감 등 지각적으로 중요한 요소의 유사성을 높이는 데 사용한다. |
| **KL divergence** (Kullback–Leibler divergence) | 두 확률 분포 사이의 차이를 측정한다. VAE의 경우 인코딩한 잠재 분포가 정해진 사전분포에 가까워지도록 정규화한다. |
### 1.8 결과 및 응용
언어 명령에 맞춰 영상을 생성하거나 바꾸는 모델을 다음과 같은 작업에 활용할 수 있다.
- 콘텐츠 생성 및 확장
- 영화 및 게임 개발
- **시각적 질문 응답** (VQA) — 영상과 질문의 관계를 파악해 필요한 답을 생성한다.
- 예술적 창작
## 2. 다양한 방법의 생성 모델
### 2.1 VAE
기본 Encoder–Decoder 구조를 유지하면서 Decoder를 수정해 여러 해상도의 이미지를 생성할 수 있다.
### 2.2 PGGAN (Progressive Growing of GANs)
저해상도 영상부터 학습을 시작한다. 훈련이 진행되면서 생성자와 판별자에 층을 추가해, 더 높은 해상도의 디테일과 복잡성을 점진적으로 학습한다.
### 2.3 조건부 이미지 생성
이미지 크기나 해상도를 입력 조건으로 설정할 수 있다. 같은 구조의 모델에 서로 다른 해상도 조건을 주어 여러 스케일의 결과를 얻는다.
### 2.4 멀티스케일 GAN (MSG-GAN)
여러 해상도의 생성 결과를 동시에 처리하도록 설계된 GAN이다. 여러 스케일에서 판별 신호를 이용하므로 각 해상도에서 일관성 있는 이미지를 생성하도록 학습할 수 있다.
### 2.5 확산 모델
대표적인 확산 모델은 일정한 해상도의 이미지를 생성한다. 여러 크기의 이미지를 생성할 수 있도록 확장하는 방법에는 다음 다섯 가지가 있다.

| 방법 | 작동 방식 |
|---|---|
| **멀티스케일 접근** | 여러 해상도에서 특징을 표현하고, 해상도가 다른 표현을 활용해 큰 형태부터 작은 세부까지 다룬다. |
| **점진적 생성** | 낮은 해상도에서 전체 구조를 만들고, 후속 단계에서 해상도를 키우며 세부를 추가한다. |
| **해상도 조절** | 모델이 지원하는 범위에서 출력 해상도를 제어하거나, 선택한 해상도에 맞는 생성 단계를 사용한다. |
| **전이학습** | 사전학습 모델을 다른 해상도에 맞춰 조정한다. |
| **동적 스케일링** | 생성 중 출력 해상도에 맞춰 샘플링을 조절한다. |
### 2.6 전이학습 (Transfer Learning)
한 해상도의 이미지로 사전학습한 모델을 다른 해상도의 이미지에 Fine-tuning한다. 모델이 이미 학습한 시각 특징을 재사용해 다른 스케일에 적응시킨다.
### 2.7 동적 스케일링
일부 방법은 원하는 해상도에 맞춰 생성 중 샘플링 설정이나 단계별 노이즈 스케줄을 조정한다. 해상도에 따라 필요한 연산과 정제 정도가 달라지는 점을 반영한다. 출력 해상도에 따라 단계별로 추가되는 노이즈의 양을 조절하는 방식이 그 예다.
## 3. 확산 모델 (Diffusion Model)
### 3.1 확산 모델이란?
확산 모델은 영상 생성과 노이즈 제거에 사용할 수 있는 생성 모델이다. 데이터에 노이즈가 퍼지는 과정과 이를 되돌리는 과정을 모델링한다. 복잡한 데이터 분포를 학습해 그 분포와 비슷한 새 영상을 생성할 수 있다.
### 3.2 확산 모델 개요
순방향에서는 실제 영상에 제어된 노이즈를 단계별로 더한다. 역방향에서는 무작위 노이즈에서 시작해 학습한 모델로 노이즈를 반복적으로 제거한다. 이 과정을 거쳐 학습 데이터의 분포와 유사한 새 영상을 생성한다.
### 3.3 순방향 확산 (Forward Process)
데이터 분포에서 뽑은 실제 이미지 $x_0$로 시작한다. 한 단계마다 직전 상태 $x_{t-1}$에서 가우시안 노이즈가 더해진 새 상태 $x_t$를 얻는다. 새 상태의 분포는 직전 상태에만 의존하므로 Markov chain으로 표현한다. 대표적인 DDPM에서는 각 단계의 노이즈 분산 $\beta_t$를 사전에 정한 스케줄로 조절한다.
$$
q(x_t\mid x_{t-1})
=\mathcal N\left(x_t;\sqrt{1-\beta_t}\,x_{t-1},\beta_t I\right)
$$
순방향 전체의 전이는 각 단계의 조건부 분포를 곱한 것이다.
$$
q(x_{1:T}\mid x_0)=\prod_{t=1}^{T}q(x_t\mid x_{t-1})
$$
단계를 거치면서 원래 이미지의 신호가 약해지고 노이즈가 커진다. 충분히 진행한 $x_T$는 표준 정규분포에 가깝다.
### 3.4 역방향 과정 (Reverse Process)
노이즈가 있는 $x_t$에서 한 단계 이전의 상태를 얻는 실제 역방향 분포 $q(x_{t-1}\mid x_t)$를 직접 알기 어렵다. 신경망으로 매개변수화한 분포 $p_\theta(x_{t-1}\mid x_t)$를 학습해 이를 근사한다.
한 단계에서 더하는 노이즈가 작을 때 역방향 전이를 가우시안으로 근사할 수 있다. 가우시안의 평균과 분산을 정하는 방식은 구현마다 다르다. 학습에서는 실제 이미지에 노이즈를 섞은 상태와 시간 단계를 이용해, 노이즈나 이전 상태를 예측하도록 모델을 학습한다.
생성 시에는 가우시안 노이즈 $x_T$에서 시작한다. 학습한 역방향 전이를 모든 단계에 적용해 노이즈를 점진적으로 줄이고, 훈련 데이터의 분포와 비슷한 새 이미지 $x_0$를 얻는다. 텍스트 설명이나 저해상도 이미지를 조건으로 사용할 수도 있다.
### 3.5 확산 모델의 예
- **GLIDE** — 텍스트로 원하는 대상을 지정해 이미지를 생성하거나 편집한다. 예를 들어 슈퍼히어로 복장을 입은 아인슈타인이나 체커를 두는 고양이를 초현실적인 유화 스타일로 표현할 수 있다.
- **DALL-E 2** (unCLIP) — CLIP 이미지 임베딩을 조건으로 확산 Decoder가 이미지를 생성한다. 빅토리아 양식 집에서 현대식 집으로 이어지는 중간 이미지를 만들어 표현을 점진적으로 바꾸는 예도 있다.
### 3.6 확산 모델의 적용
| 응용 | 활용 |
|---|---|
| **이미지 노이즈 제거** | 잡음이 있는 영상에서 의미 있는 정보를 보존하며 노이즈를 줄인다. 깨끗한 신호가 중요한 의료 영상, 사진, 과학 영상에 활용된다. |
| **이미지 초고해상도** | 낮은 해상도의 영상에서 더 높은 해상도의 출력을 예측한다. 감시 영상, 위성 영상, 의료 영상에서 세부 구조를 분석하거나 해석하는 데 유용하다. |
| **이미지 보정** | 오래되거나 손상된 사진을 복원한다. 불필요한 물체를 지우거나 누락된 부분을 주변 내용과 어울리게 채울 수 있다. |
| **이미지 합성** | 광고, 디자인, 엔터테인먼트 등에 필요한 예술 이미지, 일러스트레이션과 시각 자료를 생성한다. |
**보충** · MRI·CT에서는 잡음이 있는 영상의 노이즈를 줄이거나 저해상도 영상을 조건으로 더 높은 해상도의 출력을 예측할 수 있다. 영상의 선명도와 함께 해부학적 구조와 병변이 보존됐는지도 확인한다.
### 3.7 확산 모델의 장점
| 장점 | 이유 |
|---|---|
| **고품질 이미지 생성** | 노이즈를 여러 단계에 걸쳐 정제해 실제 데이터와 유사한 세부 구조와 질감을 생성한다. |
| **무작위성 제어** | 초기 노이즈와 샘플링 방식을 정해 결과를 재현하거나 같은 조건에서 다양한 결과를 얻을 수 있다. |
| **생성 과정의 관찰** | 각 단계의 중간 이미지를 살펴보면 이미지의 큰 구조와 세부 특징이 형성되는 과정을 확인할 수 있다. 분석이나 창작에 활용할 수 있다. |
| **다양한 활용** | 조건과 입력을 바꾸어 노이즈 제거, 초고해상도, 인페인팅, 이미지 합성 등 여러 작업에 적용할 수 있다. |
### 3.8 확산 모델의 과제
| 한계 | 이유 |
|---|---|
| **계산 복잡성** | 신경망으로 여러 단계를 계산하는 학습과 추론에는 많은 연산이 든다. 해상도와 모델 크기가 커지면 GPU 같은 계산 자원이 더 많이 필요하다. |
| **학습 요구량** | 다양한 이미지 패턴을 익히려면 충분한 데이터와 시간이 필요하다. 하이퍼파라미터에 따라 학습 결과도 달라진다. |
| **추론 시간** | 역과정은 앞 단계에서 얻은 상태를 다음 단계의 입력으로 쓰므로 여러 번 순서대로 계산해야 한다. 각 단계 내부의 연산은 병렬화할 수 있다. |
| **모델 크기** | 대규모 모델의 가중치와 계산 중간 결과를 담는 메모리가 필요해 자원이 적은 환경에서는 배포하기 어렵다. |
압축된 잠재 공간에서 역과정을 반복하거나, 저해상도 이미지를 만든 뒤 해상도를 단계적으로 높이는 방식으로 고해상도 생성 비용을 줄일 수 있다. [[12. 확산 기반 영상 생성 - Stable Diffusion과 DALL-E#1.1 Stable Diffusion 개요|잠재 확산과 고해상도 생성]]
## 4. 확산 생성 모델 성능 비교
### 4.1 개요
영상 생성에 사용하는 모델을 여러 성능 지표와 생성 결과로 비교해 모델별 장단점을 파악한다.
### 4.2 성능 지표 소개
PSNR은 픽셀 오차, SSIM은 구조적 유사성, FID는 이미지 집합의 특징 분포 차이를 평가한다.
#### 4.2.1 PSNR (Peak Signal-to-Noise Ratio)
PSNR은 표현 가능한 최대 신호 전력을 기준 영상과 결과 영상 사이의 평균 제곱 오차로 나눈 값을 데시벨로 나타낸다. 기준 이미지와 출력 이미지의 대응 픽셀값 차이를 먼저 평균 제곱 오차로 계산한다. 같은 최대 픽셀값을 사용할 때 오차가 작을수록 PSNR은 높다. 영상이나 동영상의 손실 압축에서 생기는 화질 손실을 평가하는 데 쓰인다.
높이 $m$, 너비 $n$인 기준 이미지 $I$와 비교 이미지 $K$의 MSE는 다음과 같다.
$$
\operatorname{MSE}=\frac{1}{mn}
\sum_{i=0}^{m-1}\sum_{j=0}^{n-1}
[I(i,j)-K(i,j)]^2
$$
$$
\operatorname{PSNR}=10\log_{10}\frac{\mathrm{MAX}_I^2}{\operatorname{MSE}}
$$
$\mathrm{MAX}_I$는 영상 형식에서 표현할 수 있는 최대 픽셀값이다.
#### 4.2.2 SSIM (Structural Similarity Index)
SSIM은 기준 이미지와 비교 이미지가 밝기, 대비, 구조에서 얼마나 비슷한지 평가한다. 압축이나 전송 과정에서 영상 품질이 얼마나 저하됐는지 판단하는 데 쓸 수 있다. 1에 가까울수록 두 이미지가 유사하다.
$$
\operatorname{SSIM}(x,y)=
\frac{(2\mu_x\mu_y+C_1)(2\sigma_{xy}+C_2)}
{(\mu_x^2+\mu_y^2+C_1)(\sigma_x^2+\sigma_y^2+C_2)}
$$
$\mu_x,\mu_y$는 각각의 픽셀 평균, $\sigma_x^2,\sigma_y^2$는 분산, $\sigma_{xy}$는 공분산이다. $C_1,C_2$는 분모가 작을 때 계산을 안정화하는 상수다.
#### 4.2.3 FID (Fréchet Inception Distance)
FID는 생성 이미지 집합과 실제 이미지 집합의 **특징 분포**가 얼마나 비슷한지 측정한다. 두 이미지 집합을 각각 Inception 특징으로 변환하고, 특징의 평균과 공분산으로 두 분포를 근사해 거리를 계산한다. 값이 낮을수록 생성과 실제의 특징 분포가 가깝다. GAN 등에서 이미지 집합의 생성 품질을 평가할 때 사용할 수 있다.
### 4.3 모델별 성능 비교
같은 데이터와 평가 조건에서 모델별 PSNR·SSIM·FID를 표나 차트 등으로 비교할 수 있다. PSNR과 SSIM은 기준 이미지와 대응하는 결과를 비교하고, FID는 실제와 생성 이미지 집합의 분포를 비교한다.
### 4.4 장단점 분석
모델의 장단점을 판단할 때는 생성 품질과 함께 학습 시간, 모델 복잡도 등을 고려한다.
## 5. 응용 사례
### 5.1 VLN System (Vision-Language Navigation)
VLN은 에이전트가 현재 환경의 영상과 자연어 지시를 함께 사용해 이동하거나 목표 물체를 찾는 작업이다. 시각 특징은 CNN, ResNet 또는 ViT로 추출할 수 있다. 지시 문장은 LSTM이나 BERT로 텍스트 특징을 얻거나, GPT-3·GPT-4 같은 언어 모델을 사용해 해석할 수 있다. 멀티모달 결합 단계에서 두 특징을 연결해 무엇을 찾아 어디로 움직일지 결정한다.
예를 들어 ‘오른쪽으로 돌아 침대 둘레를 지나 화장실 안에서 기다려’라는 지시에는 방향, 경유할 물체, 목표 장소가 들어 있다. 에이전트는 현재 상태 $s_t$에서 다음 행동 $a_t$를 선택한다. 행동으로 환경 상태가 바뀌면 새 시야를 관찰한다. 강화학습에서는 행동이나 과제 수행 결과에 대한 보상 $r_t$를 학습 신호로 사용할 수 있다.
### 5.2 플랫폼
| 구성 | 역할과 예 |
|---|---|
| **데이터셋** | 장면을 구성할 영상이나 3D 공간 정보를 제공한다. Replica, 2D–3DS, Matterport3D 등이 있다. |
| **시뮬레이터** | 에이전트가 장면을 관찰하고 움직일 수 있는 실험 환경을 제공한다. House3D, AI2-THOR, Matterport3D Simulator 등이 있다. |
| **과제** | 환경에서 이동하며 정보를 얻는 질의응답 (EmbodiedQA), 언어 표현과 사물·행동을 연결하는 Language grounding, 상호작용형 질의응답 (Interactive QA), 시각·언어 내비게이션, 시각 내비게이션 등이 있다. |
### 5.3 3D 게임 환경
크기, 색상, 형태로 기둥·횃불 등의 객체를 구분한다. ‘가장 큰 노란색 물체로 가라’나 ‘낮은 초록색 물체로 가라’는 지시를 이해하려면 각 속성과 이동 행동을 시각 정보에 연결해야 한다. 물체가 다른 물체에 가려진 경우에는 환경을 탐색해 올바른 대상에 도달해야 한다.
### 5.4 실제 환경
여러 방향의 파노라마 시야를 사용해 다음 이동 방향을 고른다. 같은 종류의 물체도 집이나 시점에 따라 외형이 달라지므로, 물체의 위치와 공간적 관계를 함께 파악해야 한다. 예를 들어 벽난로 오른쪽으로 돌아 문을 지나고, 오른쪽으로 돌아 복도의 미닫이문 옆에서 기다리라는 지시를 현재 시야에 맞춰 해석한다.
### 5.5 제안 방법 — Coarse-to-Fine Fusion
Coarse-to-Fine Fusion은 장면 전체의 거친 구조와 물체의 세부 특징을 여러 스케일에서 추출하고 지시 문장과 결합한다. Autoencoder를 사용한 CF+AE 구성에서는 영상의 거친 단계·중간 단계·세밀한 단계 특징을 얻는다. GRU로 표현한 언어 특징과 각 단계의 시각 특징을 결합하고, LSTM으로 시점에 따른 상태를 표현한다.
REVERIE를 이용한 실험에서는 이 표현을 순환 구조가 있는 Rec-BERT에 결합한다. ResNet-152로 장면 특징을, Faster R-CNN으로 객체 특징을 얻는다. 지시 토큰과 시각 토큰을 이전 단계의 정보와 함께 처리해 다음 행동을 고르고, 지시에서 가리키는 대상 객체의 확률도 계산한다.
### 5.6 VizDoom
서로 다른 난이도에서 ‘낮은 빨간색 기둥으로 가라’, ‘높은 초록색 기둥으로 가라’, ‘갑옷으로 가라’ 같은 지시를 실행한다. 대상을 바로 볼 수 없는 상황에서는 주변을 관찰하며 경로를 선택한다.
### 5.7 REVERIE와 Matterport3D
실제 실내 공간을 스캔한 환경을 사용한다. ‘난간 쪽으로 가서 계단 오른쪽을 지나고, 거실에서 오른쪽으로 돌아 작은 탁자 옆에 멈춰라’와 같은 지시를 따라 이동한다.
