## 1. GAN의 원리
### 1.1 듀얼 네트워크와 경쟁 학습
**GAN** (Generative Adversarial Network)은 이미지 생성·스타일 전환·데이터 증강에 쓰이며, 두 신경망이 게임처럼 경쟁하며 서로 성능을 끌어올리는 프레임워크다.

- **생성자** (Generator, G) — 무작위 노이즈를 입력받아 실제와 구별되지 않는 합성 데이터를 생성해 판별자를 속이는 것을 목표로 한다.
- **판별자** (Discriminator, D) — 실제 샘플과 생성 샘플을 구분하고 진짜일 확률을 출력해 생성자에 학습 피드백을 제공한다.

**반복 훈련 흐름** (적대적 학습)
1. **데이터 생성** — G가 무작위 노이즈에서 합성 샘플을 생성한다.
2. **판별자 학습** — G를 고정한 채 실제 샘플에는 높은 진짜 점수, 생성 샘플에는 낮은 진짜 점수를 주도록 D의 손실을 줄인다.
3. **생성자 학습** — D를 고정한 채 생성 샘플이 실제로 판정되도록 D를 통과한 기울기로 G의 손실을 줄인다.
4. **반복 개선과 내시 균형** (Nash equilibrium) — D와 G를 번갈아 갱신한다. 생성 분포가 실제 분포와 같아져 **어느 쪽도 일방적으로 이득을 높일 수 없고 D가 진위를 구분하지 못하는 상태**가 이상적인 내시 균형이다.

### 1.2 GAN의 한계와 해결 방법

| 문제점 | 원인과 현상 | 기술적 해결 방법 |
|---|---|---|
| **모드 붕괴** (Mode collapse) | 서로 다른 노이즈를 넣어도 G가 D를 속이기 쉬운 비슷한 샘플만 반복 생성해 다양성이 크게 줄어든다. | D가 한 배치 안의 생성 샘플 다양성을 함께 평가하도록 설계하거나 손실 함수를 개선한다. |
| **학습 불안정** | G와 D가 번갈아 변하면서 상대의 학습 목표가 계속 달라져 손실이 진동하고 수렴이 어렵다. | G와 D의 학습률·갱신 횟수 균형을 맞추고, **Batch Normalization** (예: DCGAN) 등으로 기울기 전달을 안정화한다. |
| **하이퍼파라미터 민감성** | 두 네트워크의 균형에 맞는 설정을 찾는 데 많은 시간과 전문 지식이 필요하다. | 구조 설계 지침과 안정화된 최적화 설정을 적용한다. |
| **윤리적 문제** | 딥페이크 악용이나 학습 데이터의 편향 반영 위험이 있다. | 가짜 탐지 네트워크 개발, 데이터 편향 점검과 책임 있는 배포 규제가 필요하다. |

## 2. 영상 생성 원리
### 2.1 생성 모델 · 노이즈 · 잠재 공간
- **생성 모델 vs 판별 모델** — **판별 모델**은 클래스를 구분해 레이블을 붙이는 데 초점을 두고, **생성 모델**은 데이터의 기본 분포를 학습해 원본과 유사한 새 샘플을 생성한다 (이미지는 픽셀·그리드, 컬러 채널, 이미지 크기, 채널 깊이, 정규화·스케일링으로 수치 표현한다).
- **노이즈** (Noise) — 제어된 노이즈를 도입하면 같은 조건에서도 세부가 다른 다양한 샘플을 만들고, 현실의 미세한 불규칙성을 반영해 사실감을 높인다.
- **잠재 공간** (Latent space) — 데이터의 핵심 특징·질감·패턴을 간결하게 표현하는 추상 공간으로, 실제 이미지를 잠재 변수로 변환 (데이터 매핑)한다. 잠재 변수를 조정해 새 스타일을 만들고, 연속 잠재 공간의 두 지점 사이를 이동하면 표정·스타일 등이 **부드럽게 전환**된다.

### 2.2 조건부 이미지 생성
텍스트·레이블·참조 이미지 같은 추가 조건으로 생성 과정을 안내해 원하는 속성의 결과를 얻는다.

| 응용 | 입력·조건 | 생성 결과 |
|---|---|---|
| **스타일 전환** | 콘텐츠 이미지와 스타일 이미지 | 콘텐츠의 형태·배치를 유지하면서 스타일의 색상·질감·붓질을 반영한다. |
| **텍스트–이미지 합성** | 텍스트 설명 | GAN·VAE·Diffusion 등이 문장에 지정한 속성을 반영한 이미지를 생성한다. |
| **이미지 편집** | 원본 이미지와 편집 지시 | 원본 맥락을 유지하면서 지정한 색상·모양·객체를 수정한다. |

### 2.3 평가 지표

| 지표 | 평가 내용 |
|---|---|
| **Inception Score** (IS) | 사전학습 Inception 모델로 각 생성 이미지의 분류 명확성과 전체 클래스 다양성을 평가한다. **값이 높을수록** 우수하다. |
| **Fréchet Inception Distance** (FID) | Inception 특징 공간에서 실제 이미지 분포와 생성 이미지 분포의 차이를 측정한다. **값이 낮을수록** 두 분포가 가깝다. |
| **사람 평가** | 사람이 시각적 품질·사실감·매력을 직접 판단해 자동 지표가 놓치는 미묘한 차이를 평가한다. |

## 3. 생성형 네트워크 구조
**생성형 네트워크**는 데이터 분포를 확률적으로 학습해 새 데이터를 생성하거나 변환하는 신경망이다. 기반 구조인 **Autoencoder**는 Encoder로 입력을 저차원 잠재 표현으로 압축하고 Decoder로 원본을 재구성한다 (노이즈 제거 등에 활용).

| 모델 | 기본 구조와 학습 원리 | 생성·샘플링 원리 |
|---|---|---|
| **VAE** (Variational Autoencoder) | Autoencoder에 **확률적 잠재 변수**를 도입한다. Encoder가 입력의 잠재 분포를 추정하고 Decoder가 복원하며, 재구성 항과 잠재 분포 정규화 항으로 구성된 **변분 하한** (ELBO)을 최대화한다. | 정해진 잠재 사전분포에서 연속 잠재 벡터를 샘플링해 Decoder에 넣어 새 이미지를 생성한다 (연속 공간 이동으로 표정 등 부드러운 전환 가능). |
| **GAN** | **생성자** (G)와 **판별자** (D)가 경쟁하는 **적대적 학습**을 수행한다. 이상적인 내시 균형에서 생성 분포가 실제 분포와 같아진다. | 무작위 노이즈 벡터를 학습된 생성자 G에 입력해 한 번에 합성 샘플을 생성한다. |
| **확산 모델** (Diffusion model) | 순방향 과정에서 실제 데이터에 가우시안 노이즈를 단계적으로 더하고, 이를 되돌려 **노이즈를 제거하는 역과정**을 신경망으로 학습한다. | 무작위 가우시안 노이즈에서 시작해 학습한 역과정을 여러 단계 반복 적용하며 점진적으로 정제해 새 이미지를 생성한다. |

## 4. GAN 응용

| 응용 | 모델 | 핵심 작동 방식 |
|---|---|---|
| 이미지 생성 | **DCGAN** (Deep Convolutional GAN) | FC·Pooling 층을 배제하고 G는 Transposed Convolution (ReLU·Tanh), D는 Strided Convolution (LeakyReLU)을 사용한다. **Batch Normalization**으로 학습을 안정화한다. |
| 얼굴 생성 | **StyleGAN** | 잠재 벡터를 매핑 네트워크로 스타일 벡터로 변환해 합성 네트워크 여러 층에 반영하고 얼굴 속성을 제어한다. |
| 이미지–이미지 변환 | **CycleGAN** | 짝지어지지 않은 이미지로 두 도메인 간 양방향 변환을 학습하며, 순환 일관성으로 왕복 변환 결과가 원본에 가까워지게 한다. |
| 음악 생성 | **MuseGAN** | 무작위 노이즈에서 여러 트랙의 음표 시퀀스를 생성하고 (양방향 LSTM 등), 판별자가 실제 음악과 구분한다. |
| 자연어 생성 | **TextGAN** | RNN·LSTM·GRU 기반 생성자가 노이즈나 시드 문장에서 토큰을 순차 생성하고 판별자가 진위를 구분한다. |
| 자연어 생성 | **SeqGAN** | Monte Carlo rollout으로 미완성 시퀀스를 여러 번 완성해 판별자 보상으로 기대 보상을 추정하고 정책 경사로 생성자를 갱신한다. |
| 자연어 생성 | **LeakGAN** | 판별자가 생성 중인 문장의 내부 특징을 유출 (Leak)하면 Manager가 하위 목표를 정하고 Worker가 다음 토큰을 생성한다. |
