## 1. 단어 표현과 임베딩
### 1.1 희소·빈도 기반 표현
텍스트를 모델에 입력하려면 단어를 수치 벡터로 바꿔야 한다. 초기 방식은 어휘 인덱스나 등장 빈도에 의존한다.

| 방식 | 표현 방법 | 한계 |
|---|---|---|
| **One-hot Encoding** | 어휘에서 해당 단어의 인덱스만 1로 두고 나머지를 0으로 둔다. | 차원이 어휘 크기만큼 커지고 단어 사이의 의미가 반영되지 않는다. |
| **Bag-of-Words** (BoW) | 문장·문서에 나타난 단어별 등장 횟수를 세어 희소 벡터로 만든다 (텍스트 분류에 활용). | 단어의 순서와 주변 문맥이 사라진다. |
| **TF-IDF** | 문서 내 단어 빈도 (TF)와 전체 문서에서 드문 정도 (IDF)를 곱해 가중치를 부여한다. | 한 문서에 자주 나오고 전체에서는 드문 단어 (`car` 등)를 강조하고 흔한 단어 (`the` 등)를 낮추지만, 의미 관계는 포착하지 못한다. |
$$
\operatorname{IDF}(t)=\log\frac{N}{\operatorname{df}(t)}
$$
$N$은 전체 문서 수, $\operatorname{df}(t)$는 단어 $t$가 등장한 문서 수다.
### 1.2 학습 기반 단어 임베딩 (Word Embedding)
**단어 임베딩**은 단어를 **밀집 벡터**로 표현해 의미가 비슷한 단어끼리 벡터 공간에서 가까워지게 한다.

| 방식 | 벡터를 만드는 방식 | 표현의 특징 |
|---|---|---|
| **Word2Vec** | Skip-gram은 중심 단어에서 주변 단어를, CBOW는 주변 단어에서 중심 단어를 예측하며 학습한다. | 주위 단어가 비슷한 단어끼리 가까워지며 의미 산술 (`왕 − 남자 + 여자 ≈ 여왕`)이 가능하다. |
| **GloVe** (Global Vectors) | 전체 말뭉치의 단어 동시 등장 행렬을 이용한 행렬 분해 방식으로 밀집 벡터를 학습한다. | 말뭉치 전반의 동시 등장 패턴으로 의미·구문 관계를 표현한다. |
| **FastText** | 문자 단위 $n$-gram 벡터를 합쳐 단어를 표현한다 (`<eating>` → `<ea`, `eat`, `ati`, …). | 공유하는 하위 단어 정보를 이용해 희귀 단어, 어휘 밖 단어 (OOV), 오탈자도 표현한다. |
| **문맥 임베딩** (Contextual embedding) | 주변 문맥을 이용해 해당 위치의 동적 단어 표현을 계산한다 (ELMo·BERT·GPT). | 같은 단어라도 등장하는 문맥에 따라 다른 벡터를 얻는다. |
## 2. Transformer 전체 흐름과 위치 인코딩
### 2.1 Transformer의 전체 흐름
**입력 토큰 → 임베딩 + 위치 인코딩 → Encoder → Decoder → Linear · Softmax → 다음 토큰 예측**
1. 입력 토큰을 임베딩하고 위치 정보를 더한 뒤 **Encoder**에 넣어 문맥 표현을 얻는다.
2. **Decoder**는 지금까지 주어진 출력 토큰과 Encoder의 문맥 표현을 받아 다음 토큰을 예측한다.
### 2.2 위치 인코딩 (Positional Encoding)
Self-Attention 연산 자체에는 토큰의 순서가 담기지 않는다. Encoder와 Decoder는 토큰 임베딩에 **위치 인코딩**을 더해 입력과 출력 토큰의 순서를 전달한다.
## 3. Self-Attention
### 3.1 Self-Attention과 Query·Key·Value
각 토큰이 같은 입력 시퀀스 안에서 관련된 위치를 직접 참조해 자기 표현을 갱신한다. 입력 행렬 $X$를 서로 다른 학습 행렬로 투영해 $Q=XW_Q$, $K=XW_K$, $V=XW_V$를 만든다 (세 행렬 모두 같은 입력 시퀀스에서 나온다).

| 요소 | 역할 |
|---|---|
| **Query** (Q) | 현재 위치에서 어떤 정보를 찾을지 나타낸다. |
| **Key** (K) | 각 위치가 Query와 얼마나 관련 있는지 비교하는 데 쓰인다. |
| **Value** (V) | 관련도에 따라 가중합할 정보를 담는다. |
### 3.2 Scaled Dot-Product Attention
1. **내적** — $QK^\top$으로 각 Query와 Key의 관련도 점수를 구한다.
2. **스케일링** — 점수를 Key 차원 $d_k$의 제곱근으로 나눠 큰 내적값을 완화한다 (점수 차이가 지나치게 크면 Softmax 가중치가 일부 위치에 몰린다).
3. **마스킹** — 참조할 수 없는 위치의 점수에 $-\infty$를 더한다. **Causal mask**는 미래 토큰, **Padding mask**는 패딩 토큰을 가린다.
4. **Softmax** — Query마다 Key 방향으로 정규화해 가중치 합을 1로 만든다 (가려진 위치는 0이 된다).
5. **Value 가중합** — 가중치로 Value를 합쳐 현재 위치의 문맥 벡터 (Context vector)를 만든다.
예: 두 번째 토큰의 점수가 $[0.1, 0.6, 0.2, 0.1]$이면 Causal mask 적용 후 $[0.1, 0.6, -\infty, -\infty]$가 되어 앞선 두 토큰만 출력에 기여한다.
$$
\operatorname{Attention}(Q,K,V)=\operatorname{softmax}\left(\frac{QK^\top}{\sqrt{d_k}}+M\right)V
$$
### 3.3 Self-Attention의 장점과 계산 비용

| 항목 | 이유와 조건 |
|---|---|
| **장거리 의존성 파악** | 멀리 떨어진 위치도 한 레이어에서 직접 참조해 복잡한 문맥 관계를 포착한다. |
| **문맥 기반 표현** | 같은 단어도 주변 토큰과의 관련도에 따라 다른 문맥 벡터가 만들어지며, 국소·전역 관계를 함께 반영한다. |
| **병렬 처리** | 시퀀스가 주어지면 직전 위치의 상태를 기다리지 않고 여러 위치를 동시에 계산한다. |
| **계산 비용** | 표준 Self-Attention은 입력 길이 $N$에 대해 $N\times N$ 점수 행렬을 계산하므로 시간·메모리 비용이 길이의 제곱 ($O(N^2)$)에 비례한다. |
- **추가 활용** — 가변 길이 시퀀스 처리, 대규모 사전학습 후 다운스트림 Fine-tuning, 이미지·오디오 등 멀티모달 확장, Attention 가중치를 통한 해석에 유리하다.
## 4. Multi-Head Attention
### 4.1 Single-Head와 Multi-Head 비교

| 방식 | Q·K·V 투영 | 포착하는 관계 |
|---|---|---|
| **Single-Head Attention** | Q·K·V를 한 세트로 투영한다. | 하나의 가중치 분포로 입력 관계를 반영한다. |
| **Multi-Head Attention** | 헤드마다 별도의 Q·K·V 투영을 학습한다. | 가까운 위치와 먼 위치 등 서로 다른 관계를 병렬로 포착한다. |
### 4.2 작동 방식과 장점
1. 입력을 헤드마다 별도의 $Q, K, V$로 투영한다 (예: 512차원을 8개 헤드 × 64차원으로 분할).
2. 각 헤드에서 Scaled Dot-Product Attention을 독립적으로 계산한다.
3. 각 헤드의 출력을 이어 붙이고 (Concat), 선형 투영해 최종 표현을 얻는다 (64차원 × 8 → 512차원).

| 장점 | 이유 |
|---|---|
| **병렬 연산과 하드웨어 효율** | 여러 헤드의 행렬 연산을 GPU·TPU에서 동시에 실행해 속도와 확장성을 높인다. |
| **관계별 특화와 문맥 이해** | 헤드마다 서로 다른 의존성·패턴에 특화돼 폭넓은 문맥을 반영하고 성능을 높인다. |
| **구조 유연성** | 과제 복잡도와 계산 자원에 맞춰 헤드 수를 조정할 수 있다. |
## 5. Encoder·Decoder 내부 구조와 출력
### 5.1 Transformer Encoder와 Decoder
- **Encoder** — 같은 구조의 레이어를 반복 적층한다. 각 레이어는 **Multi-Head Self-Attention → 위치별 FFN**으로 구성되며, 각 하위 레이어 뒤에 **Add & Norm** (잔차 연결 + Layer Normalization)을 적용해 학습을 안정화한다.
- **Decoder** — 각 레이어가 **Masked Self-Attention → Cross-Attention → 위치별 FFN** 순으로 계산한다 (마찬가지로 각 하위 레이어 뒤에 **Add & Norm** 적용).

| Attention | Query 입력 | Key·Value 입력 | 참조 범위 |
|---|---|---|---|
| **Encoder Self-Attention** | Encoder 시퀀스 | 같은 Encoder 시퀀스 | 입력 시퀀스 전체 위치 |
| **Masked Decoder Self-Attention** | Decoder 시퀀스 | 같은 Decoder 시퀀스 | 현재 위치까지의 출력 토큰 |
| **Cross-Attention** | Decoder 표현 | Encoder 출력 | 원문 (Encoder) 전체 위치 |
### 5.2 Linear·Softmax와 학습·생성 차이
Linear 층은 Decoder의 마지막 표현을 어휘별 점수로 바꾸고, Softmax는 이를 다음 토큰의 확률 분포로 변환한다.

| 단계 | Decoder 입력 | 토큰 처리 방법 |
|---|---|---|
| **학습** | 정답 시퀀스를 오른쪽으로 한 칸 밀고 맨 앞에 시작 토큰을 둔다. | Causal mask로 미래 토큰을 가리고, 주어진 여러 위치의 다음 토큰을 **병렬**로 예측한다. |
| **생성** | 시작 토큰이나 앞서 생성한 출력 토큰에서 시작한다. | 다음 토큰 하나를 선택해 입력 뒤에 붙이며, 종료 토큰이 나올 때까지 **자기회귀적**으로 반복한다. |
## 6. RNN과 Transformer 비교

| 관점 | RNN | Transformer |
|---|---|---|
| **장거리 의존성** | 정보가 여러 hidden state를 거쳐야 하며 시간축 역전파에서 기울기 소실·폭발이 발생할 수 있다. | Self-Attention으로 멀리 떨어진 위치도 한 레이어에서 직접 참조해 정보 전달 경로가 짧아진다. |
| **병렬화** | 현재 상태 $h_t$ 계산에 이전 상태 $h_{t-1}$이 필요해 시간축 계산이 순차적이다. | Encoder와 학습 중 주어진 Decoder 위치는 병렬로 계산한다 (추론 생성은 한 토큰씩 자기회귀). |
| **순서 정보** | 입력을 순서대로 읽으며 상태에 순서를 반영한다. | 토큰 임베딩에 **위치 인코딩**을 더해 순서를 전달한다. |
