# 04. 트랜스포머 1 - 임베딩과 Attention

[[00. 생성형인공지능입문 - 시험 대비 목차|과목 목차]] · [[03. 컨볼루션 신경망 개요|이전 주차]] · [[05. 트랜스포머 2 - ViT와 U-Net|다음 주차]]

## 1. 단어 표현과 임베딩

### 1.1 단어 임베딩 (Word embedding)

단어 임베딩은 단어를 **밀집 벡터**로 표현한다. 학습한 벡터에는 단어 사이의 의미 관계가 반영될 수 있다. 의미가 비슷한 단어는 벡터 공간에서 서로 가까울 수 있다.

### 1.2 단어 표현 방법

텍스트를 모델에 입력하려면 단어와 문맥을 수치로 표현해야 한다. 표현 방식에 따라 어휘 인덱스, 등장 빈도, 단어 사이의 의미 관계, 주변 문맥 가운데 담을 수 있는 정보가 달라진다.

### 1.3 One-hot Encoding과 Bag-of-Words

| 방식 | 수치로 표현하는 방법 | 한계 |
|---|---|---|
| **One-hot Encoding** | 어휘에서 해당 단어의 인덱스만 1로 두고 나머지를 0으로 둔다. | 차원은 어휘 크기만큼 필요하며 단어 사이의 의미가 벡터에 반영되지 않는다. |
| **Bag-of-Words** (BoW) | 문장이나 문서에 나타난 단어별 등장 횟수를 세어 희소 벡터로 만든다. 단순하고 효율적이라 텍스트 분류에 쓰인다. | 단어의 순서와 주변 문맥이 사라진다. |

### 1.4 TF-IDF (Term Frequency–Inverse Document Frequency)

**TF**는 특정 문서에서 단어가 얼마나 자주 나타나는지, **IDF**는 전체 문서에서 그 단어가 얼마나 드문지를 나타낸다. 두 값을 곱하면 한 문서에서 자주 나오고 전체 문서에서는 드문 단어에 높은 가중치가 붙는다.

$$
\operatorname{IDF}(t)=\log\frac{N}{\operatorname{df}(t)}
$$

$N$은 전체 문서 수, $\operatorname{df}(t)$는 단어 $t$가 한 번이라도 나온 문서 수다.

| 단어 | 두 문서에서의 등장 여부 | IDF와 TF-IDF |
|---|---|---|
| `the` | 두 문서 모두 등장 | $\log_{10}(2/2)=0$이므로 TF-IDF도 0이다. |
| `car` | 한 문서에만 등장 | $\log_{10}(2/1)\approx0.301$이다. 등장한 문서에서 TF가 $1/7$이면 TF-IDF는 약 0.043이다. |

### 1.5 학습 기반 임베딩

| 방식 | 벡터를 만드는 방식 | 표현의 특징 |
|---|---|---|
| **Word2Vec** | Skip-gram은 중심 단어에서 주변 단어를, CBOW는 주변 단어에서 중심 단어를 예측하며 벡터를 학습한다. | 주위 단어가 비슷한 단어끼리 가까워질 수 있다. |
| **GloVe** (Global Vectors for Word Representation) | 전체 말뭉치의 단어 동시 등장 행렬을 이용한다. 가중 행렬 분해와 유사한 방식으로 밀집 벡터를 학습한다. | 말뭉치 전반에서 단어가 함께 나오는 패턴으로 의미·구문 관계를 표현한다. |
| **FastText** | 문자 단위의 $n$-gram 벡터를 합쳐 단어를 표현한다. | 접두사나 접미사처럼 공유하는 부분을 이용할 수 있어 희귀 단어, 어휘 밖의 단어, 철자가 조금 다른 단어도 표현할 수 있다. |
| **문맥 임베딩** (Contextual embedding) | 주변 문맥을 이용해 해당 위치의 단어 표현을 계산한다. ELMo·BERT·GPT가 사용하는 방식이다. | 같은 단어라도 등장하는 문맥에 따라 다른 벡터를 얻는다. |

Word2Vec에서는 ‘왕 − 남자 + 여자’가 ‘여왕’의 벡터에 가까워질 수 있다. FastText에서는 단어의 양끝을 표시한 `<eating>`에서 `<ea`, `eat`, `ati`, `tin`, `ing`, `ng>`의 3-gram을 얻는다.

## 2. Transformer 전체 흐름과 위치 인코딩

### 2.1 Transformer의 전체 흐름

1. 입력 토큰을 임베딩하고 위치 정보를 더한 뒤 **Encoder**에 넣어 문맥 표현을 얻는다. 
2. **Decoder**는 지금까지 주어진 출력 쪽 토큰과 Encoder의 문맥 표현을 받아 다음 토큰을 예측한다. 
3. 번역에서는 원문의 문맥 표현을 참고해 번역문을 이어서 생성한다.

### 2.2 위치 인코딩 (Positional Encoding)

Self-Attention 연산 자체에는 토큰의 순서가 담기지 않는다. Encoder와 Decoder는 토큰 임베딩에 **위치 인코딩**을 더해 입력과 출력 쪽 토큰의 순서를 전달한다.

## 3. Self-Attention

### 3.1 Self-Attention의 개요

각 토큰이 같은 입력 시퀀스 안에서 관련된 위치를 참조해 자기 표현을 갱신한다. 멀리 떨어진 토큰도 직접 참조할 수 있다. BERT와 GPT 등은 Self-Attention을 문맥 표현에 사용하고, 이 표현은 번역·감성 분석·질의응답 등에 활용할 수 있다.

### 3.2 Query·Key·Value

입력 행렬 $X$를 서로 다른 학습 행렬로 투영해 $Q=XW_Q$, $K=XW_K$, $V=XW_V$를 만든다. Self-Attention의 세 행렬은 같은 입력 시퀀스에서 나온다.

| 요소        | 역할                                  |
| --------- | ----------------------------------- |
| **Query** | 현재 위치에서 어떤 정보를 찾을지 나타낸다.            |
| **Key**   | 각 위치가 Query와 얼마나 관련 있는지 비교하는 데 쓰인다. |
| **Value** | 관련도에 따라 가중합할 정보를 담는다.               |

### 3.3 Scaled Dot-Product Attention

1. **내적** — $QK^\top$으로 각 Query와 Key의 관련도 점수를 구한다.
2. **스케일링** — 점수를 Key 차원 $d_k$의 제곱근으로 나눠 큰 내적값을 완화한다. 점수 차이가 지나치게 크면 Softmax 가중치가 일부 위치에 몰릴 수 있다.
3. **마스킹** — 참조할 수 없는 위치의 점수에 $-\infty$를 더한다. Causal mask는 미래 토큰, Padding mask는 길이를 맞추기 위해 추가한 토큰을 가린다.
4. **Softmax** — Query마다 Key 방향으로 정규화해 가중치 합이 1이 되게 한다. 가려진 위치의 가중치는 0이 된다.
5. **Value 가중합** — 가중치로 Value를 합쳐 현재 위치의 문맥 벡터 (Context vector)를 만든다.

두 번째 토큰의 점수가 $[0.1, 0.6, 0.2, 0.1]$이면 Causal mask 적용 후 $[0.1, 0.6, -\infty, -\infty]$가 된다. 첫 번째와 두 번째 토큰만 출력에 기여한다.

$$
\operatorname{Attention}(Q,K,V)=
\operatorname{softmax}\left(\frac{QK^\top}{\sqrt{d_k}}+M\right)V
$$

$M$은 필요에 따라 적용하는 Mask다.

### 3.4 Self-Attention의 장점과 계산 비용

| 항목               | 이유와 조건                                                                                 |
| ---------------- | -------------------------------------------------------------------------------------- |
| **장거리 의존성 파악**   | 멀리 떨어진 위치도 한 레이어에서 직접 참조해 복잡한 문맥 관계를 포착할 수 있다.                                         |
| **상황에 맞는 표현**    | 같은 단어도 주변 토큰과의 관련도에 따라 다른 문맥 벡터가 만들어진다.                                                |
| **병렬 처리**        | 시퀀스가 주어져 있으면 직전 위치의 상태를 기다릴 필요 없이 여러 위치를 동시에 계산할 수 있다.                                 |
| **가변 길이 시퀀스 처리** | 정해진 입력 범위 안에서 길이가 다른 문장이나 문서에도 같은 연산을 적용할 수 있다.                                        |
| **계층 구조의 관계 파악** | 가까운 위치의 국소 관계와 시퀀스 전반의 전역 관계를 함께 반영할 수 있다.                                             |
| **확장성과 계산 비용**   | 표준 Self-Attention은 입력 길이 $N$에 대해 $N\times N$ 점수 행렬을 계산한다. 시간·메모리 비용은 길이의 제곱에 비례해 증가한다. |

### 3.5 사전학습·멀티모달 적용·가중치 해석

대규모 텍스트로 사전학습한 모델을 다운스트림 과제에 맞춰 Fine-tuning할 수 있다. 이미지나 오디오도 토큰으로 표현해 Attention을 적용할 수 있다. Attention 가중치는 출력 위치가 입력의 어느 위치를 많이 참고했는지 확인하는 단서가 된다.

## 4. Multi-Head Attention

### 4.1 Multi-Head Attention 개요

여러 헤드가 입력을 서로 다른 표현으로 투영해 각기 다른 관계를 학습한다.

### 4.2 Single-Head와 Multi-Head 비교

| 방식 | Q·K·V 투영 | 포착하는 관계 |
|---|---|---|
| **Single-Head Attention** | Q·K·V를 한 세트로 투영한다. | 하나의 가중치 분포로 입력 관계를 반영한다. |
| **Multi-Head Attention** | 헤드마다 별도의 Q·K·V 투영을 학습한다. | 가까운 위치와 먼 위치 등 서로 다른 관계를 병렬로 포착한다. |

### 4.3 Multi-Head Attention의 작동 방식

1. 입력을 헤드마다 별도의 $Q,K,V$로 투영한다.
2. 각 헤드에서 Scaled Dot-Product Attention을 독립적으로 계산한다.
3. 각 헤드의 출력을 이어 붙인다 (Concat).
4. 이어 붙인 벡터를 선형 투영해 최종 표현을 얻는다.

모델 차원이 512이고 헤드가 8개라면, 헤드마다 Q·K·V를 64차원으로 투영할 수 있다. 64차원 출력 8개를 이어 붙이면 다시 512차원이 된다.

### 4.4 Multi-Head Attention의 장점

| 항목 | 이유 |
|---|---|
| **빠른 연산** | 여러 헤드의 Attention을 동시에 계산할 수 있다. |
| **문맥 이해** | 입력의 여러 부분과 단어 관계를 함께 봐 더 폭넓은 문맥을 반영한다. |
| **성능 개선** | 복잡한 의존성이나 미묘한 관계를 여러 헤드에 걸쳐 표현할 수 있어 자연어 처리 성능을 높이는 데 도움이 된다. |
| **확장 가능성** | 늘어난 헤드의 연산도 병렬로 배치할 수 있다. 입력이 길어지면 헤드별 점수 행렬의 크기는 커진다. |
| **관계별 특화** | 헤드마다 서로 다른 관계나 패턴에 특화될 수 있다. |
| **하드웨어 활용** | GPU·TPU 등에서 여러 헤드의 행렬 연산을 병렬로 실행할 수 있다. |
| **유연성** | 과제의 복잡성과 계산 자원에 맞춰 헤드 수를 설정할 수 있다. |

## 5. Encoder·Decoder 내부 구조와 출력

### 5.1 Transformer Encoder

같은 구조의 레이어를 반복해서 쌓는다. 각 레이어의 **Multi-Head Self-Attention**은 입력 위치 사이의 관계를 반영한다. 이어서 **FFN** (Feed-Forward Network)은 위치별 벡터를 독립적으로 변환한다. 최종 입력 문맥 표현은 Decoder에 전달한다.

Encoder와 Decoder의 각 하위 레이어 뒤에 **Add & Norm**을 적용한다. Add는 입력을 하위 레이어의 출력에 더하고, Norm은 각 토큰의 특징 차원을 정규화해 학습을 안정화한다.

### 5.2 Transformer Decoder

Decoder도 같은 구조의 레이어를 반복해서 쌓는다. 한 레이어는 **Masked Self-Attention → Cross-Attention → 위치별 FFN** 순으로 계산한다. Masked Self-Attention은 출력 쪽 미래 토큰을 가리고, Cross-Attention은 Encoder의 출력이 담은 원문 정보를 참고한다.

| Attention | Query를 만드는 입력 | Key·Value를 만드는 입력 | 참조 범위 |
|---|---|---|---|
| **Encoder Self-Attention** | Encoder 쪽 시퀀스 | 같은 Encoder 쪽 시퀀스 | 입력 시퀀스의 위치 |
| **Masked Decoder Self-Attention** | Decoder 쪽 시퀀스 | 같은 Decoder 쪽 시퀀스 | 현재 위치까지의 출력 쪽 토큰 |
| **Cross-Attention** | Decoder 표현 | Encoder 출력 | 원문 위치 |

### 5.3 Linear와 Softmax

Linear 층은 Decoder의 마지막 표현을 어휘별 점수로 바꾼다. Softmax는 그 점수를 다음 토큰의 확률 분포로 변환한다.

| 단계 | Decoder 입력 | 토큰 처리 방법 |
|---|---|---|
| **학습** | 정답 시퀀스를 오른쪽으로 한 칸 밀고 맨 앞에 시작 토큰을 둔다. | Causal mask로 뒤의 토큰을 가리고, 주어진 여러 위치의 다음 토큰을 병렬로 예측한다. |
| **생성** | 시작 토큰이나 앞서 주어진 출력 토큰에서 시작한다. | 다음 토큰 하나를 선택해서 입력 뒤에 붙인다. 종료 토큰이 나올 때까지 이 과정을 반복한다. |

## 6. RNN과 Transformer 비교

| 관점 | RNN | Transformer |
|---|---|---|
| **장거리 의존성** | 정보가 여러 hidden state를 거쳐야 한다. 시간축 역전파에서 기울기가 소실되거나 폭발할 수 있고, 특히 기울기 소실은 먼 시점 사이의 관계 학습을 어렵게 한다. | Self-Attention으로 멀리 떨어진 위치도 한 레이어에서 직접 참조해 정보 전달 경로가 짧아진다. |
| **병렬화** | 현재 상태 $h_t$를 구하려면 이전 상태 $h_{t-1}$이 필요해 시간축 계산이 순차적이다. | Encoder와 학습 중 주어진 Decoder 위치는 병렬로 계산할 수 있다. 자기회귀 생성에서는 앞서 생성한 토큰을 사용해 한 토큰씩 이어 간다. |
| **순서 정보** | 입력을 순서대로 읽으며 상태에 순서를 반영한다. | 토큰 임베딩에 위치 인코딩을 더해 순서를 전달한다. |
