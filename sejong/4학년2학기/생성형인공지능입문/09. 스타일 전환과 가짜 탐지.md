## 1. 스타일 생성 (Style Generation)
### 1.1 스타일 전환과 NST·CycleGAN
**스타일 생성**은 이미지에 특정 예술가·사조·디자인의 시각 스타일을 결합하는 작업이며, **스타일 전환** (Style Transfer)은 콘텐츠 이미지의 형태·배치를 유지하면서 스타일 이미지의 색상·질감·붓질을 반영한다.

| 방식 | 핵심 구조와 원리 |
|---|---|
| **NST** (Neural Style Transfer) | 심층 CNN으로 콘텐츠 특징과 스타일 특징을 분리해 추출한 뒤, 결과 이미지가 콘텐츠 특징과 스타일 특징을 함께 만족하도록 최적화한다. 인접 픽셀의 급격한 변화를 줄이기 위해 **Total variation loss**를 함께 쓰기도 한다. |
| **CycleGAN** | 짝지어지지 않은 두 도메인 간 변환을 학습한다. 생성자 2개 ($G: X\to Y$, $F: Y\to X$)와 판별자 2개 ($D_X, D_Y$)로 구성되며, **Adversarial loss** (목표 도메인처럼 생성)와 **순환 일관성 손실** ($F(G(x))\approx x$, $G(F(y))\approx y$로 원본 보존)을 함께 사용한다. |

- **응용과 과제** — 예술적 렌더링 (사진→회화), 브랜드 맞춤형 디자인 (로고·광고)에 활용하며, **콘텐츠 보존** (원래 객체 유지와 스타일 반영 균형), **스타일 일관성** (이미지 전체의 조화), **주관성** (사용자별 선호 강도 조절)이 주요 과제다.

## 2. 예술 작품 생성 실습 (Generation of Artwork)
ImageNet으로 사전학습한 **VGG-19**의 Convolution 특징 추출부를 고정한 채, 결과 이미지의 픽셀을 직접 갱신해 콘텐츠 거리 $D_c$와 스타일 거리 $D_s$의 가중합 $L=\alpha D_c+\beta D_s$를 반복 최소화한다.

| 손실 | 비교 대상과 역할 |
|---|---|
| **콘텐츠 손실** (Content loss) | 선택한 층에서 결과 이미지와 콘텐츠 이미지의 특징 맵을 비교해 형태와 배치를 유지한다. |
| **스타일 손실** (Style loss) | 선택한 층에서 결과 이미지와 스타일 이미지의 **Gram matrix** (특징 채널 간 상관관계)를 비교해 질감과 색상 패턴을 반영한다. |

## 3. 유명 인물 생성 실습 (Generation of Celebrity)
유명인 얼굴 데이터셋 **CelebA**로 **DCGAN**을 학습해 새로운 합성 얼굴 이미지를 생성한다.

| 구성 | 층 구성과 활성화 함수 |
|---|---|
| **생성자** (G) | 잠재 노이즈 벡터 $z$를 **Transposed Convolution**으로 해상도를 단계적으로 높여 RGB 얼굴을 만든다. 중간층은 BatchNorm + ReLU, 출력층은 **Tanh** (픽셀 범위 $[-1,1]$)를 사용한다. |
| **판별자** (D) | 입력 얼굴을 **Strided Convolution**으로 해상도를 낮추며 진위를 분류한다. 중간층은 BatchNorm + **LeakyReLU**, 출력층은 **Sigmoid** (실제 확률)를 사용한다. |

- **BCE 손실과 교대 학습** — 판별자와 생성자 모두 이진 교차 엔트로피 (BCE) 손실을 사용한다. 판별자 D는 G를 고정한 채 실제 배치를 1, 생성 배치를 0으로 분류하도록 ($\log D(x)+\log(1-D(G(z)))$ 최대화) 학습하고, 생성자 G는 D를 고정한 채 생성 이미지의 목표 레이블을 1로 두어 ($-\log D(G(z))$ 최소화) D를 속이도록 갱신한다.

## 4. 가짜 식별 네트워크 1 (Fake Detection Network)
### 4.1 원리와 탐지 모델
**가짜 식별 네트워크**는 이미지·동영상·텍스트에서 결함·불일치·불규칙성 같은 단서를 학습해 실제 콘텐츠와 합성·변조 콘텐츠를 구분한다.

| 접근 방식 | 핵심 작동 방식 |
|---|---|
| **랜드마크 특징 추출** | 얼굴의 눈·코·입 같은 기준 **랜드마크** 분포와 움직임을 실제 얼굴 패턴과 비교해 조작 흔적을 찾는다. |
| **가짜 탐지용 GAN** | 적대적 학습에서 실제·합성 미디어를 구분하도록 훈련한 판별자 (D)를 재사용해 미세한 합성 불일치를 탐지한다. |
| **가짜 탐지용 CNN·RNN** | CNN으로 각 프레임의 저수준 경계·질감과 고수준 얼굴 특징을 추출하고, RNN으로 프레임 간 시간적 변화를 분석해 영상 진위를 판별한다. |

### 4.2 가짜 탐지 평가 지표
가짜 콘텐츠를 양성으로 둘 때 **TP**는 가짜를 가짜로 맞힌 수, **FP**는 진짜를 가짜로 오탐한 수, **FN**은 가짜를 놓친 (미탐) 수다.

| 지표 | 평가 내용 |
|---|---|
| **정확도** (Accuracy) | 전체 샘플 중 옳게 분류한 비율이다. 진짜가 압도적으로 많은 불균형 데이터에서는 가짜를 많이 놓쳐도 높게 나올 수 있다. |
| **정밀도** (Precision) | 가짜로 분류한 항목 중 실제 가짜 비율이다 ($\mathrm{TP}/(\mathrm{TP}+\mathrm{FP})$). 진짜를 가짜로 잘못 판단하는 **오탐**의 영향을 받는다. |
| **재현율** (Recall, Sensitivity) | 실제 가짜 중 가짜로 찾아낸 비율이다 ($\mathrm{TP}/(\mathrm{TP}+\mathrm{FN})$). 가짜를 놓치는 **미탐**의 영향을 받는다. |
| **F1 점수** | 정밀도와 재현율의 조화평균으로, 두 지표의 균형을 함께 평가한다. |

## 5. 가짜 식별 네트워크 2
- **응용** — **이미지 조작 탐지** (표정 변경·객체 제거·배경 교체 불일치), **비디오 변조 탐지** (프레임 간 시간적 불규칙성), **콘텐츠 진위 검증** (기사·소셜 미디어 오정보 확산 방지)에 활용한다.
- **도전 과제와 한계** — 탐지기를 속이는 **적대적 공격**, 학습 데이터 편향으로 인한 일반화 한계, 빠르게 변하는 조작 기법과 학습에 없던 **미관측 조작** (제로데이), 앞뒤 장면의 맥락 이해 필요성, 데이터 수집 시 개인정보·권리 보호가 주요 과제다.
- **윤리적 고려 사항** — 분석 과정의 개인정보 침해, 데이터 편향에 따른 공정성 문제, **오탐** (정상 콘텐츠 피해)과 **미탐** (조작 유통)의 위험, 판정 근거의 투명성·설명 가능성, 과도한 검열과 표현의 자유 위축, 탐지 기술이 더 정교한 조작 기법을 촉진하는 부작용을 고려해야 한다.
