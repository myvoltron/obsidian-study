## 1. Convolution이란?

### 1.1 머신러닝과 딥러닝 비교

**특징 추출**은 입력에서 후속 작업에 유용한 패턴을 찾아 모델이 사용할 수 있는 표현으로 바꾸는 과정이다.

| 방식 | 특징 추출과 다운스트림 작업 |
|---|---|
| 전통적인 머신러닝 | 특징 추출과 후속 작업을 따로 수행한다. 영상에서 경계·질감·모양 등을 추출한 뒤 분류에 사용한다. |
| 딥러닝 | 다층 신경망이 특징 추출과 후속 작업을 함께 학습한다. 특징을 수작업으로 설계할 필요가 없다. |

**보충** · 추출한 특징의 활용

| 활용 | 추출한 특징의 역할 |
|---|---|
| **텍스트 생성** | 토큰의 의미와 문맥을 벡터로 표현해 다음 토큰 예측에 사용한다. |
| **이미지 생성** | 참조 영상의 형태·배치·질감을 추출해 영상을 복원하거나, 생성 조건으로 사용해 결과 영상의 구조나 속성에 반영한다. |

### 1.2 Convolution (합성곱)

- 합성곱은 두 함수를 결합해 새로운 함수를 만드는 연산이다.
- 영상 처리에서는 커널을 각 픽셀과 그 주변에 적용해 영상을 변환한다.
- 신경망은 합성곱을 여러 층에서 적용해 경계 같은 낮은 수준의 특징부터 더 복잡한 **계층적 특징**까지 학습한다.

### 1.3 Convolution 레이어

2차원 합성곱의 연산식은 다음과 같다.

$$
G[m,n]=(f*h)[m,n]=\sum_j\sum_k h[j,k]\,f[m-j,n-k]
$$

**커널** (필터)과 같은 크기의 입력 영역을 골라 대응 원소끼리 곱한다. 그 결과를 모두 더한 값이 **특징 맵** (Feature map)의 한 원소다.

### 1.4 Stride

Stride는 필터가 가로·세로 방향으로 한 번에 이동하는 간격이다. Stride가 2면 두 칸씩 이동한다. 같은 입력·필터·Padding에서 Stride가 커지면 계산하는 위치가 줄어 출력 특징 맵이 작아질 수 있다.

### 1.5 Padding

**Padding**은 입력 둘레에 값을 덧붙여 필터를 적용할 영역을 넓힌다. 가장자리 정보의 손실을 줄이고 출력 크기를 조절하는 데 쓰인다. Padding이 0이면 테두리를 추가하지 않고, 폭이 1인 Zero padding은 입력 둘레에 0을 한 칸씩 추가한다.

Dilation이 1이고 양쪽 Padding이 같을 때, 한 축의 출력 크기는 다음과 같다. $N_\text{in}$은 입력 크기, $K$는 필터 크기, $P$는 한쪽 Padding, $S$는 Stride다.

$$
N_\text{out}=\left\lfloor\frac{N_\text{in}+2P-K}{S}\right\rfloor+1
$$

### 1.6 필터 처리 예시

Padding 없이 $5\times5$ 입력에 $3\times3$ 필터를 Stride 1로 적용하면 $3\times3$ 특징 맵이 나온다. 이 필터는 영역의 왼쪽과 오른쪽 값을 비교하므로 세로 경계에 반응한다. 아래 예에서는 두 열의 합이 같아 출력의 한 칸이 0이다.

$$
\underbrace{\begin{bmatrix}1&0&2\\5&4&2\\3&4&5\end{bmatrix}}_{\text{입력 영역}}
\qquad
\underbrace{\begin{bmatrix}-1&0&1\\-1&0&1\\-1&0&1\end{bmatrix}}_{\text{필터}}
$$

$$
\begin{aligned}
&(-1)\cdot1+0\cdot0+1\cdot2\\
&+(-1)\cdot5+0\cdot4+1\cdot2\\
&+(-1)\cdot3+0\cdot4+1\cdot5=0
\end{aligned}
$$

이 예시는 필터를 뒤집지 않고 계산하는 CNN의 일반적인 방식이다. 필터를 Stride만큼 옮겨 같은 계산을 반복하면 특징 맵이 완성된다.

같은 $5\times5$ 입력과 $3\times3$ 필터에서 Stride와 Padding을 바꾸면 다음과 같다.

| Stride | Padding | 출력 크기 | 차이 |
|---|---|---|---|
| 1 | 0 | $3\times3$ | 필터 중심이 입력 안쪽 세 칸을 차례로 지난다. |
| 2 | 0 | $2\times2$ | 두 칸씩 이동하므로 계산하는 위치와 출력 크기가 줄어든다. |
| 1 | 1 | $5\times5$ | 필터 중심이 입력의 가장자리까지 갈 수 있어 경계에서도 응답을 구한다. |

### 1.7 Convolution 응용

**CNN** (Convolutional Neural Network)은 합성곱으로 이미지의 특징을 추출하는 신경망이다.

| 과제 | 출력 |
|---|---|
| 이미지 분류 (Image classification) | 영상 전체의 클래스 |
| 객체 감지 (Object detection) | 물체마다 위치와 클래스 |
| 인스턴스 분할 (Instance segmentation) | 같은 클래스의 물체도 개체별로 구분한 영역 |
| 시맨틱 분할 (Semantic segmentation) | 각 픽셀의 의미 클래스 |
| 파놉틱 분할 (Panoptic segmentation) | 픽셀별 클래스와 물체별 개체 구분 |

## 2. 다층 신경망

### 2.1 다층 신경망의 구성

다층 인공 신경망 (ANN)은 사람의 신경 구조에서 영감을 얻은 모델이다. 딥러닝의 기본 구성 요소이며 입력층·은닉층·출력층으로 나뉜다.

### 2.2 입력층·은닉층·출력층

| 레이어                    | 받는 정보               | 역할                                                                                       |
| ---------------------- | ------------------- | ---------------------------------------------------------------------------------------- |
| **입력층** (Input layer)  | 영상의 픽셀값이나 데이터셋의 특징값 | 입력값을 다음 층으로 전달한다.                                                                        |
| **은닉층** (Hidden layer) | 앞선 층의 출력            | 입력과 출력 사이에서 학습으로 중간 표현을 만든다. 여러 은닉층을 쌓으면 특징과 패턴을 여러 수준으로 표현할 수 있다.                       |
| **출력층** (Output layer) | 마지막 은닉층의 표현         | 과제에 맞는 최종 예측을 만든다. 이진 분류에서는 두 클래스에 각각 대응하는 출력을 둘 수 있고, 다중 클래스 분류에서는 보통 클래스마다 하나의 출력을 둔다. |

### 2.3 활성화 함수 (Activation function)

ReLU와 Sigmoid처럼 비선형인 활성화 함수는 신경망이 복잡한 패턴을 학습할 수 있게 한다.

| 함수 | 특징 | 비선형성 |
|---|---|---|
| **Linear** | 입력값을 선형적으로 변환한다. 선형 연산만 여러 층에 쌓아도 표현력은 한 층과 같다. | 없음 |
| **ReLU** (Rectified Linear Unit) | 음수는 0으로 바꾸고 0 이상의 값은 그대로 전달한다. | 있음 |
| **Sigmoid** | 입력을 0과 1 사이의 값으로 바꾼다. | 있음 |

### 2.4 하이퍼파라미터 (Hyperparameter)

하이퍼파라미터는 학습으로 추정하는 가중치와 달리 학습 전에 정하는 설정이다. 적절히 선택하면 과적합이나 과소적합을 줄이는 데 도움이 된다.

| 설정 | 조절하는 것 |
|---|---|
| **Epoch 수** | 전체 훈련 데이터셋을 몇 번 학습에 사용할지 정한다. |
| **학습률** | 기울기를 반영해 파라미터를 한 번에 얼마나 바꿀지 조절한다. |
| **배치 크기** | 한 번의 갱신에 사용할 훈련 샘플 수를 정한다. |
| **Optimizer** | 가중치와 편향을 어떤 규칙으로 갱신할지 정한다. |

## 3. 다층 신경망의 구조

### 3.1 CNN 기본 레이어

| 레이어 | 역할 |
|---|---|
| **Convolution** | 입력 데이터에 필터를 적용하여 데이터의 패턴과 특징을 감지한다. |
| **Pooling** | 입력 데이터의 공간 크기를 줄이면서 주요 특징을 선택하고 요약하여 필요한 정보를 보존한다. |
| **Fully Connected** | 이전 층의 모든 뉴런을 현재 층의 각 뉴런에 연결한다. 가중합과 활성화 연산으로 출력을 생성한다. |

### 3.2 CNN의 기타 구성 요소

| 레이어 | 역할 |
|---|---|
| **Normalization** | 이전 층에서 나온 활성화 값을 정규화하여 학습 안정성과 수렴을 개선한다. |
| **Dropout** | 학습 중 일부 뉴런을 무작위로 비활성화하여 과적합을 줄이고 모델의 견고성을 높인다. |
| **Flatten** | 다차원 입력을 1차원 벡터로 재구성하여 Fully Connected 층에서 사용할 수 있게 한다. |

### 3.3 대표 CNN 모델

| 모델            | 핵심 구조                                                                                                         | 목적과 효과                                        |
| ------------- | ------------------------------------------------------------------------------------------------------------- | --------------------------------------------- |
| **LeNet**     | LeNet-5는 Convolution 2개, 평균 Pooling 계열의 서브샘플링 2개, 분류용 후단 레이어 3개로 구성된다.                                        | 손글씨 숫자를 인식한다.                                 |
| **AlexNet**   | Convolution 5개와 Fully Connected 3개를 쌓는다.                                                                      | ImageNet 대회에서 우승해 심층 CNN의 영상 분류 성능을 보여줬다.     |
| **VGG**       | $3\times3$ Convolution을 반복한다. 가중치가 있는 레이어 수에 따라 VGG-16과 VGG-19가 있다.                                           | 작은 필터를 반복해 깊고 균일한 구조를 만든다.                    |
| **GoogLeNet** | Inception 모듈이 $1\times1$, $3\times3$, $5\times5$ 합성곱을 병렬로 적용하고 결과를 이어 붙인다. 큰 필터 앞의 $1\times1$ 합성곱은 채널 수를 줄인다. | 여러 크기의 특징을 포착하면서 파라미터와 연산량을 줄인다.              |
| **ResNet**    | 잔차 블록에서 Skip connection으로 입력 $x$를 잔차 변환 $F(x)$에 더한다.                                                          | 기울기 전달을 도와 ResNet-152 같은 깊은 모델을 학습하기 쉽게 한다.   |
| **DenseNet**  | 각 층이 앞선 모든 층의 특징 맵을 입력으로 받는다.                                                                                 | 특징 재사용으로 파라미터를 효율적으로 쓰고, 기울기가 직접 전달될 경로를 만든다. |

## 4. 다층 신경망의 학습

### 4.1 순전파 (Feedforward)

입력을 네트워크에 넣고 Convolution, 활성화 함수, Pooling 등의 연산을 차례로 적용해 예측값을 계산한다.

### 4.2 손실 함수 (Loss function)

**손실 함수**는 예측값과 목표값의 차이를 수치화하고 큰 오류에 불이익을 준다. 비용 함수나 목적 함수라고도 하며 과제에 맞춰 선택한다.

### 4.3 손실 함수 예시 — 평균 제곱 오차 (MSE)

회귀에서 쓰는 **MSE**는 예측값과 목표값의 차이를 제곱해 평균한 값이다.

$$
\mathrm{MSE}=\frac1n\sum_{i=1}^{n}(\hat y_i-y_i)^2
$$

값이 작을수록 같은 데이터에서 예측이 목표값에 가깝다.

### 4.4 역전파 (Backpropagation)

출력층에서 입력 쪽으로 **연쇄 법칙** (Chain rule)을 적용해, 각 파라미터가 손실에 얼마나 영향을 주는지 기울기를 계산한다. Optimizer는 이 기울기를 사용해 파라미터를 갱신한다.

### 4.5 최적화 알고리즘 (Optimization algorithm)

**최적화 알고리즘**은 손실을 줄이는 방향으로 가중치와 편향을 갱신한다. 대표적으로 확률적 경사하강법 (SGD), Adam, RMSprop, AdaGrad가 있다.

### 4.6 최적화 알고리즘 예시 — SGD

1. 가중치를 무작위로 한 번 초기화한다.
2. 훈련 데이터에서 **미니배치**를 무작위로 뽑는다.
3. 미니배치의 손실을 구하고 각 파라미터에 대한 기울기를 계산한다.
4. 기울기와 학습률로 파라미터를 갱신한다.
5. 수렴하거나 중지 기준을 충족할 때까지 여러 Epoch에 걸쳐 2~4단계를 반복한다.

**학습 1회 흐름** — 순전파 → 손실 계산 → 역전파 → 파라미터 갱신

## 5. CNN의 한계

| 한계                       | 발생 이유                                                 | 결과·예시·대응                                            |
| ------------------------ | ----------------------------------------------------- | --------------------------------------------------- |
| **대규모 데이터셋 요구**          | 다양한 영상 패턴을 학습하려면 많은 예제가 필요하다.                         | 데이터가 부족하면 과적합해 새 영상에서 성능이 떨어질 수 있다.                 |
| **이동 불변성의 한계**           | 같은 물체라도 위치나 방향이 달라지면 신경망의 반응이 달라질 수 있다.               | 고양이 이미지의 위치나 방향을 바꾸는 데이터 증강으로 완화할 수 있다.             |
| **Pooling Layer의 정보 손실** | 주변 여러 값을 하나로 요약하면서 공간 크기를 줄인다.                        | 특징의 정확한 위치나 작은 경계가 사라질 수 있다.                        |
| **좌표계와 부분·전체의 관계**       | 국소 특징을 찾더라도 물체의 방향을 기준으로 각 부분의 배치와 관계를 파악하기 어려울 수 있다. | 눈·코·입을 각각 찾는 것과 그 배치가 얼굴을 어떻게 이루는지 파악하는 것은 별개의 문제다. |
| **적대적 공격에 대한 취약성**       | 입력을 의도적으로 변형하면 CNN이 잘못 판단할 수 있다.                      | 자율주행처럼 안전이 중요한 분야에서는 이러한 입력 변화에도 견고해야 한다.           |
