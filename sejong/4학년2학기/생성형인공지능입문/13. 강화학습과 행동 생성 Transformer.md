## 1. 강화 학습 리뷰
### 1.1 학습 패러다임과 강화학습 환경

| 학습 방식 | 목표와 응용 |
|---|---|
| **지도학습** (Supervised Learning) | 조건부 분포 $p_\theta(y\mid x)$를 학습해 분류 (Classification)와 회귀 (Regression)를 수행한다. |
| **비지도학습** (Unsupervised Learning) | 데이터 분포 $p_\theta(x)$를 학습해 추론 (Inference)과 생성 (Generation)을 수행한다. |
| **강화학습** (Reinforcement Learning) | 상태에 따른 행동 정책 $\pi_\theta(a\mid s)$를 학습해 예측 (Prediction)과 제어 (Control)를 수행한다. |
**Agent** (정책 $\pi_\theta(a\mid s)$) —Action $a_t$→ **Environment** —State $s_{t+1}$, Reward $r_t$→ **Agent**
### 1.2 MDP (Markov Decision Process)와 가치·정책
강화학습 환경은 4가지 요소의 튜플 $\langle S, A, T, R \rangle$로 표현한다.

| MDP 요소 | 역할 |
|---|---|
| **상태 공간** ($S$) | 에이전트가 놓일 수 있는 상태 집합 ($s_t \in \mathcal{S}$)이다. |
| **행동 공간** ($A$) | 에이전트가 선택할 수 있는 행동 집합 ($a_t \in \mathcal{A}$)이다. |
| **전이 함수** ($T$) | 상태 $s$에서 행동 $a$를 취했을 때 다음 상태 $s'$로 이동할 확률 $T(s,a,s')=P(s'\mid s,a)$이다. |
| **보상 함수** ($R$) | 상태 $s$에서 행동 $a$를 취했을 때 기대되는 보상 $R(s,a)$이다. |

| 핵심 개념 | 설명 |
|---|---|
| **누적 보상** (Return, $G$) | 할인율 $\gamma < 1$을 적용한 미래 보상 합 $G(s_t,a_t)=\sum_{\tau=0}^{T}\gamma^\tau R(s_{t+\tau},a_{t+\tau})$이다. 눈앞의 충동적 보상보다 장기 보상을 추구하며, 환경 불확실성을 반영하고 무한 시평에서 값이 수렴하게 한다. |
| **강화학습 목표** | 기대 누적 보상 $J(\pi)$를 최대화하는 최적 정책 $\hat{\pi}=\arg\max_\pi J(\pi)$를 학습한다. |
| **Value 함수** ($V^\pi(s)$) | 정책 $\pi$를 따를 때 현재 상태 $s$에서 기대되는 누적 보상이다. |
| **Q 함수** ($Q^\pi(s,a)$) | 상태 $s$에서 특정 행동 $a$를 취한 뒤 정책 $\pi$를 따를 때 기대되는 누적 보상이다. |
| **정책 반복** | 현재 정책의 $V^\pi, Q^\pi$를 계산하는 **정책 평가** (Policy Evaluation)와, 각 상태에서 $Q^\pi(s,a)$가 최대인 행동으로 정책을 고치는 **정책 갱신** (Policy Update)을 반복한다 (예: DQN의 Atari 게임 제어). |
## 2. 판단 트랜스포머 (Decision Transformer)
### 2.1 Decision Transformer
강화학습을 가치 함수 ($V, Q$) 추정 대신 **조건부 시퀀스 모델링**으로 재정의한 모델이다.
**입력** $(\hat{R}_{t-1}, s_{t-1}, a_{t-1}, \hat{R}_t, s_t)$ → **임베딩 + 위치 인코딩** → **Causal Transformer** → **Linear Decoder** → **다음 행동 $a_t$**
- **핵심 원리** — 앞으로 얻고 싶은 목표 누적 보상인 **Return-to-go** ($\hat{R}_t$), 상태 $s_t$, 과거 행동 $a_t$를 시퀀스로 입력해 다음 행동 $a_t$를 자기회귀적으로 예측한다.
- **최적 행동 경로 생성** — 랜덤 워크처럼 최적이 아닌 경로가 섞인 데이터로 학습하더라도, 추론 시 높은 목표 Return을 조건으로 주면 목표 지점까지 최적 경로에 맞는 행동을 생성한다.
### 2.2 Trajectory Transformer
상태·행동·보상의 각 차원 ($s_t^1,\dots,s_t^N, a_t^1,\dots,a_t^M, r_t$)을 모두 개별 토큰 시퀀스로 펼쳐 자기회귀 Transformer로 전체 **행동 궤적** (Trajectory)을 모델링한다. 다음 행동뿐 아니라 미래 상태와 보상까지 함께 예측해 장기 행동 계획 (Planning)에 활용한다.

## 3. 행동 생성용 트랜스포머 (Behavior Transformer)
### 3.1 개요와 Continuous Action Binning
**Behavior Transformer** (BT / BeT)는 여러 방식의 정답이 공존하는 (다봉 분포) 연속 행동 시연 데이터를 모방 학습하기 위한 Transformer 모델이다.
- **연속 행동 이산화** ($k$-means) — 연속 행동 데이터셋을 $k$-means로 $k$개의 클러스터 중심 ($A_1,\dots,A_k$)으로 군집화한다. 각 실제 행동 $a$를 가장 가까운 **클러스터 번호** (Bin)와 중심과의 차이인 **잔차 오프셋** (Offset)으로 분해한다.
### 3.2 BT 구조·학습과 추론
**관측 시퀀스 → MinGPT → Binning Head + Offset Head → 연속 행동 복원**

| 단계 | 핵심 내용 |
|---|---|
| **Binning Head** (분류) | 관측 시퀀스를 입력받은 MinGPT가 정답 클러스터 (Action bin)의 확률 분포를 예측하며, **NLL / Focal loss**로 학습한다. |
| **Offset Head** (회귀) | 각 클러스터 중심에서 실제 행동까지의 미세 잔차 오프셋을 예측하며, 정답 클러스터의 오프셋에 대해 **MSE loss**로 학습한다. |
| **추론** (실행) | 최근 관측 이력을 MinGPT에 넣어 확률 분포에서 클러스터 $c$를 샘플링하고, 해당 클러스터의 예측 오프셋을 더해 최종 연속 행동 $\hat{a}=A_c+\langle a_c \rangle$을 실행한다. |
- **응용 데모** — 텍스트 지시 기반 로봇 팔 물체 조작 (Text to Behavior), 자율주행 (Text to Driving), 주방 작업 (Kitchen Demo) 등에 적용한다.
## 4. 셰프 로봇의 행동 생성
### 4.1 디지털 다이닝 (Digital Dining)의 발전
**1세대** (IT 통신 기반) → **1.5세대** (초기 메타버스: 제페토·로블록스) → **생성 AI 기반 디지털 다이닝** (혼합현실·음성 인터페이스 + 전자 코·전자 혀 시식 로봇 + 개인화 음식을 제조하는 셰프 로봇)
### 4.2 생성형 AI와 셰프 로봇의 활용

| 구성·기능 | 활용 방식 |
|---|---|
| **대화형 요리 주문** | 자연어·음성으로 사용자의 요구와 취향을 이해해 주문과 조리 조건에 반영한다. |
| **요리 로봇 동작 생성** | Behavior Transformer 등으로 주방 환경에서 전자레인지·주전자·가스레인지 조작 같은 연속 조리 동작을 생성한다. |
| **초감각 센서** (미각·후각) | 음식 분쇄 정도에 따른 **염도 센서** (Salinity)와 단일 센서 한계를 보완하는 **냄새 센서** (전자 코, E-nose) 및 멀티센서·Transformer 분석으로 숙성도와 풍미를 인식한다 (인간 미각과 센서 측정치의 상관관계 연구). |
| **시식 로봇·언어 명령 제조** | 표정 인식·표현과 인공 코·입을 갖춘 시식 로봇으로 음식 페어링을 평가하고, 언어 명령에 맞춰 개인화된 음식을 제조한다. |
## 5. AI 기반 행동 생성
- **정의** — 특정 동작을 자율적으로 수행하거나 목표에 맞는 출력 (텍스트·영상·오디오·로봇 움직임·전략 등)을 생성하는 기술이다.
- **주요 활용과 사례** — 게임 NPC 동작과 전략 의사결정 (알파고), 로봇 내비게이션·협업·서비스 제어, 자연어 처리·가상 비서 (GPT-3), VR·AR 가상 캐릭터 동작, 자율주행 (차량 제어·도로 감지: 테슬라 오토파일럿·웨이모) 등에 활용한다.
- **도전 과제** — 실제 환경 적용이 확대됨에 따라 **안전과 지속 가능성**을 보장하기 위한 **윤리적·법적 문제** 해결이 필요하다.
