## 1. 영상 생성 동작 1 (Stable Diffusion)
### 1.1 Stable Diffusion 개요
**Stable Diffusion**은 **잠재 확산 모델** (Latent Diffusion Model, LDM) 기반의 이미지 생성 모델이다. 사전학습한 VAE로 이미지를 압축된 잠재 공간에 표현하고, 이 공간에서 확산을 수행해 고품질 이미지를 효율적으로 생성한다.
**이미지 → VAE Encoder → 잠재 표현 $z_0$ → 순방향 확산 → U-Net 노이즈 예측 → VAE Decoder → 이미지**

| 구성 | 역할 |
|---|---|
| **VAE** (Variational Autoencoder) | Encoder로 이미지를 잠재 공간에 압축하고, Decoder로 정제된 잠재 표현을 픽셀 공간에 복원한다. |
| **U-Net** | 노이즈가 있는 잠재 표현과 시간 단계, 조건을 받아 추가된 노이즈를 예측한다. |
| **텍스트 Encoder** | 텍스트 조건을 사용할 때 프롬프트의 의미를 토큰 임베딩으로 표현한다 (예: CLIP ViT-L/14). |
픽셀 공간에서 고해상도 이미지를 매 단계 처리하면 계산량과 메모리 부담이 크다. 잠재 확산은 VAE로 압축한 표현에서 노이즈 제거를 반복해 비용을 줄이고, 정제가 끝난 표현만 VAE Decoder로 한 번 픽셀 공간에 복원한다.
### 1.2 학습·생성 흐름과 텍스트 조건 제어
1. **잠재 공간 압축** — VAE Encoder가 입력 이미지를 저차원 잠재 표현 $z_0$으로 압축한다.
2. **순방향 확산** — 잠재 표현에 정해진 스케줄로 가우시안 노이즈를 단계적으로 추가한다.
3. **노이즈 예측과 역방향 정제** — 학습에서는 U-Net이 노이즈가 섞인 $z_t$, 시간 단계, 조건을 받아 추가된 노이즈를 예측한다. 생성에서는 무작위 노이즈에서 시작해 U-Net 예측과 Scheduler로 노이즈를 반복 제거한다.
4. **픽셀 공간 복원** — 정제가 끝난 잠재 표현을 VAE Decoder에 넣어 최종 이미지를 얻는다. 같은 프롬프트라도 시작 노이즈가 다르면 다른 결과가 나온다.
[[11. Diffusion과 텍스트 기반 이미지 생성#3. 확산 모델 (Diffusion Model)|확산 과정과 응용]]
- **텍스트 조건 제어** (Cross-Attention) — 사전학습 텍스트 Encoder인 **CLIP ViT-L/14** 등이 프롬프트를 토큰 임베딩으로 변환한다. U-Net은 **Cross-Attention**에서 영상 잠재 특징을 **Query**, 텍스트 임베딩을 **Key·Value**로 사용해, 노이즈 제거 단계마다 영상의 각 위치와 관련된 프롬프트의 물체·특징을 반영한다.
## 2. 영상 생성 동작 2 (DALL-E)
### 2.1 구조와 2단계 학습
초기 **DALL-E**는 확산 모델이 아니라, 텍스트 토큰과 이산 이미지 토큰을 하나의 시퀀스로 이어 붙여 예측하는 **자기회귀 Transformer** 모델이다.
**BPE 텍스트 토큰 + dVAE 이미지 토큰 → Transformer Decoder → dVAE Decoder → 이미지**

| 단계 | 핵심 내용 |
|---|---|
| **1단계 · 시각 코드북 학습** | **이산 VAE** (dVAE)를 학습해 이미지를 격자 형태의 이산 이미지 토큰 (코드북)으로 압축하고 재구성한다 (ELBO 최대화). |
| **2단계 · 사전학습** | dVAE를 고정한 채 BPE 텍스트 토큰 뒤에 dVAE 이미지 토큰을 이어 붙인다. Transformer Decoder가 Attention Mask로 참조 범위를 제한하며 다음 토큰을 자기회귀적으로 예측한다 (이미지 모델링 비중을 높이기 위해 이미지 교차 엔트로피 손실에 더 큰 가중치를 둔다). |
생성할 때는 프롬프트를 텍스트 토큰으로 입력하면 Transformer가 뒤이어 이미지 토큰을 하나씩 생성하고, dVAE Decoder가 이를 픽셀 이미지로 복원한다.
### 2.2 평가와 특징
- **제로샷 성능** — MS-COCO를 학습에 직접 쓰지 않은 제로샷 평가에서 기존 GAN 계열 (AttnGAN·DM-GAN·DF-GAN)보다 높은 사실성과 캡션 일치도를 보였다.
- **일반화와 한계** — 학습 데이터에 없는 새로운 개념 조합을 묘사할 수 있으나, 복잡한 이미지 간 변환에서는 결과의 일관성이 떨어지는 한계가 있다.
## 3. DALL-E 2 소개
### 3.1 DALL-E 2 (unCLIP) 구조
**DALL-E 2** (unCLIP)는 텍스트와 이미지를 같은 의미 공간에 정렬하는 **CLIP**을 사용한다. 텍스트에서 CLIP 이미지 임베딩을 먼저 생성하고, 이 임베딩을 다시 이미지로 복원하는 **계층적 확산 생성** 방식이다.
**텍스트 → Prior → CLIP 이미지 임베딩 → Diffusion Decoder → Upsampler → 이미지**

| 구성 | 역할 |
|---|---|
| **CLIP** (Contrastive Language–Image Pre-training) | 텍스트 Encoder와 이미지 Encoder가 같은 배치의 대응 쌍은 코사인 유사도를 높이고 다른 쌍은 낮추는 **대조학습**으로 공동 임베딩 공간을 학습한다. 이미지 임베딩과 클래스 설명 임베딩의 유사도를 비교해 제로샷 분류에도 활용할 수 있다. |
| **Prior** | 텍스트 캡션 (또는 텍스트 임베딩)을 조건으로 대응하는 **CLIP 이미지 임베딩**을 생성한다 (자기회귀 Prior 또는 확산 Prior 사용). |
| **Diffusion Decoder & Upsampler** | Prior가 만든 CLIP 이미지 임베딩을 조건으로 픽셀 공간에서 노이즈를 제거해 이미지를 생성하고 (CLIP Encoder의 역방향), Upsampler가 해상도를 단계적으로 높인다. |
### 3.2 Guidance scale과 성능 비교
- **Guidance scale** — 샘플링 중 텍스트 조건을 얼마나 강하게 반영할지 조절하는 설정이다. 값을 높이면 **사실성과 캡션 일치도**가 높아지지만, 결과가 비슷해져 **다양성이 줄어드는 트레이드오프**가 생긴다.
- **GLIDE 대비 특징** — MS-COCO 제로샷 평가에서 Guidance scale을 높일 때 GLIDE는 다양성이 크게 줄어 FID가 악화됐지만, unCLIP (DALL-E 2)은 사실성과 캡션 일치도를 유지하면서 다양성을 더 잘 보존했다.
### 3.3 Stable Diffusion · DALL-E 1 · DALL-E 2 비교

| 모델 | 생성 방식과 핵심 특징 |
|---|---|
| **Stable Diffusion** (LDM) | VAE로 압축한 **잠재 공간**에서 U-Net으로 확산한다. CLIP 텍스트 임베딩을 **Cross-Attention**으로 주입해 고해상도 이미지를 효율적으로 생성한다. |
| **DALL-E 1** | 확산이 아닌 **자기회귀 Transformer**다. dVAE로 이미지를 이산 토큰으로 변환한 뒤 텍스트 토큰과 한 시퀀스로 이어 다음 토큰을 예측한다. |
| **DALL-E 2** (unCLIP) | **CLIP** 공동 공간 위에서 **Prior**가 텍스트로부터 CLIP 이미지 임베딩을 생성하고, **Diffusion Decoder**와 Upsampler가 이를 픽셀 이미지로 복원한다. |
## 4. DALL-E의 응용 사례
- **창작·디자인** — 텍스트 설명으로 아트·일러스트·광고 시안·디지털 아트·밈을 제작하고, 인테리어 배치·패션 의상·건축 평면도와 도시 계획을 시각화한다.
- **상업·엔터테인먼트** — 이커머스 제품 시안·카탈로그, 게임 에셋·캐릭터, 영화·애니메이션 스토리보드, 개인 아바타와 맞춤형 콘텐츠를 생성한다.
- **과학·연구** — 과학 개념·시뮬레이션을 시각화하고, 의료 보고서를 바탕으로 해부학 도표나 설명용 합성 의료 이미지를 만든다.
## 5. 생성 모델의 확장성
생성 모델의 **확장성**은 요구 사항과 계산 제약에 맞춰 다양한 복잡도·크기·해상도의 결과를 생성하는 능력이다.

| 특성 | 내용 |
|---|---|
| **해상도 유연성** | 목적에 따라 저·중·고해상도와 세부 수준을 선택해 생성한다. |
| **자원 효율** | 출력 규모가 커져도 연산량과 메모리 증가를 줄여 품질과 비용의 균형을 맞춘다. |
| **입력 적응** | 텍스트·참조 이미지·사용자 선호 등 달라지는 입력 조건에 맞춰 결과를 조정한다. |
| **점진적 개선** | 저해상도에서 전체 배치와 큰 형태를 만든 뒤, 후속 Upsampler로 해상도를 높이며 경계·질감을 추가해 계산 부담을 줄인다. |
| **스케일 간 일관성** | 해상도가 높아져도 주요 객체의 형태와 위치 등 큰 구조가 시각적으로 유지된다. |
| **응용 다양성** | 이미지 합성, 초고해상도, 콘텐츠 제작, 스타일 전환 등 여러 과제에 적용한다. |
| **가용 자원에 따른 조정** | 하드웨어·소프트웨어 환경에 맞춰 생성 속도와 품질의 균형을 조절한다. |
| **다중 스케일 표현** | 전체 구조부터 작은 질감까지 서로 다른 수준의 특징을 모델의 각 구성 요소가 나누어 처리한다. |
