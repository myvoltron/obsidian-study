## 1. RNN의 구조
### 1.1 순차 데이터와 hidden state
**순환 신경망** (RNN, Recurrent Neural Network)은 순차 데이터 또는 시계열 데이터를 위해 설계된 신경망 모델이다. 예를 들어 `I like Seoul, so I'm going to ___`의 빈칸을 예측하려면 앞에서 나온 `Seoul`을 기억해야 한다.
각 시점의 **hidden state**는 이전 데이터와 현재 데이터의 정보를 저장한다. **현재 입력** $x_t$와 **이전 hidden state** $h_{t-1}$로 **현재 hidden state** $h_t$를 계산한 뒤, 이를 이용해 출력 $o_t$를 만들고 다음 시점에 상태를 전달한다.
$$
h_t = \tanh(W_{xh}x_t + W_{hh}h_{t-1} + b)
$$
RNN은 모든 시점에서 같은 가중치를 사용한다. 시간축으로 펼친 계산 그래프는 방향성 비순환 그래프다.
### 1.2 단방향과 양방향

| 구조 | 참조하는 문맥 | 조건·활용 |
|---|---|---|
| **단방향 RNN** | 정방향 레이어만 사용한다. 현재 위치에서는 앞쪽 정보와 현재 입력에 접근할 수 있다. | 다음 토큰 예측에 적합하다. |
| **양방향 RNN** | 정방향 레이어와 역방향 레이어를 모두 사용한다. 현재 위치 이전과 이후의 정보를 모두 이용할 수 있다. | 전체 입력 시퀀스가 주어져야 한다. |
## 2. RNN의 한계와 개선
### 2.1 장기 의존성과 기울기 문제
**장기 의존성**은 멀리 떨어진 시점의 정보가 현재 예측에 필요한 경우다. RNN은 오래전 입력의 정보를 기억하기 어렵다. 학습 과정에서 역전파할 때 시간 단계에 따라 미분 항이 연속적으로 곱해져 기울기가 매우 작아지거나 커질 수 있다.

| 문제 | 원리와 결과 | 완화 방법 |
|---|---|---|
| **Vanishing gradient** | 기울기가 매우 작아지거나 0에 가까워진다. 먼 시간 단계 사이에 학습 신호를 전달하기 어려워져 장기 의존성을 학습하는 데 한계가 생긴다. | LSTM·GRU의 게이트로 이전 상태의 중요한 정보를 유지한다. |
| **Exploding gradient** | 역전파 중 기울기가 너무 커지면서 가중치가 과도하게 갱신되어 모델 학습이 불안정해진다. | **Gradient clipping**으로 기울기 크기를 제한한다. 성분별 clipping은 각 값을 $[-C, C]$ 범위로 제한한다. |
**시간축 병렬화의 제약**은 순전파에서도 생긴다. $h_t$를 구하려면 $h_{t-1}$이 필요하므로, 입력 전체가 주어져도 한 시퀀스의 모든 시점을 동시에 계산하기 어렵다. Transformer의 Self-Attention은 이미 주어진 위치들의 표현을 병렬로 계산할 수 있다. [[04. 트랜스포머 1 - 임베딩과 Attention#6. RNN과 Transformer 비교|RNN과 Transformer 비교]]
### 2.2 LSTM과 GRU

| 모델 | 상태 | 게이트 역할 |
|---|---|---|
| **LSTM** (Long Short-Term Memory) | **Cell state**에 장기 기억을 전달하고 **hidden state**를 출력한다. | **Forget**은 이전 기억을 얼마나 유지할지, **input**은 새 정보를 얼마나 추가할지, **output**은 cell state에서 어떤 정보를 hidden state로 내보낼지 결정한다. |
| **GRU** (Gated Recurrent Unit) | **Hidden state**가 기억과 출력 역할을 함께 한다. | **Reset**은 후보 상태를 만들 때 이전 상태를 얼마나 반영할지, **update**는 이전 상태와 후보 상태를 어떤 비율로 섞을지 결정한다. |
LSTM과 GRU는 이전 상태에서 필요한 정보를 여러 시점에 걸쳐 유지해 기울기 소실을 완화한다. Gradient clipping은 역전파 중 지나치게 큰 기울기를 제한해 갱신을 안정화한다.
GRU에서는 현재 입력 $x_t$와 이전 상태 $h_{t-1}$로 reset gate $r_t$와 update gate $z_t$를 계산한다. $r_t$를 적용해 후보 상태 $g_t$를 구하고, $z_t$와 $1-z_t$로 이전 상태와 후보 상태를 섞는다.
$$
\begin{aligned}
r_t &= \sigma(W_{xr}x_t+W_{hr}h_{t-1}+b_r) \\
z_t &= \sigma(W_{xz}x_t+W_{hz}h_{t-1}+b_z) \\
g_t &= \tanh(W_{xg}x_t+W_{hg}(r_t\odot h_{t-1})+b_g) \\
h_t &= z_t\odot h_{t-1}+(1-z_t)\odot g_t
\end{aligned}
$$
## 3. Attention 1 — RNN 번역
### 3.1 RNN Encoder–Decoder와 고정 길이 벡터 병목
**Seq2Seq**는 Encoder와 Decoder라는 두 개의 RNN으로 구성된다. Encoder의 첫 번째 노드는 첫 단어를 입력받고, 후속 노드는 이전 노드의 hidden state와 다음 단어를 입력받는다. Encoder가 출력하는 **문맥 벡터** (Context vector)는 Decoder의 입력으로 사용된다. Decoder는 각 시점에서 번역된 단어를 출력하고, 자신의 hidden state를 다음 시점의 입력으로 전달한다.
**입력 시퀀스 → RNN Encoder → 고정 길이 문맥 벡터 → RNN Decoder → 출력 시퀀스**
기본 RNN 번역은 입력 길이에 관계없이 문장 전체를 마지막 고정 길이 벡터 하나에 담는다. 긴 문장의 세부 정보를 모두 보존하기 어려워 번역에 필요한 원문의 일부를 놓칠 수 있다. 입력 위치별 상태를 유지하는 Bahdanau Attention은 이 정보 병목을 완화한다.
### 3.2 Attention과 Bahdanau Attention
**Attention**은 고정 길이 벡터에 의존하는 기존 Encoder–Decoder 구조의 한계를 보완한다. Encoder는 각 입력 위치에 해당하는 **hidden state**를 유지한다. Attention은 각 입력 위치의 관련성을 나타내는 가중치를 계산하고, Decoder는 이 가중치에 따라 입력 위치별 상태를 참고해 출력 시퀀스를 생성한다.
**Bahdanau Attention**은 양방향 RNN Encoder를 사용한다. 입력 위치 $i$의 상태 $h_i$는 정방향과 역방향 hidden state를 결합한 값이다. 이전 Decoder 상태 $s_{t-1}$와 $h_i$를 비교하는 **additive attention**으로 점수를 구한다.
$$
\begin{aligned}
e_{t,i} &= v_a^\top\tanh(W_a[h_i; s_{t-1}]) \\
\alpha_{t,i} &= \operatorname{softmax}_i(e_{t,i}) \\
c_t &= \sum_i \alpha_{t,i} h_i
\end{aligned}
$$
$e_{t,i}$는 관련도 점수, $\alpha_{t,i}$는 입력 위치별 가중치, $c_t$는 시점 $t$의 context vector다. Decoder는 $c_t$와 이전 상태 $s_{t-1}$를 이용해 현재 상태 $s_t$를 계산하고 출력 토큰 $y_t$를 예측한다. 기본 Seq2Seq와의 번역 비교에서 특히 긴 문장의 BLEU 점수가 높았다. 가중치는 출력 토큰이 어떤 입력 위치에 집중했는지 보여주는 **정렬** (Alignment)로 나타낼 수 있다.
## 4. Attention 2 — Query·Key·Value와 Global Attention
**Attention 함수**는 Query와 Key–Value 쌍의 집합을 받아, Query에 대한 각 Key의 관련도에 따라 Value를 가중합한다.

| 요소 | 역할 | RNN 번역에서의 예 |
|---|---|---|
| **Query** (Q) | 현재 필요한 정보를 찾는 기준 | Decoder 상태 |
| **Key** (K) | Query와 관련도를 비교할 표현 | 입력 위치별 Encoder 상태 |
| **Value** (V) | 가중합에 사용할 정보 | 입력 위치별 Encoder 상태 |
**Query와 각 Key의 관련도 계산 → Softmax로 가중치 정규화 → 대응하는 Value의 가중합**
**Global Attention**은 context vector를 구할 때 Encoder의 **모든 hidden state**를 고려한다.
## 5. 간단한 언어 번역
자연어 처리에서 **기계 번역**은 계산 방법과 알고리즘을 사용하여 한 언어의 텍스트나 음성을 다른 언어로 자동 변환하는 작업이다. 통계적 기계 번역과 신경망 기계 번역이 있으며, Transformer는 신경망 기계 번역에 사용하는 모델 구조다.

| 항목 | 영어 → 프랑스어 Seq2Seq |
|---|---|
| **병렬 데이터** | 의미가 대응하는 영어·프랑스어 문장 쌍을 사용한다. 예를 들어 `I am cold.` → `J’ai froid.` |
| **단어 표현** | 고유 단어마다 ID를 부여하고, 해당 ID 위치만 1인 **one-hot 벡터**로 표현할 수 있다. |
| **특수 토큰** | **SOS**는 시퀀스의 시작, **EOS**는 시퀀스의 끝을 표시한다. |
기본 Decoder는 고정 길이 context vector를 사용하고, Attention Decoder는 출력 시점마다 Encoder 상태를 가중합해 context vector를 계산한다. 번역 토큰은 EOS를 출력할 때까지 생성한다.
