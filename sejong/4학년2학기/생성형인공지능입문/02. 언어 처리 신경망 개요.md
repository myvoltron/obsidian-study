## 1. RNN의 구조
### 1.1 순차 데이터와 hidden state
**순환 신경망** (RNN, Recurrent Neural Network)은 순차 데이터 또는 시계열 데이터를 위해 설계된 신경망 모델이다. 예를 들어 `I like Seoul, so I'm going to ___`의 빈칸을 예측하려면 앞에서 나온 `Seoul`을 기억해야 한다.
각 시점의 **hidden state**는 이전 데이터와 현재 데이터의 정보를 저장한다. **현재 입력** $x_t$와 **이전 hidden state** $h_{t-1}$로 **현재 hidden state** $h_t$를 계산해 출력 $o_t$를 만들고 다음 시점으로 전달한다.
$$
h_t = \tanh(W_{xh}x_t + W_{hh}h_{t-1} + b)
$$
RNN은 모든 시점에서 같은 가중치를 공유하며, 시간축으로 펼친 계산 그래프는 방향성 비순환 그래프다.
### 1.2 단방향과 양방향

| 구조 | 참조하는 문맥 | 조건·활용 |
|---|---|---|
| **단방향 RNN** | 정방향 레이어만 사용해 이전 정보와 현재 입력에 접근한다. | 다음 토큰 예측에 적합하다. |
| **양방향 RNN** | 정방향과 역방향 레이어를 모두 사용해 이전과 이후 정보를 함께 이용한다. | 전체 입력 시퀀스가 주어져야 한다. |
## 2. RNN의 한계와 개선
### 2.1 구조적 한계와 완화 방법
**장기 의존성**은 멀리 떨어진 시점의 정보가 현재 예측에 필요한 경우다. RNN은 시간축 역전파에서 미분 항이 연속으로 곱해지고, 순전파에서도 이전 시점 상태를 기다려야 하는 구조적 한계가 있다.

| 한계 | 원인과 결과 | 완화 방법 |
|---|---|---|
| **Vanishing gradient** | 역전파 중 기울기가 0에 가까워져 먼 시점까지 학습 신호가 전달되지 않고 장기 의존성 학습이 어려워진다. | **LSTM·GRU**의 게이트로 이전 상태의 중요한 정보를 유지한다. |
| **Exploding gradient** | 역전파 중 기울기가 과도하게 커져 가중치가 크게 흔들리고 학습이 불안정해진다. | **Gradient clipping**으로 기울기 크기를 $[-C, C]$ 범위로 제한한다. |
| **시간축 병렬화 제약** | $h_t$를 구하려면 $h_{t-1}$이 필요하므로 입력 전체가 주어져도 모든 시점을 동시에 계산하기 어렵다. | **Transformer**의 Self-Attention으로 주어진 위치들을 병렬 계산한다. |

### 2.2 LSTM과 GRU

| 모델 | 상태 | 게이트 역할과 특징 |
|---|---|---|
| **LSTM** (Long Short-Term Memory) | **Cell state**에 장기 기억을 전달하고 **hidden state**를 출력한다. | **Forget**은 이전 기억 유지 비율, **input**은 새 정보 추가 비율, **output**은 hidden state로 내보낼 정보를 결정한다. |
| **GRU** (Gated Recurrent Unit) | Cell state 없이 **hidden state**가 기억과 출력을 함께 맡는다. | LSTM을 2개 게이트로 간소화했다. **Reset**은 후보 상태 계산 시 이전 상태 반영 비율을, **update** (LSTM의 forget+input 결합)는 이전 상태와 후보 상태의 혼합 비율을 결정한다. |
## 3. Attention 1 — RNN 번역
### 3.1 RNN Encoder–Decoder와 고정 길이 벡터 병목
**Seq2Seq**는 두 개의 RNN (Encoder·Decoder)으로 구성된다. Encoder는 입력 시퀀스를 순서대로 읽어 하나의 **문맥 벡터** (Context vector)로 압축하고, Decoder는 이 벡터를 바탕으로 번역 토큰을 순차 생성한다.
**입력 시퀀스 → RNN Encoder → 고정 길이 문맥 벡터 → RNN Decoder → 출력 시퀀스**
기본 RNN 번역은 문장 길이에 관계없이 원문 전체를 고정 길이 벡터 하나에 담으므로, 긴 문장의 세부 정보를 놓치는 **정보 병목**이 생긴다.
### 3.2 Attention과 Bahdanau Attention
**Attention**은 Encoder가 모든 입력 위치의 **hidden state**를 유지하게 하고, Decoder가 출력 시점마다 입력 위치별 관련도 가중치에 따라 원문 정보를 동적으로 참고해 고정 길이 병목을 완화한다.
- **Bahdanau Attention** — 양방향 RNN Encoder의 각 위치 상태 $h_i$와 이전 Decoder 상태 $s_{t-1}$을 비교하는 **additive attention**을 사용한다.
- **계산 흐름** — **관련도 점수 계산 → Softmax 가중치 정규화 → Encoder 상태 가중합**으로 시점 $t$의 동적 context vector $c_t$를 만든다.
- **효과와 해석** — 기본 Seq2Seq 대비 특히 긴 문장의 BLEU 점수가 높으며, 가중치는 출력 토큰이 어떤 입력 위치에 집중했는지 보여주는 **정렬** (Alignment)로 시각화할 수 있다.
## 4. Attention 2 — Query·Key·Value와 Global Attention
**Attention 함수**는 Query와 Key–Value 쌍의 집합을 받아, Query에 대한 각 Key의 관련도에 따라 Value를 가중합한다.

| 요소 | 역할 | RNN 번역에서의 예 |
|---|---|---|
| **Query** (Q) | 현재 필요한 정보를 찾는 기준 | Decoder 상태 |
| **Key** (K) | Query와 관련도를 비교할 표현 | 입력 위치별 Encoder 상태 |
| **Value** (V) | 가중합에 사용할 정보 | 입력 위치별 Encoder 상태 |
**Query와 각 Key의 관련도 계산 → Softmax로 가중치 정규화 → 대응하는 Value의 가중합**
- **Global Attention** — context vector를 구할 때 Encoder의 **모든 hidden state**를 고려하는 방식이다.
## 5. 간단한 언어 번역
- **기계 번역** — 한 언어의 텍스트·음성을 다른 언어로 자동 변환하는 작업으로, 통계적 기계 번역·신경망 기계 번역·Transformer 기반 모델이 쓰인다.
- **Seq2Seq 번역 전처리** — 대응 문장 쌍 (병렬 데이터)의 고유 단어에 ID를 부여해 **one-hot 벡터**로 표현하며, 문장 시작에 **SOS**, 끝에 **EOS** 특수 토큰을 붙인다.
- **생성 종료** — 기본 Decoder (고정 context vector)나 Attention Decoder (시점별 가중합 context vector) 모두 **EOS**가 출력될 때까지 토큰을 생성한다.
