## 1. ChatGPT란 무엇일까?

| 항목 | 핵심 내용 |
|---|---|
| **ChatGPT** | OpenAI에서 개발한 대규모 언어 모델 (LLM) 기반 서비스다. GPT (Generative Pre-trained Transformer)를 기반으로 사용자 질의에 대한 텍스트 응답을 생성한다. |
| **GPT 구조** | Transformer Decoder 기반이다. **Masked Multi-Head Self-Attention**으로 현재 위치까지의 토큰만 참조한다. |
| **학습** | 사람의 피드백을 사용하는 강화학습인 **RLHF** (Reinforcement Learning from Human Feedback)로 **Fine-tuning**한다. |
| **한계** | 학습 시점 이후의 최신 정보에 제약이 있으며, 불확실한 질의에서 사실에 근거하지 않는 부정확한 답을 추측해 생성하는 **환각** (Hallucination)이 발생할 수 있다. |
## 2. 생성형 인공지능이란?
### 2.1 개념과 Encoder–Decoder
**생성형 인공지능** (Generative AI)은 텍스트, 이미지, 음악 등의 콘텐츠 생성을 중점으로 하는 인공지능 분야다. 대표 플랫폼은 **ChatGPT**와 **DALL-E**다.
Encoder–Decoder 구조에서 **Encoder**는 입력을 해석해 **문맥 정보** (Contextual information)를 생성하고, **Decoder**는 이 문맥 정보를 바탕으로 출력을 생성한다.
**입력 → Encoder → 문맥 정보 → Decoder → 출력**
### 2.2 출력별 대표 모델과 생성 구조

| 출력 | 대표 모델 |
|---|---|
| **이미지 생성** | **GAN** (Generative Adversarial Network)과 Autoencoder로 실제와 유사한 이미지를 생성한다. |
| **텍스트 생성** | **RNN** (Recurrent Neural Network)이나 Transformer로 텍스트를 생성한다. |
| **비디오 생성** | **3D CNN**이나 **GAN**으로 동영상을 생성한다. |
| **오디오 생성** | **1D CNN**이나 **GAN**으로 오디오를 생성한다. |

| 모델 | 구성과 핵심 원리 |
|---|---|
| **GAN** | Generator와 Discriminator로 구성되며, 실제·생성 데이터를 구분하는 판별 신호로 경쟁 학습한다. |
| **VAE** (Variational Autoencoder) | Encoder와 Decoder로 구성되며, 변분 하한을 최대화해 확률적 잠재 표현을 학습한다. |
| **Flow-based Models** | 가역 변환과 역변환 (Decoder가 Encoder의 역함수)으로 데이터와 잠재 표현을 가역적으로 변환한다. |
| **Diffusion Models** | 순방향 확산에서 가우시안 노이즈를 점진적으로 추가하고, 이를 제거하는 역과정을 학습한다. |
[[07. GAN과 생성 모델 개요|GAN·VAE·Diffusion 비교]]
### 2.3 문제점

| 문제 | 핵심 내용 |
|---|---|
| **데이터셋** | 대규모 모델에는 많은 데이터가 필요하며, 데이터가 부족하거나 품질이 낮으면 생성 결과에 영향을 준다. |
| **보안·윤리** | 위험한 요청에 유해한 답을 생성할 수 있어 법적 규제 등으로 대응해야 한다. |
## 3. 인지형 AI와의 차이점
### 3.1 인지형 인공지능
**인지형 인공지능** (Cognitive AI)은 컴퓨터가 인간의 사고와 인지 과정을 모사하는 분야다. 데이터 마이닝, 머신러닝, 자연어 처리를 활용해 지능적인 의사 결정과 문제 해결을 수행한다.
- **구성 요소** — 지식 표현, 학습, 자연어 처리 (NLP), 컴퓨터 비전, 추론 및 의사 결정으로 이루어진다.
- **주요 응용** — 지능형 고객 서비스, 지능형 검색, 지능형 번역, 지능형 이미지 분석 (의료 영상 판독), 자율주행 등에 활용한다.
### 3.2 인지형 AI와 생성형 AI의 차이
두 유형은 자연어 처리와 머신러닝 같은 구성 기술을 공유하지만, 시스템의 주된 목적과 출력이 다르다.

| 유형 | 목적과 예시 |
|---|---|
| **인지형 AI** | 입력을 이해·추론하고 판단한다. 같은 이미지에서 객체의 종류를 판별해 ‘고양이’라는 레이블을 붙인다. |
| **생성형 AI** | 입력이나 학습한 패턴을 바탕으로 새로운 콘텐츠를 만든다. 같은 이미지에 대해 ‘고양이가 창가에 앉아 있다’라는 설명문을 생성한다. |
## 4. 언어 및 영상 생성
### 4.1 언어 생성
**언어 생성** (Language generation)은 자연스러운 인간 언어 규범에 맞는 텍스트를 생성하는 자연어 처리 분야로, 질의응답·챗봇·고객 서비스·자동 콘텐츠 생성에 쓰인다.
- **딥러닝 접근** — 신경망이 데이터에서 언어의 규칙과 특징을 직접 학습하므로 수작업 특징 설계를 줄이고, 문맥을 반영해 자연스러운 텍스트를 생성한다.
- **대표 모델** — Markov chain, **RNN** (이전 hidden state 전달), **LSTM** (장기 정보 유지), **Transformer** (위치 정보와 Attention 활용), **GPT** (프롬프트에 이어지는 텍스트 생성, [[06. BERT와 GPT#2. GPT|GPT의 학습과 생성]]).
### 4.2 이미지 생성
**이미지 생성** (Image generation)은 알고리즘으로 사진·그림·3D 렌더링·가상 이미지를 만드는 과정으로, 규칙 기반·통계 기반·딥러닝 기반 방법을 사용한다.
- **딥러닝 기반 이미지 생성** — 신경망으로 입력 표현과 출력 이미지의 관계를 학습하며, 대표 모델인 **GAN**과 **VAE**는 잠재 벡터에서 실제와 유사한 이미지를 생성한다.
## 5. 언어 생성 방법
### 5.1 구축 단계와 전처리
**데이터셋 선택 → 입력 텍스트 전처리 → 언어 모델 선택 → 모델 학습 → 모델 평가**
- **데이터셋** (Text Corpus) — 언어 생성에 사용하는 문장 집합으로, 클래스 레이블·품사 태그·번역문 등을 포함할 수 있다.

| 전처리 | 역할과 예시 |
|---|---|
| **Tokenization** | 텍스트를 문자·단어·서브워드 등 입력 요소로 분리한다. 예: `This is tokenizing.` → Character `[T][h]…`, Word `[This][is][tokenizing][.]`, Subword `[This][is][token][izing][.]`. |
| **Vectorization** | 토큰이나 텍스트를 수치로 표현한다 (단어 인덱스, TF-IDF 등). |
| **Embedding** | 의미 관계나 문맥 정보를 담은 벡터로 토큰을 표현한다. |
- **모델 선택과 학습** — [[02. RNN과 Attention#1. RNN의 구조|RNN]]이나 [[04. 단어 임베딩과 Transformer#2. Transformer 전체 흐름과 위치 인코딩|Transformer]]를 선택해 `가중치 초기화 → 예측 → 손실 계산 → 역전파·가중치 갱신`을 손실이 안정될 때까지 반복한다.
### 5.2 평가

| 지표 | 평가 내용 |
|---|---|
| **Perplexity** (PPL) | 실제 다음 토큰에 높은 확률을 부여할수록 **값이 낮아지며** (교안에서는 ‘난해성’으로 표기), 낮을수록 예측 성능이 좋다. |
| **BLEU** | 생성문과 참조문에서 일치하는 단어 및 연속 단어 묶음을 바탕으로 유사성을 측정한다. |
| **ROUGE** | 요약 등 과제별 지표로, 생성 요약과 참조 요약의 중첩을 측정한다 (Recall-Oriented Understudy for Gisting Evaluation). |
| **사람 평가·정성적 분석** | 평가자가 생성 텍스트의 일관성, 문법, 문맥 관련성을 직접 검토하고 주관적으로 평가한다. |
